## 0. المبادئ والقيود المحدثة

* **لا JS:** الاعتماد على `Compiler/` الأصلي (`Lexer.cpp, Parser.cpp, CodeGen.cpp, Optimizer.cpp`) — لا `Studio/Web/js/dhad-*.js`.
* **Qt5 LTS 5.15+** لضمان `Windows 7` (آخر Qt يدعم 7) وحتى `Windows 11 / Linux / macOS` — نفس `Compiler/CMakeLists.txt:51` `find_package(Qt5 5.15)` + `CPU/Makefile:12` `QtWidgets`.
* **C++20 + CMake ≥3.21** موحد — مخرجات `DaadCore` تُربط كـ `STATIC lib` للمحرر.
* **الكتابة من اليمين لليسار (RTL):** المحرر نفسه من اليمين لليسار — كل سطر `ض` يبدأ من اليمين، المؤشر يتحرك يمين→يسار، أرقام الأسطر على اليمين — `QPlainTextEdit` مضبوط `Qt::RightToLeft` (انظر 2.3).
* **واجهة عربية 100%:** كل القوائم, الأزرار, الرسائل, التشخيصات بالعربية فقط — لا إنجليزية في الواجهة (انظر 2.4).
* **ممنوع الإيموجي:** يُمنع `U+1F600` أو أي `emoji` في الكود والواجهة — يُسمح فقط **نصوص + صور PNG/SVG** كأيقونات (انظر 2.5).
* **ثيم مزدوج:** `فاتح (نهاري)` و `غامق (ليلي)` عبر `QSS` ملفين — تبديل فوري من قائمة عرض (انظر 2.6).
* **كل مرحلة تنتهي ببناء أخضر** `cmake --build && ctest` — لا مرحلة تبدأ قبل اكتمال سابقتها.

### 2.2 التفاصيل الدقيقة QMainWindow + QTabWidget
* **اتجاه النافذة:** `setLayoutDirection(Qt::RightToLeft); setLocale(QLocale("ar_SA"));` — كل `QDockWidget` يرسو يميناً افتراضياً.
* **QTabWidget:** `setTabsClosable(true), setMovable(true), setDocumentMode(true), setTabPosition(QTabWidget::North)` — كل `EditorTab` يحمل `filePath, isModified, DaadDocument` (نص + AST cache).
* **الاختصارات العربية:** `Ctrl+ن (جديد), Ctrl+ف (فتح), Ctrl+ح (حفظ), Ctrl+ب (بناء), F5 (تشغيل), Ctrl+م (تحويل), Ctrl+Space (إكمال)`.

### 2.3 متطلب 1 — الكتابة من اليمين إلى اليسار
* **المحرر:** `QPlainTextEdit *editor; editor->setLayoutDirection(Qt::RightToLeft); editor->document()->setDefaultTextOption(QTextOption(Qt::AlignRight)); QTextOption opt; opt.setTextDirection(Qt::RightToLeft); opt.setAlignment(Qt::AlignRight);` — السطر يبدأ من اليمين، عند `Enter` يبقى RTL.
* **المؤشر:** `QTextCursor` يتحرك `Left/Right` معكوسة منطقياً — `Home` يذهب لأقصى اليمين `End` لأقصى اليسار.
* **أرقام الأسطر:** `LineNumberArea` تُرسم على **اليمين** وليس اليسار (عكس المحررات الإنجليزية) — `paintEvent` يحسب `rect.x = width - numbersWidth`.
* **الفواصل العربية:** `؛` و `،` تُحفظ كـ `؛,،` في الملف لكن `Lexer.cpp:196,245` يعاملها `; ,` — المحرر يعرضها يمينية دون تحويل.
* **التحديد والنسخ:** `QPlainTextEdit::createMimeData` يحافظ على `UTF-8` عبر `UnicodeUtils::toCodepoints` — لا كسر للعربية.
* **الاختبار:** كتابة `صحيح س = 5 ؛` تظهر `؛` على اليسار البصري لكن منطقياً في نهاية السطر يميناً — اختبار `QTest::keyClickSequence("صحيح س = 5 ؛")`.

### 2.4 متطلب 2 — واجهة عربية 100%
* **القوائم:** كل `QAction::setText("...")` عربي — لا يوجد `File/Edit` — حتى رسائل الأخطاء `DiagnosticsEngine` عربية أصلاً `فشل التحويل مع الأخطاء`.
* **ملفات الترجمة:** `QTranslator` غير مطلوب لأن الأصل عربي — لكن `QLocale("ar")` يضمن `QFileDialog` عربي (`"افتح ملف ض"`).
* **الأيقونات:** نصوص فقط أو صور `PNG` مع `tooltip` عربي — لا `emoji`.

### 2.5 متطلب 3 — ممنوع الإيموجي (نصوص + صور فقط)
* **القاعدة:** يُمنع `U+1F000..U+1FFFF` في `QSS, QIcon, QMessageBox, QTextEdit` — حتى في التعليقات الداخلية.
* **البديل:** كل أيقونة `QIcon(":/icons/save.png")` من `resources.qrc` — `save.png (16x16), build.png, run.png, theme-light.png, theme-dark.png` — تصميم `SVG` أحادي اللون.

## 4. QSyntaxHighlighter — تلوين 107 نوع (VS Code-like)

### 4.1 القاموس
* يُبنى من `KeywordRegistry::getStandardKeywordRegistry()` + `TokenType` — لا قائمة يدوية. في `highlightBlock()`:
  ```cpp
  Lexer lexer(text); Token tok;
  while((tok=lexer.getNextToken()).type != TOKEN_EOF){
    QTextCharFormat fmt = formatFor(tok.type); // خريطة TokenType→QColor حسب الثيم
    setFormat(tok.column-1, tok.text.length(), fmt);
  }
  ```
* **الألوان حسب الثيم:**
  * فاتح: `أنواع #268bd2, تحكم #d33682, صنف #b58900, نص #2aa198, رقم #859900`

### 4.2 الميزات VS Code
* **RTL/فواصل عربية:** `؛ → ;` و `، → ,` تُلوّن كـ `SEMICOLON/COMMA` `Lexer.cpp:196,245`.
* **Bracket Matching:** `QTextCursor` يظلل القوس المقابل عند الوقوف على `{ } ( )`.
* **MiniMap:** `QPlainTextEdit` مصغر على اليسار (معكوس RTL) يعرض خريطة الملف.
