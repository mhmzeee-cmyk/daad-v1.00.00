## 3. الوصفات الجاهزة (انسخ وطبق)

### 3.1 وصفة كلمة منطقية/عادية جديدة (نموذج `ليس` — منجزة، للتوثيق والتكرار)

```cpp
// 1. Keywords.hpp — مجموعة المنطق العربي:
KwAndArabic, KwOrArabic, KwNotArabic,
// 2. Keywords.cpp — بجانب و/أو:
m_keywordToType["ليس"] = KeywordType::KwNotArabic;
// 3. Keywords.cpp — المكافئات:
case KeywordType::KwNotArabic: info.cppEquivalent = "!"; break;
// 4. Parser.cpp — فرع أحادي (كان موجودًا ميتًا):
if (TOKEN_KEYWORD && text == "ليس") { consume(); return Unary("!", parseUnary()); }
// 5. CodeGen.cpp — visit(Unary) موجودة تطبع (op operand)
// 6. JS — تحقق التطابق (KW_NOT + parseUnary + genExpr موجودة)
// 7. اختبار: إذا (ليس خطأ) → if ((!false)) → 1
```
