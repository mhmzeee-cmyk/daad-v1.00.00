## الفئة الأولى: ميزات الصنف (الأعلى أولوية)
> تغطي ~60 كود فاشل في الكتاب

### 1.1 كلمات محفوظة كأسماء متغيرات داخل الدوال
**المشكلة:** `صحيح` و `خطأ` و `منطقي` و `معلومات` هي كلمات محفوظة، لكن الكتاب يستخدمها كأسماء متغيرات:
```ض
منطقي صحيح = البريد.يحتوي("@");
امسك (خطأ أ) { ... }
```

**الحل:** في الـ Parser، بعد `KW_CONST` و `KW_BOOL`، نسمح باستخدام الكلمة المحفوظة كاسم متغير إذا كان في سياق تعريف متغير.

**الملفات:**
- `dhad-parser.js`: تعديل `parseVarDecl()` و `parseConstDecl()` لقبulaة الأسماء المحجوزة كأسماء
- `dhad-parser.js`: تعديل `parseTryCatch()` لقبulaة `خطأ` كمتغير امسك

**الوقت:** يوم واحد

---

### 1.2 بناء الصنف الكامل
**المشكلة:** `parseClass()` حالياً يقرأ `{ ... }` بشكل عام بدون معالجة خاصة.

**التحسينات المطلوبة:**

#### 1.2.1 الباني (Constructor)
```ض
صنف طالب {
    نص الاسم;
    صحيح العمر;

    طالب(نص اسم, صحيح عمر) {
        هذا.الاسم = اسم;
        هذا.العمر = عمر;
    }
}
```

**التعديلات:**
- `dhad-ast.js`: إضافة `ConstructorDeclAST(params, body)`
- `dhad-parser.js`: إضافة `parseConstructor()` — يتعرف على `اسم الصنف(...)` داخل الجسم
- `dhad-codegen.js`: تعديل `emitClasses()` للبحث عن `ConstructorDecl` واستخدامه كباني

#### 1.2.2 الوصول (عام/خاص/محمي)
```ض
صنف حساب_بنكي {
    عام نص رقم_الحساب;
    خاص نص كلمة_المرور;
    محمي صحيح الرصيد;

    عام دالة إيداع(صحيح مبلغ) { ... }
    خاص دالة تحديث() { ... }
}
```

**التعديلات:**
- `dhad-ast.js`: إضافة حقل `access` لـ `VarDeclStmtAST` و `FunctionDeclAST`
- `dhad-parser.js`: تعديل `parseClass()` لقراءة `عام`/`خاص`/`محمي` قبل كل عضو
- `dhad-codegen.js`: `خاص` → متغير محلي داخل closure، `عام` → `this.x`

#### 1.2.3 الوراثة
```ض
صنف حيوان {
    نص الاسم;
    دالة صوت() { ارجع "أصوات"; }
}

صنف كلب يرث حيوان {
    دالة صوت() { ارجع "نبarking"; }
}
```

**التعديلات:**
- `dhad-parser.js`: تعديل `parseClass()` للبحث عن `يرث اسم الصنف` بعد الاسم
- `dhad-ast.js`: إضافة حقل `parent` لـ `ClassDeclAST`
- `dhad-codegen.js`: إضافة `ChildClass.prototype = Object.create(ParentClass.prototype)`

#### 1.2.4 الأعضاء الثابتة (ساكن)
```ض
صنف عداد {
    ساكن صحيح عدد_الكائنات = 0;
    ساكن دالة عد() { ارجع عدد_الكائنات; }
}
```

**التعديلات:**
- `dhad-ast.js`: إضافة حقل `isStatic` لـ `VarDeclStmtAST` و `FunctionDeclAST`
- `dhad-parser.js`: قراءة `ساكن` قبل نوع العضو
- `dhad-codegen.js`: `static` members → `ClassName.member = value` بدلاً من `this.member`

**الوقت:** 3 أيام

### 1.3 جديد داخل تعريف مصفوفة صنف
```ض
طالب[] الطلاب = [
    جديد طالب("أحمد", 20),
    جديد طالب("سارة", 21)

```

- `dhad-codegen.js`: التأكد من أن `new ClassName()` يعمل داخل array literal

**الوقت:** نصف يوم

## الفئة الثانية: ميزات التعبيرات
> تغطي ~20 كود فاشل

### 2.1 العامل الشرطي (الثلاثي) `? :`
```ض
صحيح أ = 5;
صحيح النتيجة = أ > 0 ? أ * 2 : 0;
طباعة(النتيجة);  // 10
```

**التعديلات:**
- `dhad-lexer.js`: إضافة `QUESTION: '?'` و `COLON: ':'` (COLON موجود بالفعل)
- `dhad-parser.js`: إضافة parsing بعد `parseBinaryExpr` — إذا جاء `?` بعد التعبير
- `dhad-ast.js`: إضافة `TernaryExprAST(condition, trueExpr, falseExpr)`
- `dhad-codegen.js`: `case 'TernaryExpr': return '(' + cond + ' ? ' + true + ' : ' + false + ')'`

**الوقت:** نصف يوم

---

### 2.2 الدوال closures / Lambda
```ض
دالة إنشاء_عداد(صحيح البداية) {
    صحيح العد = البداية;
    دالة زاد() {
        العد += 1;
        ارجع العد;
    }
    ارجع زاد;
}

دالة العداد = إنشاء_عداد(0);
طباعة(العداد());  // 1
طباعة(العداد());  // 2
```

**التعديلات:**
- `dhad-codegen.js`: تعديل `emitFunctionDecl()` — الدوال الداخلية تحفظ المتغيرات من الـ scope الخارجي تلقائياً (JS closures تشتغل تلقائياً)
- لا يتطلب تعديلات في الـ Parser (الكود الحالي يمرر)

**الوقت:** نصف يوم (اختبار وتأكد أن closures تعمل)

### 2.3 الدالة كمعامل (محسّن)
```ض
دالة لكل_عنصر(صحيح[] القائمة, دالة العملية) {
    لكل (صحيح عداد في القائمة) {
        العملية(عداد);
    }
}
```

**ملاحظة:** هذا يمر بالفعل! لكن يحتاج اختبار closures مع for-each.

**الوقت:** اختبار فقط

## الفئة الثالثة: المؤشرات والمراجع
> تغطي ~10 كود فاشل

### 3.1 المؤشرات `*` والعنوان `&`
```ض
صحيح القيمة = 42;
صحيح* المؤشر = &القيمة;
طباعة(*المؤشر);  // 42
```

**الحل في JavaScript:** المؤشرات والمراجع ستكون no-op (identities) لأن JS لا يدعمها.

**التعديلات:**
- `dhad-parser.js`: دعم `&` كعامل unary (address-of) و `*` كعامل unary (dereference)
- `dhad-codegen.js`: `*expr` → `expr` و `&expr` → `expr` (no-op)

**الوقت:** نصف يوم

## الفئة الرابعة: ميزات متقدمة
> تغطي ~30 كود فاشل

### 4.1 القائمة المختلطة (mixed array)
```ض
قائمة بيانات = [1, "مرحبا", صواب, 3.14];
```

**التعديلات:**
- `dhad-lexer.js`: إضافة `KW_LIST` → `قائمة`
- `dhad-parser.js`: `قائمة` كنوع variable declaration
- `dhad-codegen.js`: `قائمة` → `var` (بدون type)

**الوقت:** نصف يوم

---

### 4.2 `طول()` كدالة
```ض
صحيح[] أ = [1, 2, 3];
طباعة(طول(أ));  // 3
```

**التعديلات:**
- `dhad-parser.js`: `طول` كدالة مدمجة في `parsePrimary()`
- `dhad-codegen.js`: `طول(x)` → `x.length`

**الوقت:** ربع يوم

---

### 4.3 `خطأ` كمتغير امسك
```ض
حاول {
    ...
} امسك (خطأ أ) {
    طباعة("خطأ: " + أ);
}
```

**التعديلات:**
- `dhad-parser.js`: تعديل `parseTryCatch()` — السماح بكلمة محفوظة `خطأ` كاسم المتغير

**الوقت:** ربع يوم

---

### 4.4 `بانتظار` (async/await)
```ض
دالة جلب() بانتظار {
    نص البيانات = بانتظار جلب_بيانات();
    ارجع البيانات;
}
```

**التعديلات:**
- `dhad-parser.js`: قراءة `بانتظار` بعد `دالة` → flag `isAsync`
- `dhad-ast.js`: إضافة حقل `isAsync` لـ `FunctionDeclAST`
- `dhad-codegen.js`: `function async` → `async function`

**الوقت:** نصف يوم

---

### 4.5 `استورد` / `صدّر` (modules)
```ض
استورد "حسابات";
صدّر دالة اجمع;
```

**التعديلات:**
- `dhad-parser.js`: معالجة `استورد "اسم"` و `صدّر اسم`
- `dhad-ast.js`: `ImportDeclAST(path)`, `ExportDeclAST(name)`
- `dhad-codegen.js`: `import` → `require()`, `export` → `module.exports`

**الوقت:** نصف يوم

## ملخص الإنجاز

### الملفات المعدلة:
- `dhad-lexer.js`: `AMPERSAND`, `KW_AWAIT` (بانتظار), `KW_IN` (في)
- `dhad-ast.js`: `ForEachStmtAST`, `ConstructorDeclAST`, `TernaryExprAST`, `ImportStmtAST`, `ExportStmtAST`, حقول `access`/`isStatic`/`parent`

## ملاحظات تقنية

1. **لا نكسر الكود الحالي** — 75/75 اختبار تمر، يجب أن تبقى كما هي
2. **الأولوية للكتاب** — نركز على الميزات التي في الكتاب أولاً
3. **JS closures تشتغل تلقائياً** — لا يتطلب تعديلات خاصة
4. **المؤشرات no-op** — JS لا يدعمها، نترجمها لـ identity
5. **`خطأ` كمتغير** — يتطلب تعديل بسيط في `parseTryCatch`
6. **`عام`/`خاص`** — في JS نستخدم convention: خاص = closure variable، عام = this.x
7. **async/await** — JS يدعمها مباشرة: `async function`
8. **import/export** — نستخدم `require()`/`module.exports` لـ Node.js
