# 1. هياكل البيانات (Data Structures) - 10 وحدات

## 1.1 الأكوام والمكدسات (Stacks & Queues)

**الملف:** stdlib/هياكل_البيانات/الأكوام_والمكدسات.ض

**الوصف:** توفر هذه الوحدة هيكلي البيانات الأساسيين: المكدس (Stack - LIFO) والطابور (Queue - FIFO). المكدس يعمل ككومة حيث آخر عنصر يُدخل هو أول عنصر يُخرج. الطابور يعمل كصف حيث أول عنصر يُدخل هو أول عنصر يُخرج.

**الدوال الرئيسية:**

| الدالة | التوقيع | الوصف |
|--------|---------|-------|
| \إنشاء_مكدس\ | \() -> صحيح\ | إنشاء مكدس جديد وإرجاع معرفه |
| \ادفع_المكدس\ | \(مكدس صحيح, قيمة صحيح) -> صحيح\ | دفع قيمة إلى أعلى المكدس (push) |
| \أخرج_المكدس\ | \(مكدس صحيح) -> صحيح\ | إخراج وإرجاع القيمة من أعلى المكدس (pop) |
| \.peek_المكدس\ | \(مكدس صحيح) -> صحيح\ | الاطلاع على أعلى قيمة بدون إخراجها (peek) |
| \فارغ_المكدس\ | \(مكدس صحيح) -> صحيح\ | التحقق مما إذا كان المكدس فارغاً |
| \حجم_المكدس\ | \(مكدس صحيح) -> صحيح\ | إرجاع عدد العناصر في المكدس |
| \مسح_المكدس\ | \(مكدس صحيح)\ | مسح جميع العناصر من المكدس |
| \إنشاء_كوّة\ | \() -> صحيح\ | إنشاء طابور (Queue) جديد |
| \أدخل_الكوّة\ | \(كوّة صحيح, قيمة صحيح) -> صحيح\ | إدخال قيمة في نهاية الطابور (enqueue) |
| \أخرج_الكوّة\ | \(كوّة صحيح) -> صحيح\ | إخراج قيمة من بداية الطابور (dequeue) |

**مثال استخدام:**
\\\daad
// إنشاء مكدس واختبار عملياته
صحيح مكدسي = إنشاء_مكدس()
ادفع_المكدس(مكدسي, 10)
ادفع_المكدس(مكدسي, 20)
ادفع_المكدس(مكدسي, 30)
طباعة(أخرج_المكدس(مكدسي)) // 30
طباعة(أخرج_المكدس(مكدسي)) // 20

// إنشاء طابور
صحيح طابوري = إنشاء_كوّة()
أدخل_الكوّة(طابوري, 1)
أدخل_الكوّة(طابوري, 2)
أدخل_الكوّة(طابوري, 3)
طباعة(أخرج_الكوّة(طابوري)) // 1
طباعة(أخرج_الكوّة(طابوري)) // 2
\\\

**التطبيق C++ المقابل:**
\\\cpp
#include <stack>
#include <queue>

std::stack<int> s;
s.push(10); s.push(20); s.push(30);
int top = s.top(); s.pop(); // 30

std::queue<int> q;
q.push(1); q.push(2); q.push(3);
int front = q.front(); q.pop(); // 1
\\\

## 1.2 القوائم المرتبطة (Linked Lists)

**الملف:** \stdlib/هياكل_البيانات/القوائم_المرتبطة.ض\

**الوصف:** تنفيذ القائمة المرتبطة (Linked List) وهي بنية بيانات خطية تتكون من عقد (nodes) حيث كل عقدة تحتوي على بيانات ومؤشر للعقدة التالية. تدعم الإدراج والحذف من أي موضع بكفاءة.

**الدوال الرئيسية:**

| الدالة | التوقيع | الوصف |
|--------|---------|-------|
| \إنشاء_قائمة_مرتبطة\ | \() -> صحيح\ | إنشاء قائمة مرتبطة جديدة |
| \إضافة_عقدة\ | \(قائمة صحيح, قيمة صحيح) -> صحيح\ | إضافة عقدة في نهاية القائمة |
| \إدراج_عقدة\ | \(قائمة صحيح, موقع صحيح, قيمة صحيح) -> صحيح\ | إدراج عقدة في موقع محدد |
| \حذف_عقدة\ | \(قائمة صحيح, قيمة صحيح) -> صحيح\ | حذف عقدة بقيمة محددة |
| \البحث_في_القائمة\ | \(قائمة صحيح, قيمة صحيح) -> صحيح\ | البحث عن قيمة في القائمة |
| \حجم_القائمة_المرتبطة\ | \(قائمة صحيح) -> صحيح\ | إرجاع عدد العقد |
| \طباعة_القائمة\ | \(قائمة صحيح)\ | طباعة جميع عناصر القائمة |
| \تفريغ_القائمة\ | \(قائمة صحيح)\ | حذف جميع العقد |
| \عكس_القائمة\ | \(قائمة صحيح) -> صحيح\ | عكس ترتيب القائمة |
| \دمج_قائمتين\ | \(ق1 صحيح, ق2 صحيح) -> صحيح\ | دمج قائمتين مرتبطتين |

**مثال استخدام:**
\\\daad
صحيح ق = إنشاء_قائمة_مرتبطة()
إضافة_عقدة(ق, 5)
إضافة_عقدة(ق, 10)
إضافة_عقدة(ق, 15)
إدراج_عقدة(ق, 1, 7) // إدراج 7 في الموقع 1
طباعة_القائمة(ق) // 5 -> 7 -> 10 -> 15
طباعة(حجم_القائمة_المرتبطة(ق)) // 4
حذف_عقدة(ق, 10)
طباعة_القائمة(ق) // 5 -> 7 -> 15
\\\

**التطبيق C++ المقابل:**
\\\cpp
#include <list>
std::list<int> lst;
lst.push_back(5); lst.push_back(10); lst.push_back(15);
auto it = lst.begin(); std::advance(it, 1);
lst.insert(it, 7);
lst.remove(10);
// lst: 5, 7, 15
\\\

## 1.3 المصفوفات الديناميكية (Dynamic Arrays)

**الملف:** \stdlib/هياكل_البيانات/المصفوفات_الديناميكية.ض\

**الوصف:** مصفوفة ديناميكية (ArrayList/Vector) تنمو تلقائياً عند إضافة عناصر جديدة. توفر وصولاً عشوائياً سريعاً O(1) مع إمكانية الإضافة والحذف في النهاية بكفاءة.

**الدوال الرئيسية:**

| الدالة | التوقيع | الوصف |
|--------|---------|-------|
| \إنشاء_مصفوفة_ديناميكية\ | \() -> صحيح\ | إنشاء مصفوفة ديناميكية فارغة |
| \أضف_عنصر\ | \(مصفوفة صحيح, قيمة صحيح) -> صحيح\ | إضافة عنصر في النهاية |
| \أدخل_في_موقع\ | \(مصفوفة صحيح, موقع صحيح, قيمة صحيح) -> صحيح\ | إدراج عنصر في موقع محدد |
| \احصل_من_موقع\ | \(مصفوفة صحيح, موقع صحيح) -> صحيح\ | الحصول على عنصر بموقعه |
| \عدّل_في_موقع\ | \(مصفوفة صحيح, موقع صحيح, قيمة صحيح) -> صحيح\ | تعديل عنصر في موقع |
| \احذف_من_موقع\ | \(مصفوفة صحيح, موقع صحيح) -> صحيح\ | حذف عنصر من موقع |
| \حجم_المصفوفة\ | \(مصفوفة صحيح) -> صحيح\ | عدد العناصر الحالية |
| \سعة_المصفوفة\ | \(مصفوفة صحيح) -> صحيح\ | السعة الحالية للمصفوفة |
| \هل_فارغة\ | \(مصفوفة صحيح) -> صحيح\ | التحقق مما إذا كانت فارغة |
| \تصغير_السعة\ | \(مصفوفة صحيح)\ | تصغير السعة لتتناسب مع الحجم |

**مثال استخدام:**
\\\daad
صحيح دين = إنشاء_مصفوفة_ديناميكية()
أضف_عنصر(دين, 10)
أضف_عنصر(دين, 20)
أضف_عنصر(دين, 30)
أدخل_في_موقع(دين, 1, 15) // [10, 15, 20, 30]
طباعة(احصل_من_موقع(دين, 2)) // 20
احذف_من_موقع(دين, 0) // [15, 20, 30]
طباعة(حجم_المصفوفة(دين)) // 3
\\\

**التطبيق C++ المقابل:**
\\\cpp
#include <vector>
std::vector<int> v;
v.push_back(10); v.push_back(20); v.push_back(30);
v.insert(v.begin() + 1, 15);
int x = v[2]; // 20
v.erase(v.begin()); // v: [15, 20, 30]
\\\

## 1.4 الخرائط والمجموعات (Maps & Sets)

**الملف:** \stdlib/هياكل_البيانات/الخرائط_والمجموعات.ض\

**الوصف:** تنفيذ خريطة التجزئة (HashMap/Dictionary) والمجموعة (Set). الخريطة تخزن أزواج مفتاح-قيمة، والمجموعة تخزن قيماً فريدة بدون ترتيب محدد.

**الدوال الرئيسية - الخريطة:**

| الدالة | التوقيع | الوصف |
|--------|---------|-------|
| \إنشاء_خريطة\ | \() -> صحيح\ | إنشاء خريطة تجزئة جديدة |
| \وضع_في_خريطة\ | \(خريطة صحيح, مفتاح نص, قيمة صحيح) -> صحيح\ | إضافة زوج مفتاح-قيمة |
| \احصل_من_خريطة\ | \(خريطة صحيح, مفتاح نص) -> صحيح\ | الحصول على قيمة بمفتاحها |
| \هل_يوجد_مفتاح\ | \(خريطة صحيح, مفتاح نص) -> صحيح\ | التحقق من وجود مفتاح |
| \احذف_مفتاح\ | \(خريطة صحيح, مفتاح نص) -> صحيح\ | حذف زوج بمفتاحه |
| \حجم_الخريطة\ | \(خريطة صحيح) -> صحيح\ | عدد الأزواج في الخريطة |
| \المفاتيح\ | \(خريطة صحيح) -> صحيح[]\ | إرجاع جميع المفاتيح |
| \القيم\ | \(خريطة صحيح) -> صحيح[]\ | إرجاع جميع القيم |

**الدوال الرئيسية - المجموعة:**

| الدالة | التوقيع | الوصف |
|--------|---------|-------|
| \إنشاء_مجموعة\ | \() -> صحيح\ | إنشاء مجموعة جديدة |
| \أضف_لمجموعة\ | \(مجموعة صحيح, قيمة صحيح) -> صحيح\ | إضافة قيمة للمجموعة |
| \هل_في_مجموعة\ | \(مجموعة صحيح, قيمة صحيح) -> صحيح\ | التحقق من وجود قيمة |
| \احذف_من_مجموعة\ | \(مجموعة صحيح, قيمة صحيح) -> صحيح\ | حذف قيمة من المجموعة |
| \حجم_المجموعة\ | \(مجموعة صحيح) -> صحيح\ | عدد العناصر الفريدة |
| \تقاطع_مجموعات\ | \(م1 صحيح, م2 صحيح) -> صحيح\ | تقاطع مجموعتين |
| \اتحاد_مجموعات\ | \(م1 صحيح, م2 صحيح) -> صحيح\ | اتحاد مجموعتين |
| \الفرق_بين_مجموعتين\ | \(م1 صحيح, م2 صحيح) -> صحيح\ | الفرق بين مجموعتين |

**مثال استخدام:**
\\\daad
// استخدام الخريطة
صحيح خ = إنشاء_خريطة()
وضع_في_خريطة(خ, "أحمد", 95)
وضع_في_خريطة(خ, "سارة", 88)
وضع_في_خريطة(خ, "محمد", 92)
طباعة(احصل_من_خريطة(خ, "أحمد")) // 95
إذا(هل_يوجد_مفتاح(خ, "سارة")) {
    طباعة("سارة موجودة")
}

// استخدام المجموعة
صحيح م = إنشاء_مجموعة()
أضف_لمجموعة(م, 1)
أضف_لمجموعة(م, 2)
أضف_لمجموعة(م, 3)
أضف_لمجموعة(م, 1) // لن تُضاف (مكررة)
طباعة(حجم_المجموعة(م)) // 3
\\\

**التطبيق C++ المقابل:**
\\\cpp
#include <unordered_map>
#include <unordered_set>

std::unordered_map<std::string, int> m;
m["أحمد"] = 95; m["سارة"] = 88;

std::unordered_set<int> s;
s.insert(1); s.insert(2); s.insert(3);
\\\

## 1.5 الأشجار الثنائية (Binary Trees)

**الملف:** \stdlib/هياكل_البيانات/الأشجار_الثنائية.ض\

**الوصف:** تنفيذ الشجرة الثنائية (Binary Tree) وشجرة البحث الثنائية (BST). الشجرة الثنائية هي هيكل بيانات غير خطي حيث لكل عقدة ولدان على الأكثر (أيسر وأيمن).

**الدوال الرئيسية:**

| الدالة | التوقيع | الوصف |
|--------|---------|-------|
| \إنشاء_شجرة\ | \() -> صحيح\ | إنشاء شجرة ثنائية فارغة |
| \إضافة_عقدة_شجرة\ | \(شجرة صحيح, قيمة صحيح) -> صحيح\ | إضافة عقدة للشجرة |
| \إضافة_عقدة_BST\ | \(شجرة صحيح, قيمة صحيح) -> صحيح\ | إضافة عقدة لشجرة بحث (مرتبة) |
| \بحث_في_BST\ | \(شجرة صحيح, قيمة صحيح) -> صحيح\ | بحث ثنائي في الشجرة |
| \اجتياز_بالعمق\ | \(شجرة صحيح) -> صحيح[]\ | اجتياز بالعمق أولاً (DFS) |
| \اجتياز_بالعرض\ | \(شجرة صحيح) -> صحيح[]\ | اجتياز بالعرض أولاً (BFS) |
| \اجتياز_منظم\ | \(شجرة صحيح) -> صحيح[]\ | اجتياز منظم (Inorder) |
| \اجتياز_قبلي\ | \(شجرة صحيح) -> صحيح[]\ | اجتياز قبلي (Preorder) |
| \اجتياز_بعدي\ | \(شجرة صحيح) -> صحيح[]\ | اجتياز بعدي (Postorder) |
| \ارتفاع_الشجرة\ | \(شجرة صحيح) -> صحيح\ | ارتفاع الشجرة |
| \حجم_الشجرة\ | \(شجرة صحيح) -> صحيح\ | عدد العقد في الشجرة |
| \حذف_عقدة_BST\ | \(شجرة صحيح, قيمة صحيح) -> صحيح\ | حذف عقدة من شجرة البحث |
| \هل_متوازنة\ | \(شجرة صحيح) -> صحيح\ | التحقق من توازن الشجرة |

**مثال استخدام:**
\\\daad
// إنشاء شجرة بحث ثنائية
صحيح ش = إنشاء_شجرة()
إضافة_عقدة_BST(ش, 50)
إضافة_عقدة_BST(ش, 30)
إضافة_عقدة_BST(ش, 70)
إضافة_عقدة_BST(ش, 20)
إضافة_عقدة_BST(ش, 40)
إضافة_عقدة_BST(ش, 60)
إضافة_عقدة_BST(ش, 80)

طباعة(بحث_في_BST(ش, 40)) // 1 (موجود)
طباعة(بحث_في_BST(ش, 100)) // -1 (غير موجود)
طباعة(ارتفاع_الشجرة(ش)) // 3

صحيح[] منظم = اجتياز_منظم(ش)
طباعة(منظم) // [20, 30, 40, 50, 60, 70, 80]
\\\

**التطبيق C++ المقابل:**
\\\cpp
struct Node { int val; Node *left, *right; };

Node* insertBST(Node* root, int v) {
    if (!root) return new Node{v, nullptr, nullptr};
    if (v < root->val) root->left = insertBST(root->left, v);
    else root->right = insertBST(root->right, v);
    return root;
}

void inorder(Node* root) {
    if (!root) return;
    inorder(root->left);
    std::cout << root->val << " ";
    inorder(root->right);
}
\\\

## 1.6 الرسوم البيانية (Graphs)

**الملف:** \stdlib/هياكل_البيانات/الرسوم_البيانية.ض\

**الوصف:** تنفيذ الرسم البياني (Graph) مع دعم الخوارزميات الأساسية: البحث بالعمق (DFS)، البحث بالعرض (BFS)، والمسار الأقصر (Dijkstra).

**الدوال الرئيسية:**

| الدالة | التوقيع | الوصف |
|--------|---------|-------|
| \إنشاء_رسم_بياني\ | \() -> صحيح\ | إنشاء رسم بياني جديد |
| \إضافة_عقدة\ | \(رسم صحيح, عقدة صحيح) -> صحيح\ | إضافة عقدة للرسم |
| \إضافة_حافة\ | \(رسم صحيح, من صحيح, إلى صحيح) -> صحيح\ | إضافة حافة بين عقدتين |
| \إضافة_حافة_موزونة\ | \(رسم صحيح, من صحيح, إلى صحيح, وزن صحيح) -> صحيح\ | إضافة حافة بوزن |
| \حذف_حافة\ | \(رسم صحيح, من صحيح, إلى صحيح) -> صحيح\ | حذف حافة |
| \جيران\ | \(رسم صحيح, عقدة صحيح) -> صحيح[]\ | الحصول على جيران عقدة |
| \BFS\ | \(رسم صحيح, بداية صحيح) -> صحيح[]\ | بحث بالعرض أولاً |
| \DFS\ | \(رسم صحيح, بداية صحيح) -> صحيح[]\ | بحث بالعمق أولاً |
| \دياجسترا\ | \(رسم صحيح, بداية صحيح, نهاية صحيح) -> صحيح[]\ | أقصر مسار (Dijkstra) |
| \هل_موصول\ | \(رسم صحيح, ع1 صحيح, ع2 صحيح) -> صحيح\ | التحقق من وجود اتصال |
| \عدد_العقد\ | \(رسم صحيح) -> صحيح\ | عدد العقد |
| \عدد_الحواف\ | \(رسم صحيح) -> صحيح\ | عدد الحواف |

**مثال استخدام:**
\\\daad

## 1.8 المكدسات والقوائم المتقدمة (Advanced Stacks & Queues)

**الملف:** \stdlib/هياكل_البيانات/المكدسات_والقوائم_المتقدمة.ض\

**الوصف:** تنفيذات متقدمة: الطابور ذو الأولوية (Priority Queue) والمكدس المزدوج (Deque) والطابور الدائري (Circular Queue).

**الدوال الرئيسية:**

| الدالة | التوقيع | الوصف |
|--------|---------|-------|
| \إنشاء_طابور_أولوية\ | \() -> صحيح\ | إنشاء طابور أولوية |
| \أدخل_بأولوية\ | \(طابور صحيح, قيمة صحيح, أولوية صحيح) -> صحيح\ | إدخال بأولوية محددة |
| \أخرج_الأعلى\ | \(طابور صحيح) -> صحيح\ | إخراج العنصر الأعلى أولوية |
| \إنشاء_مكدس_مزدوج\ | \() -> صحيح\ | إنشاء مكدس مزدوج (Deque) |
| \ادفع_أمام\ | \(مكدس صحيح, قيمة صحيح) -> صحيح\ | دفع في الأمام |
| \ادفع_خلف\ | \(مكدس صحيح, قيمة صحيح) -> صحيح\ | دفع في الخلف |
| \أخرج_أمام\ | \(مكدس صحيح) -> صحيح\ | إخراج من الأمام |
| \أخرج_خلف\ | \(مكدس صحيح) -> صحيح\ | إخراج من الخلف |
| \إنشاء_طابور_دائري\ | \(حجم صحيح) -> صحيح\ | إنشاء طابور دائري |
| \أدخل_دائري\ | \(طابور صحيح, قيمة صحيح) -> صحيح\ | إدخال في الطابور الدائري |
| \أخرج_دائري\ | \(طابور صحيح) -> صحيح\ | إخراج من الطابور الدائري |

\\\daad

أدخل_بأولوية(ط, 30, 2) // أولوية متوسطة
طباعة(أخرج_الأعلى(ط)) // 20 (أعلى أولوية)

// مكدس مزدوج

ادفع_أمام(مزدوج, 2)
طباعة(أخرج_خلف(مزدوج)) // 1
\\\

**التطبيق C++ المقابل:**
\\\cpp

## 1.9 الهياكل المتهمة (Hash Structures)

**الوصف:** بنية بيانات التجزئة (Hash Table) الأساسية مع التعامل مع التصادمات باستخدام السلسلة (Chaining).

**الدوال الرئيسية:**

| الدالة | التوقيع | الوصف |
|--------|---------|-------|
| \إنشاء_جدول_تجزئة\ | \(حجم صحيح) -> صحيح\ | إنشاء جدول تجزئة بحجم محدد |

    int size;

**الوصف:** دوال الإحصاء الوصفي: المتوسط الحسابي، الوسيط، المنوال، التباين، الانحراف المعياري، والمدى.

**الدوال الرئيسية:**

| الدالة | التوقيع | الوصف |
|--------|---------|-------|
| \متوسط\ | \(صحيح[] بيانات) -> عشري\ | حساب المتوسط الحسابي (Mean) |
| \وسيط\ | \(صحيح[] بيانات) -> عشري\ | حساب الوسيط (Median) |
| \منوال\ | \(صحيح[] بيانات) -> صحيح\ | حساب المنوال (Mode) - القيمة الأكثر تكراراً |
| \تباين\ | \(صحيح[] بيانات) -> عشري\ | حساب التباين (Variance) |
| \انحراف_معياري\ | \(صحيح[] بيانات) -> عشري\ | حساب الانحراف المعياري (Std Dev) |
| \مجموع\ | \(صحيح[] بيانات) -> صحيح\ | مجموع القيم |
| \أصغر\ | \(صحيح[] بيانات) -> صحيح\ | أصغر قيمة في المصفوفة |
| \أكبر\ | \(صحيح[] بيانات) -> صحيح\ | أكبر قيمة في المصفوفة |
| \مدى\ | \(صحيح[] بيانات) -> صحيح\ | المدى (أكبر - أصغر) |
| \مجموع_مربعات\ | \(صحيح[] بيانات) -> صحيح\ | مجموع مربعات القيم |
| \متوسط_هندسي\ | \(صحيح[] بيانات) -> عشري\ | المتوسط الهندسي |
| \متوسط_توافقي\ | \(صحيح[] بيانات) -> عشري\ | المتوسط التوافقي |

**مثال استخدام:**
\\\daad
صحيح[] ب = [10, 20, 30, 40, 50]
طباعة(متوسط(ب)) // 30.0
طباعة(وسيط(ب)) // 30.0
طباعة(منوال(ب)) // 10 (إذا كانت كلها مختلفة، يرجع الأولى)
طباعة(تباين(ب)) // 200.0
طباعة(انحراف_معياري(ب)) // 14.14
طباعة(مجموع(ب)) // 150
طباعة(مدى(ب)) // 40
طباعة(متوسط_هندسي([2, 8])) // 4.0
\\\

**التطبيق C++ المقابل:**
\\\cpp
#include <numeric>
#include <algorithm>
#include <cmath>

double mean(const std::vector<int>& v) {
    return std::accumulate(v.begin(), v.end(), 0.0) / v.size();
}

double median(std::vector<int> v) {
    std::sort(v.begin(), v.end());
    if (v.size() % 2 == 0) return (v[v.size()/2 - 1] + v[v.size()/2]) / 2.0;
    return v[v.size()/2];
}

double variance(const std::vector<int>& v) {
    double m = mean(v);
    double sum = 0;
    for (int x : v) sum += (x - m) * (x - m);
    return sum / v.size();
}
\\\

long long permutation(int n, int r) {

    for (int i = 0; i < r; i++) p *= (n - i);

long long combination(int n, int r) {
    if (r > n - r) r = n - r;
    long long c = 1;
    for (int i = 0; i < r; i++)
        c = c * (n - i) / (i + 1);
    return c;
}

#include <random>
int random_between(int from, int to) {

## 2.6 المصفوفات الرياضية (Matrix Operations)

**الملف:** \stdlib/الرياضيات_والحساب/المصفوفات_الرياضية.ض\

**الوصف:** عمليات المصفوفات الرياضية: الجمع، الطرح، الضرب، المحدد، المقلوب، المنقول، والتحليل العددي للمصفوفات.

**الدوال الرئيسية:**

|--------|---------|-------|

| \ضرب_مصفوفات\ | \(م1 صحيح, م2 صحيح) -> صحيح\ | ضرب مصفوفتين |
| \ضرب_عدد_بمصفوفة\ | \(مصفوفة صحيح, عدد عشري) -> صحيح\ | ضرب عدد قياسي في مصفوفة |

**مثال استخدام:**

\\\cpp
#include <vector>
using Matrix = std::vector<std::vector<double>>;

Matrix add(const Matrix& a, const Matrix& b) {
    int n = a.size(), m = a[0].size();
    Matrix c(n, std::vector<double>(m));
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            c[i][j] = a[i][j] + b[i][j];
    return c;
}

Matrix multiply(const Matrix& a, const Matrix& b) {
    int n = a.size(), m = a[0].size(), p = b[0].size();
    Matrix c(n, std::vector<double>(p, 0));
    for (int i = 0; i < n; i++)
        for (int k = 0; k < m; k++)
            for (int j = 0; j < p; j++)
                c[i][j] += a[i][k] * b[k][j];
    return c;
}

## 2.8 الأعداد المركبة (Complex Numbers)

**الملف:** \stdlib/الرياضيات_والحساب/الأعداد_المركبة.ض\

**الوصف:** دعم كامل للأعداد المركبة (a+bi) مع العمليات الحسابية الأربعة، المعامل، السعة، المرافق، والتمثيل القطبي.

**الدوال الرئيسية:**

| الدالة | التوقيع | الوصف |
|--------|---------|-------|
| \إنشاء_عدد_مركب\ | \(حقيقي عشري, تخيلي عشري) -> صحيح\ | إنشاء عدد مركب |
| \جمع_مركب\ | \(ع1 صحيح, ع2 صحيح) -> صحيح\ | جمع عددين مركبين |
| \طرح_مركب\ | \(ع1 صحيح, ع2 صحيح) -> صحيح\ | طرح عددين مركبين |
| \ضرب_مركب\ | \(ع1 صحيح, ع2 صحيح) -> صحيح\ | ضرب عددين مركبين |
| \قسمة_مركب\ | \(ع1 صحيح, ع2 صحيح) -> صحيح\ | قسمة عددين مركبين |
| \معامل_مركب\ | \(ع صحيح) -> عشري\ | معامل (قيمة مطلقة) العدد المركب \|z\| |

| \مرافق_مركب\ | \(ع صحيح) -> صحيح\ | مرافق العدد المركب |
| \حقيقي\ | \(ع صحيح) -> عشري\ | الجزء الحقيقي |
| \تخيلي\ | \(ع صحيح) -> عشري\ | الجزء التخيلي |
| \تمثيل_قطبي\ | \(ع صحيح) -> نص\ | تمثيل العدد المركب قطبياً |
| \قوة_مركب\ | \(ع صحيح, أس صحيح) -> صحيح\ | رفع عدد مركب لأس |

**مثال استخدام:**
\\\daad
صحيح ع1 = إنشاء_عدد_مركب(3.0, 4.0)
صحيح ع2 = إنشاء_عدد_مركب(1.0, 2.0)

صحيح مجموع = جمع_مركب(ع1, ع2) // 4 + 6i
صحيح جداء = ضرب_مركب(ع1, ع2) // (3+4i)(1+2i) = -5 + 10i

طباعة(معامل_مركب(ع1)) // 5.0 (\|3+4i\| = 5)
طباعة(سعة_مركب(ع1)) // 53.13 درجة
طباعة(حقيقي(ع1)) // 3.0
طباعة(تخيلي(ع1)) // 4.0
طباعة(مرافق_مركب(ع1)) // 3 - 4i
طباعة(تمثيل_قطبي(ع1)) // "5∠53.13°"
\\\

**التطبيق C++ المقابل:**

\\\cpp
#include <cmath>
#include <functional>

double derivative(std::function<double(double)> f, double x) {
    double h = 1e-8;
    return (f(x + h) - f(x - h)) / (2 * h);
}

double integral(std::function<double(double)> f, double a, double b, int n = 1000) {
    double h = (b - a) / n;
    double sum = 0;
    for (int i = 0; i < n; i++)
        sum += f(a + i * h + h / 2);
    return sum * h;
}

double bisection(std::function<double(double)> f, double a, double b) {
    double c;
    do {
        c = (a + b) / 2;
        if (f(c) == 0.0) break;
        if (f(c) * f(a) < 0) b = c;
        else a = c;
    } while ((b - a) >= 1e-10);
    return c;
}

std::string replace_all(const std::string& s, const std::string& from, const std::string& to) {
    std::string result = s;
    size_t pos = 0;
    while ((pos = result.find(from, pos)) != std::string::npos) {
        result.replace(pos, from.length(), to);
        pos += to.length();
    }
    return result;
}

std::vector<std::string> regex_match(const std::string& s, const std::string& pattern) {
    std::regex re(pattern);
    std::smatch match;
    std::vector<std::string> results;
    std::string::const_iterator searchStart(s.cbegin());
    while (std::regex_search(searchStart, s.cend(), match, re)) {
        results.push_back(match[0]);
        searchStart = match.suffix().first;
    }
    return results;
}

## 3.8 التحويل الرمزي (Symbolic Conversion)

**الملف:** \stdlib/النصوص_والترميز/التحويل_الرمزي.ض\

**الوصف:** تحويل النصوص بين ترميزات الأحرف المختلفة: UTF-8, ASCII, Windows-1256, Unicode.

**الدوال الرئيسية:**

| الدالة | التوقيع | الوصف |
|--------|---------|-------|
| \تحويل_ترميز\ | \(نص s, من نص, إلى نص) -> نص\ | تحويل النص من ترميز لآخر |
| \إلى_UTF8\ | \(نص s) -> نص\ | تحويل النص إلى UTF-8 |
| \من_UTF8\ | \(نص s) -> نص\ | تحويل النص من UTF-8 |
| \إلى_ASCII\ | \(نص s) -> نص\ | تحويل النص إلى ASCII (فقدان الأحرف غير اللاتينية) |
| \إلى_Windows1256\ | \(نص s) -> صحيح[]\ | تحويل النص إلى ترميز Windows-1256 |
| \من_Windows1256\ | \(صحيح[] بايتات) -> نص\ | تحويل من Windows-1256 إلى نص |
| \إلى_Unicode\ | \(نص s) -> صحيح[]\ | تحويل النص إلى أكواد Unicode (code points) |
| \من_Unicode\ | \(صحيح[] رموز) -> نص\ | تحويل أكواد Unicode إلى نص |
| \تطبيع_عربي\ | \(نص s) -> نص\ | تطبيع النص العربي (توحيد أشكال الأحرف) |

**مثال استخدام:**
\\\daad

// Windows-1256
صحيح[] بايتات = إلى_Windows1256(عربي)
طباعة(طول(بايتات)) // عدد البايتات

// من Unicode

#include <map>
#include <chrono>

class Scheduler {
    std::map<int, std::thread> tasks;
    int nextId = 1;
public:
    int schedule(std::function<void()> f, int delay_ms) {
        int id = nextId++;
        tasks[id] = std::thread([f, delay_ms]() {
            std::this_thread::sleep_for(std::chrono::milliseconds(delay_ms));
            f();
        });
        tasks[id].detach();
        return id;
    }

    int repeat(std::function<void()> f, int interval_ms) {
        int id = nextId++;
        tasks[id] = std::thread([f, interval_ms, id, this]() {
            while (tasks.find(id) != tasks.end()) {
                std::this_thread::sleep_for(std::chrono::milliseconds(interval_ms));
                f();
            }
        });
        tasks[id].detach();
        return id;
    }

    void cancel(int id) {
        tasks.erase(id);
    }
};

#include <chrono>

class Timer {
    std::chrono::steady_clock::time_point start;
    std::chrono::milliseconds duration;
    bool running = false;

public:
    void start(int ms) {
        duration = std::chrono::milliseconds(ms);
        start = std::chrono::steady_clock::now();
        running = true;
    }

    void stop() { running = false; }

    int remaining() const {
        if (!running) return 0;
        auto elapsed = std::chrono::duration_cast<std::chrono::milliseconds>(
            std::chrono::steady_clock::now() - start).count();
        return std::max(0, (int)(duration.count() - elapsed));
    }

    bool isActive() const { return running && remaining() > 0; }
};

## 10.1 الخيوط (Threads)

**الملف:** \stdlib/الخيوط_والتزامن/الخيوط.ض\

**الوصف:** إنشاء وإدارة الخيوط (Threads) لتنفيذ المهام المتوازية.

**الدوال الرئيسية:**
| الدالة | التوقيع | الوصف |
|--------|---------|-------|
| \إنشاء_خيط\ | \(دالة صحيح) -> صحيح\ | إنشاء خيط جديد |
| \إنشاء_خيط_مع\ | \(دالة صحيح, معاملات صحيح[]) -> صحيح\ | إنشاء خيط بمعاملات |
| \انتظار_خيط\ | \(خيط صحيح)\ | انتظار انتهاء الخيط |
| \اسم_الخيط\ | \(خيط صحيح) -> نص\ | اسم الخيط الحالي |
| \الخيط_الحالي\ | \() -> صحيح\ | معرف الخيط الحالي |
| \خيط_نائم\ | \(مدة صحيح)\ | إيقاف الخيط مؤقتاً |
| \خيوط_نشطة\ | \() -> صحيح\ | عدد الخيوط النشطة |

**مثال استخدام:**
\\\daad
دالة مهمة(صحيح رقم) {
    لـ(صحيح أ = 0; أ < 5; أ++) {
        طباعة("خيط", رقم, ":", أ)
        خيط_نائم(100)
    }
}
صحيح خيط1 = إنشاء_خيط_مع(مهمة, [1])
صحيح خيط2 = إنشاء_خيط_مع(مهمة, [2])
انتظار_خيط(خيط1)
انتظار_خيط(خيط2)
طباعة("انتهى")
\\\

**التطبيق C++ المقابل:**
\\\cpp
#include <thread>
#include <chrono>
auto task = [](int id) {
    for(int i=0; i<5; i++) {
        std::cout << "Thread " << id << ": " << i << std::endl;
        std::this_thread::sleep_for(std::chrono::milliseconds(100));
    }
};
std::thread t1(task, 1);
std::thread t2(task, 2);
t1.join(); t2.join();
\\\
