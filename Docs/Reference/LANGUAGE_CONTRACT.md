# LANGUAGE_CONTRACT.md — عقد لغة «ض» (DAAD Track)
> كل سطر هنا مثبت بتنفيذ حقيقي (`Tests/real_regression.sh` 40/40 + `ctest` 11/11).
> غير المذكور = غير مدعوم أو غير مُتحقق — لا تفترضه.

## Types (مثبتة)
| ض | IR | الملاحظات |
|---|---|---|
| `رقم` | i64 | الأعداد الصحيحة الموقعة 64-بت |
| `رقم_عشري` | f64 | IEEE-754 double |
| `حرف`, `منطق` | i8 | موجودة في الأنواع؛ تغطية جزئية |
| `فراغ` | void | للدوال فقط |
| `نص` | ptr | سلاسل للطباعة (`اطبع("...")`) |

## Integer range (مثبت بالتنفيذ)
- الصالح: `-9223372036854775808 … 9223372036854775807` (شامل) — مختبر عند الحدود.
- خارج ذلك: تشخيص عربي `L011: عدد صحيح أكبر من الحد المسموح` + فشل البناء (لا تكميم صامت).
- ملاحظة: `-2147483648` تُكتب `0 - 2147483648` (الإشارة مفصولة عن الليترال).

## Float semantics (مثبتة)
- العمليات: `+ - * /` بين متغيرات وثوابت (مطابقة البت مع مرجع IEEE).
- الطباعة: عقدة `%.6f` — مثال: `3.14` ← `3.140000`، `8.0` ← `8.000000`، `-1.0` ← `-1.000000`.
- `NaN` ← `nan`، `+Inf` ← `inf`، `-Inf` ← `-inf`.
- القيد: الجزء الصحيح يجب أن يتسع في int64 (|v| < 9.22e18) وإلا فالأرقام حتمية غير معرفة.

## Operators (مثبتة بالتنفيذ)
- صحيح: `+ - * / %` + مقارنات (`== != < <= > >=` عبر `إذا`/`طالما`) — مختبرة.
- عشري: `+ - * /` + مقارنات السجلات — مختبرة. مقارنة (عشري مقابل ثابت) تعمل للقيم الموجبة فقط (مسار int-مؤقت — قيد موثق).
- ملاحظة: `+` ثنائية فقط — `أ + ب + ج` مرفوضة (`P001`)؛ استخدم التجميع الصريح `(أ + ب) + ج`.

## Statements / Functions (مثبتة)
- `إذا / وإلا`، `طالما`، `ارجع`، `متغير:`، استدعاء دوال حتى 6 وسائط، عودية مباشرة (مضروب، فيبوناتشي)، استدعاءات متداخلة.
- عودية متبادلة (A↔B): غير مختبرة — غير مدعومة رسميًا.

## Variables / Scopes
- متغيرات محلية للدوال عبر `متغير: اسم: نوع = قيمة`. نسخ المتغيرات (`س = ص`) سليمة.

## Input / Output
- `اطبع(عدد صحيح)` أي int64، `اطبع(عشري)` بعقدة %.6f، `اطبع("نص")`.
- `اطبع(ثابت)` مباشرة مدعوم (صحيح وعشري). `ادخل` موجود كمساعد runtime (تغطية e2e قديمة).

## Errors (مثبتة)
- `S001`: متغير غير معرف. `L011`: تجاوز حد الصحيح. `P001`: أخطاء تحليل (تُطبع وتُوقف البناء).
- أخطاء المعجم تُوقف البناء (بوابة L011)، مثل بوابتي التحليل والدلالة.

## Identifiers / Reserved (مثبتة)
- عربية ولاتينية. `و` محجوزة (تعني AND) ولا تصلح اسمًا. التطويل `هـ` (U+0640) مرفوض في المعرفات.
- `انتقل` (GOTO) مرفوضة بخطأ صريح — غير مدعومة بالتصميم.

## Explicitly unsupported
واجهات رسومية، ARM/RISC-V إنتاجي، `macOS/iOS/Android`، `async`، كائنات/أصناف في مسار DAAD (مسار Compiler العالي له `فئة` الخاصة به).
