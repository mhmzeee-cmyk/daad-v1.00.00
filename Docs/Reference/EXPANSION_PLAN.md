## المرحلة 1: مُحلل التواقيع (أساس كل شيء)
- سكربت بايثون يبني فهرسًا JSON لكل دالة في المكتبة:
  `{الاسم, الملف, أنواع_المعاملات[], نوع_الإرجاع, عدد_الأسطر}`
- القراءة من الـ.ض مباشرة بقواعد نفس محلل اللغة (نمط `دالة اسم(نوع معامل، ...) -> نوع`)
- **المخرج**: `stdlib_index.json` — لا توليد إلا عبره

## المرحلة 2: مولد واعٍ بالتوقيع (بدل القوالب العمياء)
لكل دالة أصلية ولّد حسب تصنيفها:
| التصنيف | ما يولَّد | مثال |
|---------|-----------|------|
| رياضية (معامل رقمي واحد) | `_مطلق` + `_صفرية` (فحص صفر) | `جذر_مطلق` |
| مصفوفات | `_معكوسة` + `_مرتبة` + `_مقتطعة(بداية،نهاية)` | `أضف_معكوسة` |
| نصوص | `_كلمات` (عدد كلمات) + `_كبيرة`/`_صغيرة` | `يحتوي_كلمات` |
| ملفات | `_آمنة` (فحص مقبض قبل الاستخدام) | `سجّل_آمن` |
- قاعدة صارمة: **نفس أنواع المعاملات الأصلية حرفيًا** من الفهرس — لا تخمين
- كل دالة مولدة تستدعي الأصل فقط بعد فحص حدودها

## المرحلة 3: ملفات متخصصة جديدة (النصف الثاني من الـ3×)
ملفات جديدة كاملة بدل تضخيم القديمة:
```
stdlib/math/الإحصاء.ض          (متوسط، وسيط، انحراف، توزيع)
stdlib/math/الفرز_والبحث.ض     (سريع، دمج، ثنائي)
stdlib/text/التحويلات.ض        (رقم↔نص عربي، قلب، تكرار)
stdlib/io/السجلات.ض            (append آمن، تدوير)
stdlib_arabic/...              (مقابلات عربية لكل ما سبق)
```
كل ملف جديد: ≥15 دالة + يُضاف لفهرس المرحلة 1 + يجتاز البوابة
