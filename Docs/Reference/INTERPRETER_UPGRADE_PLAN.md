# خطة تطوير المفسر السحابي (dhad.js)
## لدعم جميع ميزات الكتاب

**الحالة:** المفسر يدعم ~65% من ميزات الكتاب
**الهدف:** دعم 100% من ميزات الكتاب

## المرحلة 1: المحلل اللفظي (Lexer) — يومان

### 1.1 عوامل منطقية عربية
| الميزة | الكود | الملف |
|--------|-------|-------|
| `و` = AND | `صواب و خطأ` | dhad-lexer.js |
| `أو` = OR | `صواب أو خطأ` | dhad-lexer.js |
| `ليس` = NOT (بالفعل موجود) | | |

### 1.2 عامل الأس
| الميزة | الكود | الملف |
|--------|-------|-------|
| `^` = power | `2 ^ 3 = 8` | dhad-lexer.js + dhad-codegen.js |

### 1.3 فاصلة التعريف المتعدد
| الميزة | الكود | الملف |
|--------|-------|-------|

**ملفات التعديل:** `dhad-lexer.js`

## المرحلة 2: المحلل النحوي (Parser) — 3 أيام

### 2.1 تعريف متغيرات متعدد
```ض
صحيح أ = 1, ب = 2, ج = 3;
```
**التعديل:** `parseVarDecl()` — بعد الاسم، إذا جاء `,` استمر للاسم التالي

### 2.2 `ثابت` كنوع مستقل
```ض
ثابت سعر = 0.15;
ثابت عدد = 10;
```
**التعديل:** `parseStatement()` — case `KW_CONST` يدعم `ثابت اسم = قيمة` بدون نوع

### 2.3 حلقة `لكل ... في` (for-each)
```ض
صحيح[] قائمة = [1, 2, 3];
لكل (صحيح عداد في قائمة) {
    طباعة(عداد);
}

نص[] فواكه = ["تفاح", "موز"];
لكل (نص فاكهة في فواكه) {
    طباعة(فاكهة);
}
```
**التعديل:** `parseFor()` — إذا جاء `في` بدل `;` بعد التعريف، فهو for-each

### 2.4 قيم افتراضية للمعاملات
```ض
دالة احسب(صحيح أ, صحيح ب = 10) {
    ارجع أ + ب;
}
احسب(5);  // → 15
```
**التعديل:** `parseFunctionDecl()` — داخل الأقواس، إذا جاء `=` بعد اسمالمعامل

### 2.5 دالة كمعامل
```ض
دالة طبق(صحيح أ, صحيح ب, دالة العملية) {
    ارجع العملية(أ, ب);
}
```
**التعديل:** `isTypeKeyword()` — يدعم `دالة` كنوع

### 2.6 접근 مصفوفة بتعبير
```ض
صحيح[] أ = [10, 20, 30];
صحيح i = 1;
طباعة(أ[i]);  // → 20
```
**التعديل:** `parsePostfix()` — `[` يدعم تعبير ليس فقط ثابت

**ملفات التعديل:** `dhad-parser.js`

## المرحلة 3: مولّد الكود (CodeGen) — 3 أيام

### 3.1 عامل الأس `^`
```javascript
// ض: 2 ^ 3
// JS: Math.pow(2, 3)
```
**التعديل:** `genExpr()` case `BinaryExpr` — إذا `^` استخدم `Math.pow()`

### 3.2 عوامل عربية `و` / `أو`
```javascript
// ض: صواب و خطأ
// JS: (true && false)
```
**التعديل:** `genExpr()` — `و` → `&&`، `أو` → `||`

### 3.3 حلقة for-each
```javascript
// ض: لـكل (صحيح عداد في قائمة) { ... }
// JS: for (var عداد of قائمة) { ... }
```
**التعديل:** إضافة `ForEachStmtAST` + `emitForEach()`

### 3.4 قيم افتراضية
```javascript
// ض: دالة احسب(صحيح أ, صحيح ب = 10)
// JS: function احسب(أ, ب) { if (ب === undefined) ب = 10; ... }
```
**التعديل:** `emitFunctionDecl()` — إضافة فحص `undefined`

### 3.5 دالة كمعامل
```javascript
// ض: دالة طبق(أ, ب, دالة العملية)
// JS: function طبق(أ, ب, العملية) { ... }
```
**التعديل:** معالجة `دالة` كنوع → إنتاج paramName مباشرة

### 3.6 خصائص المصفوفات
```javascript
// ض: أ.طول        → JS: أ.length
// ض: أ.احذف(2)    → JS: أ.splice(2, 1)
// ض: أ.أضف(3)     → JS: أ.push(3)
// ض: أ.يحتوي(5)   → JS: أ.includes(5)
// ض: أ..findIndex(5) → JS: أ.indexOf(5)
```
**التعديل:** `genExpr()` case `MemberAccessExpr` — ترجمة الخصائص

### 3.7 خصائص النص
```javascript
// ض: س.طول              → JS: س.length
// ض: س.لأحرف_كبيرة()    → JS: س.toUpperCase()
// ض: س.لأحرف_صغيرة()    → JS: س.toLowerCase()
// ض: س.يحتوي("مر")      → JS: س.includes("مر")
// ض: س.يبدأ("مر")       → JS: س.startsWith("مر")
// ض: س.ينتهي("با")      → JS: س.endsWith("با")
// ض: س.قص من(0, 5)      → JS: س.slice(0, 5)
// ض: س.استبدل("أ","ب")  → JS: س.replace("أ","ب")
// ض: س.تقسيم("-")       → JS: س.split("-")
// ض: س.مزج(["أ","ب"])   → JS: س.concat(["أ","ب"])
```
**التعديل:** `genExpr()` case `MemberAccessExpr` — خريطة ترجمة كاملة

### 3.8 ثوابت في الكود المُولد
```javascript
// ض: ثابت عدد = 10;
// JS: const عدد = 10;  (بدل var)
```
**التعديل:** `emitVarDecl()` — إذا النوع يبدأ بـ `const` استخدم `const`

**ملفات التعديل:** `dhad-codegen.js`

## ملاحظات تقنية

- **لا نكسر الميزات الموجودة** — كل تعديل يُضاف كحالة جديدة
- **التوافق مع الكود القديم** — الكود القديم يجب أن يعمل كما كان
- **ال Księ errors بالعربية** — رسائل الخطأ تبقى بالعربية
- **الأداء** — لا نبطئ الترجمة (compile) بشكل ملحوظ
