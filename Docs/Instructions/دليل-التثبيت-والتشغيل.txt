  2. المنصة الكاملة (Dhad-Studio-Full) ★ موصى بها
═══════════════════════════════════════════════════════════════════════════════

  تحتوي على: السيرفر + الواجهة + الجسر + المترجم

  ── الطريقة السريعة ─────────────────────────────────────────────────────────

  1. افتح مجلد "Dhad-Studio-Full" على الفلاشة
  2. انقر مرتين على "Dhad-Studio.bat"
  3. انتظر حتى يظهر نص "Server running on port 3000"
  4. سيفتح المتصفح تلقائياً على: http://localhost:3000
  5. سجّل الدخول ببياناتك (انظر القسم 7)

  ── التشغيل اليدوي ──────────────────────────────────────────────────────────

  1. افتح Command Prompt (اضغط Start واكتب cmd)
  2. اكتب الأوامر التالية واحداً تلو الآخر:

     cd /d "المسار\Dhad-Studio-Full\server"

     مثال:
     cd /d "F:\Dhad-Studio-Full\server"

     npm install --production
     npx prisma generate
     npx prisma db push
     node src/index.js

  3. افتح المتصفح على: http://localhost:3000

  ── إيقاف السيرفر ───────────────────────────────────────────────────────────

  اضغط Ctrl+C في نافذة Command Prompt

  3. مترجم ض (Daad-Compiler)
═══════════════════════════════════════════════════════════════════════════════

  أداة سطر أوامر لترجمة ملفات .ض إلى كود C++

  ── التشغيل ─────────────────────────────────────────────────────────────────

  1. افتح Command Prompt
  2. اذهب إلى مجلد Daad-Compiler:

     cd /d "المسار\Daad-Compiler"

     مثال:
     cd /d "F:\Daad-Compiler"

  3. شغّل المترجم:

     daad-compiler.exe "المسار\الملف.ض"

     مثال:
     daad-compiler.exe examples\basic.ض

  ── الملفات المرافقة ────────────────────────────────────────────────────────

  • examples/       — أمثلة جاهزة بلغة ض
  • stdlib/          — مكتبة المعايير (English)
  • stdlib_arabic/   — مكتبة المعايير (العربية)
  • src/             — مصدر المترجم


═══════════════════════════════════════════════════════════════════════════════
  4. إضافة VS Code (VSCode-Extension)
═══════════════════════════════════════════════════════════════════════════════

  إضافة لـ VS Code لدعم ملفات .ض

  ── التثبيت ─────────────────────────────────────────────────────────────────

  الطريقة 1: عبر Command Prompt

  1. تأكد من تثبيت VS Code
  2. تأكد من تثبيت Node.js
  3. افتح Command Prompt
  4. اكتب:

     code --install-extension "المسار\VSCode-Extension"

     مثال:
     code --install-extension "F:\VSCode-Extension"

  ── المميزات ────────────────────────────────────────────────────────────────

  • تلوين صيغة البرمجة
  • قصاصات كود جاهزة
  • اختصار F9 لترجمة ملف .ض
  • تلميحات أثناء الكتابة

  5. تطبيق Electron (Dhad-Studio-Electron)
═══════════════════════════════════════════════════════════════════════════════

  تطبيق سطح مكتب يجمع السيرفر والواجهة معاً

  ── التشغيل ─────────────────────────────────────────────────────────────────

  1. افتح Command Prompt
  2. اكتب:

     cd /d "المسار\Dhad-Studio-Electron"

     مثال:
     cd /d "F:\Dhad-Studio-Electron"

     npm start

  3. سيفتح التطبيق تلقائياً

  ── ملاحظات ─────────────────────────────────────────────────────────────────

  • المجلد يحتوي على node_modules جاهزة (لا يحتاج npm install)
  • يجمع السيرفر + الواجهة في تطبيق واحد
  • يتطلب شاشة بحجم 1024×768 على الأقل

  6. واجهة الويب (Dhad-Studio-Web)
═══════════════════════════════════════════════════════════════════════════════

  ملفات HTML/CSS/JS فقط — يمكن رفعها على أي استضافة

  ── الاستخدام المحلي ────────────────────────────────────────────────────────

  الطريقة 1: عبر سيرفر المنصة الكاملة
  ────────────────────────────────────
  المنصة الكاملة (Dhad-Studio-Full) تخدم هذه الملفات تلقائياً عند فتح
  http://localhost:3000

  الطريقة 2: تشغيل مباشر في المتصفح
  ────────────────────────────────────
  1. افتح المتصفح
  2. اذهب إلى المجلد Dhad-Studio-Web
  3. اضغط زر Shift + كليك يمين
  4. اختر "Open in Terminal" أو "Open PowerShell here"
  5. اكتب: npx serve .
  6. افتح المتصفح على: http://localhost:3000

  ── الرفع على الاستضافة ────────────────────────────────────────────────────

  • Netlify: اسحب المجلد وأفلته على netlify.com/drop
  • Vercel: vercel deploy
  • أي استضافة: ارفع جميع الملفات عبر FTP

  8. استكشاف الأخطاء وإصلاحها
═══════════════════════════════════════════════════════════════════════════════

  ── "node" غير معروف ────────────────────────────────────────────────────────

  السبب: Node.js غير مثبّت أو غير موجود في PATH
  الحل:
  1. حمّل Node.js من https://nodejs.org
  2. ثبّته واختر "Add to PATH" أثناء التثبيت
  3. أعد تشغيل الكمبيوتر
  4. أعد فتح Command Prompt

  ── "Port 3000 already in use" ──────────────────────────────────────────────

  السبب: منفذ 3000 مستخدم من برنامج آخر
  الحل:
  1. افتح Task Manager (Ctrl+Shift+Esc)
  2. ابحث عن "node" في Processes
  3. أنهِ العملية (End Task)
  4. أعد تشغيل السيرفر

  ── الصفحة لا تفتح ──────────────────────────────────────────────────────────

  الحل:
  1. تأكد أن السيرفر يعمل (يظهر "Server running" في Terminal)
  2. افتح المتصفح يدوياً على: http://localhost:3000
  3. جرّب متصفح آخر

  ── "npm install" يأخذ وقتاً طويلاً ────────────────────────────────────────

  هذا طبيعي لأول مرة. الملفات بحجم حوالي 200MB.
  انتظر حتى يكتمل. لا تغلق النافذة.

  ── رسالة أمان من Windows ──────────────────────────────────────────────────

  إذا ظهرت رسالة "Windows protected your PC":
  1. اضغط "More info"
  2. اضغط "Run anyway"
  (هذا آمن — الملف مفتوح المصدر)

  ── "SQLite database is locked" ─────────────────────────────────────────────

  الحل:
  1. أغلق جميع نوافذ Command Prompt
  2. احذف ملف: server\prisma\dev-journal
  3. أعد تشغيل السيرفر

  ── الخطأ: "Cannot find module" ─────────────────────────────────────────────

  الحل:
  cd /d "مسارالمجلد\server"
  npm install --production
