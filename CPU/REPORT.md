# تقرير مشروع معالج ض — المعالج المخصص للغة العربية

## ملخص المشروع

بناء معالج مخصص بالكامل مصمم للعمل مع لغة البرمجة العربية "ض" (DAAD).
يشمل: معمارية ISA مخصصة، محاكي بالكامل بلغة C، مجمّع عربي، وبرامج اختبار.

---

## 1. المعمارية (ISA)

### المواصفات الأساسية

| الخاصية | القيمة |
|---------|--------|
| عرض البيانات | 4-bit (نيبل واحد) |
| عرض العنوان | 12-bit |
| حجم الذاكرة | 4096 نيبل |
| عدد السجلات | 8 بيانات + مح + أعلام |
| عدد التعليمات | 16+ تعليمة |
| الـ ABI | System V AMD64 (للتوافق) |

### نظام السجلات

```
س0 - س7  : سجلات بيانات 4-bit
مح       : المُراقب (Accumulator) 4-bit
أعلام    : Z(صفر) N(سالب) C(حمل)
PC       : عداد البرنامج 12-bit
SP       : مؤشر المكدس 4-bit
```

### مجموعة التعليمات

| الفئة | التعليمات |
|-------|----------|
| النقل | حمّل (load_imm), نقل (mov), اقرأ (load), خزن (store) |
| المكدس | ادفع (push), اسحب (pop) |
| الدوال | نداء (call), إرجاع (ret) |
| الحساب | جمع (add), طرح (sub), ضرب (mul), قسمة (div), باقي (mod), تبريد (neg) |
| المنطق | ومنطقي (and), أومنطقي (or), أوحصري (xor), ليس (not), shift_left, shift_right |
| القفز | قفز (jmp), قفز_إذا_صفر (jz), قفز_إذا_غيرصفر (jnz), قفز_إذا_حمل (jc), قفز_إذا_سالب (jn) |
| I/O | اطبع (print), اطبع_حرف (print_ch), ادخل (input) |
| النظام | توقف (halt), سكون (nop) |

### تنسيق التعليمة

```
تعليمات بسيطة: 8 بت (opcode 4-bit + operand 4-bit)
تعليمات موسعة: 12 بت (F0 + extension + operand/address)
```

## 2. المحاكي

### الملفات

| الملف | الوصف | الأسطر |
|-------|-------|--------|
| `src/main.c` | المحاكي + المجمّع + main | ~750 |
| `include/dhad_isa.h` | تعريفات المعمارية | ~120 |
| `Makefile` | نظام البناء | ~50 |

### الميزات

- **محاكاة كاملة**: جميع التعليمات تعمل بشكل صحيح
- **وضع DEBUG**: طباعة كل تعليمة أثناء التنفيذ
- **وضع HEX**: عرض الكود المجمّع
- **وضع STATE**: طباعة حالة المعالج بعد التنفيذ
- **حفظ binary**: حفظ البرنامج المجمّع كملف ثنائي
- **دعم Unicode**: التعليقات والتعليمات بالعربي بالكامل
- **معالجة `,` و `،`**: الفاصلة العربية والإنجليزية

---

## 3. المجمّع (Assembler)

### الميزات

- **تاخدثنات**: جمع التسميات أولاً ثم توليد الكود
- **pełna عربي**: جميع التعليمات والسجلات بالعربي
- **تسميات**: دعم التسميات (labels) بالعربي
- **أرقام hex**: دعم الأرقام العشرية والسداسية عشرية
- **معالجة Unicode**: الفاصلة العربية `،` (U+060C)

### أمثلة على الكود المجمّع

```asm
حمّل مح، 3       # → 18 03
حمّل س0، 5       # → 10 05
جمع س0           # → 90
اطبع             # → E0
توقف             # → 00
```

```
المخرج:  54321

```


## 6. خطة التوسع

### المرحلة 1: 4-bit (الحالية )
- 16+ تعليمة
- 256 بايت RAM
- مجمع عربي متكامل
- محاكي يعمل على Linux

### المرحلة 2: 8-bit (المستقبل)
- توسيع البيانات إلى 8-bit
- 256 تعليمة
- 64 KB ذاكرة
- ISA موسعة

### المرحلة 3: 16-bit
- 16-bit data path
- 65536 تعليمة
- 1 MB ذاكرة
- ISA كامل مع interrupt

### المرحلة 4: 32-bit
- معمارية كاملة
- تعدد المهام
- حماية الذاكرة
- نظام تشغيل عربي

## 7. ملاحظات تقنية

### المشاكل التي تم حلها
1. **الفاصلة العربية**: معالجة UTF-8 للـ `,` و `،`
2. **التسميات**: إصلاح تحليل `:` في نهاية التسمية
3. **تعليمات موسعة**: فصل القفز عن المنطق (避免 opcode conflict)
4. **encode ext**: إزالة البайت الإضافي غير الضروري في التعليمات非-القفز

### التحسينات المقترحة
- إضافة interrupt system
- إضافة hardware multiplier
- إضافة UART for I/O
- دعم DMA
-timer مدمج
