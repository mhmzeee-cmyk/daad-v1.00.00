# معمارية معالج ض (Dhad Processor Architecture)

## نظرة عامة

معالج ض هو معالج مخصص بالكامل مصمم للعمل مع لغة البرمجة العربية "ض" (DAAD).
مصمم ليكون بسيطاً وicielداً وقابلاً للتوسع من 4-bit إلى 32-bit.

---

## المواصفات الأساسية (الإصدار 4-bit)

| الخاصية | القيمة |
|---------|--------|
| عرض البيانات | 4-bit (نيبل واحد) |
| عرض العنوان | 12-bit |
| حجم الذاكرة | 4096 نيبل (2048 بايت) |
| عدد السجلات | 8 سجلات بيانات + 3 سجلات نظام |
| حجم التعليمة | 12-bit (نيبلان + نيبل واحد) |
| عدد التعليمات | 16 تعليمة أساسية |

## نظام السجلات

### سجلات البيانات (4-bit كل منها)
```
┌─────────────────────────────────────────────┐
│  س0 (صفر)  │缪2 بيت │ مسجل عامة            │
│  س1 (أحد)  │ 4 بت   │ مسجل عامة            │
│  س2 (اثنان)│ 4 بت   │ مسجل عامة            │
│  س3 (ثلاثة)│ 4 بت   │ مسجل عامة            │
│  س4 (أربعة)│ 4 بت   │ مسجل عامة            │
│  س5 (خمسة) │ 4 بت   │ مسجل عامة            │
│  س6 (ستة)  │ 4 بت   │ مسجل عامة            │
│  س7 (سبعة) │ 4 بت   │ مسجل عامة            │
│  مح (المح)  │ 4 بت   │ المُراقب (Accumulator) │
│  سл (العلم)│ 4 بت   │ سجل الأعلام           │
│  المío     │ 12 بت  │ عداد البرنامج (PC)     │
│  المكدس   │ 4 بت   │ مؤشر المكدس (SP)      │
└─────────────────────────────────────────────┘
```

### وصف السجلات
- **مح (المُراقب)**: السجل الرئيسي للعمليات الحسابية والمنطقية
- **س0-س7**: سجلات عامة متعددة الاستخدام
- **سجل الأعلام (Flags)**:
  -ビت 0: Z (الصفر) - النتيجة صفر
  -ビت 1: N (السالب) - النتيجة سالبة
  -ビت 2: H (الحمل) - وصل حمل
  -ビت 3: V (الفيض) - فيض/تلوث
- **عداد البرنامج (PC)**: 12-bit يشير إلى التعليمة التالية
- **مؤشر المكدس (SP)**: 4-bit يشير إلى أعلى عنصر في المكدس

## نموذج الذاكرة

### خريطة الذاكرة
```
العنوان    │ المحتوى
───────────┼─────────────────────
0xFFF      │ نهاية الذاكرة
0x800      │ بداية ROM (Program)
...        │ ...
0x100      │ نهاية ROM
0x0FF      │ بداية RAM (Data)
...        │ ...
0x020      │ نهاية RAM
0x01F      │ بداية I/O Ports
0x010      │ نهاية I/O
0x00F      │ أعلى المكدس (Stack)
...        │ ... (ينمو للأسفل)
0x000      │ بداية المكدس
```

### منافذ I/O (Memory-Mapped)
```
العنوان    │ الوظيفة
───────────┼──────────────────────
0x0F0      │ منفذ الإخراج (OUT)
0x0F1      │ منفذ الإدخال (IN)
0x0F2      │ سجل الحالة (Status)
```

## مجموعة التعليمات

### التعليمات الحسابية (Arithmetic)
```
ال opcode │ الكود    │ الوصف
──────────┼──────────┼──────────────────────
جمع       │ 0001     │ مح = مح + سج
طرح       │ 0010     │ مح = مح - سج
ضرب       │ 0011     │ مح = مح × سج
قسمة      │ 0100     │ مح = مح ÷ سج
باقي      │ 0101     │ مح = مح % سج
 זכה      │ 0110     │ مح = -مح (تبريد)
```

### التعليمات المنطقية (Logic)
```
 opcode   │ الكود    │ الوصف
──────────┼──────────┼──────────────────────
ومنطقي    │ 1000     │ مح = مح & سج
أومنطقي   │ 1001     │ مح = مح | سج
أو حصري   │ 1010     │ مح = مح ^ سج
ليس       │ 1011     │ مح = ~مح
تحريك_يمين│ 1100     │ مح = مح >> 1
تحريك_يسار│ 1101     │ مح = مح << 1
```

### تعليمات النقل (Data Transfer)
```
 opcode   │ الكود    │ الوصف
──────────┼──────────┼──────────────────────
حمل       │ 0000 +   │ سج = القيمة (فوري)
           │ operand  │
خزن       │ 0000 +   │ الذاكرة[سج2] = سج1
           │ operand  │
نقل       │ 0000 +   │ سج2 = سج1
           │ operand  │
```

### تعليمات التحكم (Control Flow)
```
 opcode   │ الكود    │ الوصف
──────────┼──────────┼──────────────────────
قفز       │ 0111     │ PC = العنوان (فوري)
إذا_صفر   │ 0111 +   │ إذا Z=1: PC = العنوان
إذا_غيرصفر│ 0111 +   │ إذا Z=0: PC = العنوان
نداء      │ 0000 +   │ دعوة دالة (push PC, jump)
إرجاع     │ 0000 +   │ ارجع من دالة (pop PC)
```

### تعليمات المكدس (Stack)
```
 opcode   │ الكود    │ الوصف
──────────┼──────────┼──────────────────────
ادفع      │ 0000 +   │ push مح to stack
اسحب      │ 0000 +   │ pop from stack to مح
```

### تعليمات الإدخال/الإخراج (I/O)
```
 opcode   │ الكود    │ الوصف
──────────┼──────────┼──────────────────────
اطبع     │ 1110     │ إخراج قيمة من المح
ادخل     │ 1111     │ إدخال قيمة إلى المح
توقف      │ 1110     │ إيقاف المعالج
```

## الأعلام (Flags)

| الاسم | البت | الشرح |
|-------|------|-------|
| Z (صفر) | 0 | النتيجة تساوي صفر |
| N (سالب) | 1 | النتيجة سالبة (bit 3 = 1) |
| H (حمل) | 2 | وصل حمل من bit 3 إلى bit 4 |
| V (فيض) | 3 | تلوث/فيض في العملية |

## خطة التوسع

### المرحلة 1: 4-bit (الحالية)
- معالج بسيط
- 16 تعليمة
- 256 بايت RAM
- مخصص للتعليم والأきっかけ

### المرحلة 2: 8-bit
- توسيع البيانات إلى 8-bit
- 256 تعليمة
- 64 KB ذاكرة
- ASA ثانية

### المرحلة 3: 16-bit
- 16-bit data path
- 65536 تعليمة
- 1 MB ذاكرة
- ISA كامل

### المرحلة 4: 32-bit
- معمارية كاملة
- تعدد المهام (Multitasking)
- حماية الذاكرة
- نظام تشغيل كامل

## أمثلة على التعليمات المجمّعة

```asm
# برنامج: جمع رقمين
حمّل س0، 5        # س0 = 5
حمّل س1، 3        # س1 = 3
نقل مح، س0        # مح = 5
جمع س1            # مح = 5 + 3 = 8
ادفع              # push مح (8) to stack
توقف              # end
```

```asm
# برنامج: عد تنازلي
حمّل س0، 10       # س0 = 10 (العداد)
بداية:
  اطبع             # طباعة المح (القيمة الحالية)
  حمّل س1، 1      # س1 = 1
 طرح س1           # مح = مح - 1
  إذا_غيرصفربداية # إذا مح ≠ 0، ارجع لبداية
توقف
```
