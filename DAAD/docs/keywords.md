## 1. مبادئ تصميم الكلمات المفتاحية

### 1.1 المعايير

كل كلمة مفتاحية في ض Core تتبع المعايير التالية:

1. **الوضوح:** الكلمة تعكس وظيفتها بوضوح
2. **العربية:** كل كلمة عربية بالكامل (لا إنجليزية)
3. **لا تكرار:** لا توجد كلمتان بنفس الوظيفة
4. **الطبيعية:** تبدو طبيعية في العربية
5. **سهولة الكتابة:** لا تحتوي على حروف صعبة الكتابة

### 1.2 نظام التسمية

- **الأفعال:** تبدأ بحرف الفعل (حمل, اجمع, اطرح)
- **الأسماء:** تبدأ بحرف الاسم (دالة, متغير, ثابت)
- **الشروط:** تبدأ بحرف الشرط (إذا, وإلا, طالما)
- **النهاية:** تنتهي بكلمة واضحة (نهاية)

### 3.0 قاعدة عامة
- **جميع** الكلمات في هذا القسم (3.1 إلى 3.11) محجوزة

## 4. قواعد تكوين الكلمات المفتاحية

### 4.1 الأفعال

- تبدأ بحرف الفعل (أو حرف الجذر)
- تكون مكونة من مقطع واحد أو مقطعين
- تعكس الفعل الحاسوبي

**أمثلة:**
- `حمل` (حمّل)
- `خزن` (خزّن)
- `اقرأ_ذاكرة` (اقرَأ)
- `اجمع` (اجمَع)
- `اطرح` (اطرَح)

### 4.2 الأسماء

- تبدأ بحرف الاسم
- تكون وصفية وواضحة
- قد تكون مركبة

**أمثلة:**
- `متغير` (変数)
- `ثابت` (定数)
- `دالة` (関数)
- `مصفوفة` (配列)
- `مؤشر_نوع` (ポインタ型)

### 4.3 الشروط

- تبدأ بحرف الشرط
- تكون واضحة ومباشرة

**أمثلة:**
- `إذا` (もし)
- `وإلا` (でなければ)
- `طالما` (while)
- `لكل` (for)

### 4.4 النهاية

- تنتهي بكلمة واضحة
- تدل على انتهاء البنيان

**أمثلة:**
- `نهاية` (终)

## 6. ملاحظات تقنية

### 6.1 الحساسية للحالة

- الكلمات المفتاحية حساسة لحالة الأحرف
- `حمل` و `حمّل` و `Hمل` كلها مختلفة
- يُنصح باستخدام الأحرف العربية صغيرة دائماً

### 6.2 الترميز

- يجب أن يكون الملف مُرمّز بـ UTF-8
- ترميز العربية: U+0600 إلى U+06FF

### 6.3 الطول الأقصى

- طول الكلمة المفتاحية: 32 حرف كحد أقصى
- طول اسم المتغير: 256 حرف كحد أقصى

## 7. أمثلة على الاستخدام

```ض
# مثال 1: تعريف متغير
متغير: عدد: رقم = 10

# مثال 2: شرط
إذا(عدد > 5) ->
    اطبع("العدد أكبر من 5")
نهاية

# مثال 3: حلقة
لكل(متغير: عداد = 0؛ العداد < 10؛ العداد = العداد + 1) ->
    اطبع(العداد)
نهاية

# مثال 4: دالة
دالة: اجمع(أ: رقم، ب: رقم) -> رقم :-
    ارجع(أ + ب)
نهاية

# مثال 5: مقارنة
إذا(عدد == 10) ->
    اطبع("العدد يساوي 10")
وإلا إذا(عدد > 10) ->
    اطبع("العدد أكبر من 10")
وإلا ->
    اطبع("العدد أصغر من 10")
نهاية

# مثال 6: عمليات بتية
متغير: أ: رقم = 0b1010
متغير: ب: رقم = 0b1100
متغير: ج: رقم = و_بتية(أ، ب)    # 0b1000
متغير: د: رقم = أو_بتية(أ، ب)   # 0b1110
متغير: هـ: رقم = تحريك_يسار(أ، 1)  # 0b10100

# مثال 7: مؤشرات
متغير: متغير: رقم = 10
متغير: مؤشر: مؤشر_نوع(رقم) = مؤشر(المتغير)
اقرأ_ذاكرة(سجل1، [المؤشر])    # سجل1 = 10
خزن([المؤشر]، 20)              # المتغير = 20

# مثال 8: هيكل
نوع: طالب = {
    الاسم: نص،
    العمر: رقم
}

متغير: ط1: طالب = { "أحمد"، 20 }
اطبع(ط1.الاسم)  # أحمد
```

## 9. ملاحظات ختامية

هذه هي القائمة المُحدّثة للكلمات المفتاحية في ض Core الإصدار 0.1.1.

**التغييرات عن الإصدار 0.1:**
1. فصل `نوع` عن `جلب_نوع`
2. استبدال `asil` بـ `و_بتية`
3. استبدال `shift_*` بـ `تحريك_*`
4. استبدال `bitwise_*` بـ عربي
5. حذف `عددي` واستبدالها بـ `رقم`
6. إضافة `نص` كنوع أساسي
7. إضافة `فراغ` كقيمة افتراضية
8. تحديد `خطأ` و `صحيح`
9. استبدال `عدّل` بـ `غيّر_حجم`
10. استبدال `أعلن` بـ `أطلق`
11. فصل `اقرأ` إلى three أنواع
12. إضافة `أدخل` و `ادرج`
13. تحديد `[]` و `.` و `@`
14. إضافة العاملات المختصرة
15. حذف جميع الكلمات الإنجليزية

**المبادئ التوجيهية:**
1. كل كلمة وظيفة واحدة
2. الكلمات عربية بالكامل
3. لا تكرار في الوظائف
4. سهولة التذكر والاستخدام
5. قرب من المفاهيم الحقيقية
