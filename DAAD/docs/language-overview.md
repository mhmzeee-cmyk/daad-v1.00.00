# ض Core - نظرة عامة على اللغة (الإصدار المُصحح)

**الإصدار:** 0.1.1 (بعد المراجعة)
**تاريخ الإصدار:** 2026-08-03
**الحالة:** مُعتمد

---

## 1. فلسفة اللغة

ض Core لغة برمجة منخفضة المستوى صُممت لتكون الجسر بين لغة التجميع (Assembly) واللغات عالية المستوى. الفكرة الأساسية هي تقديم واجهة عربية كاملة للبرمجة على مستوى المعالج، بحيث تبقى قريبة من الهاردوير مع توفير قابلية القراءة والصيانة.

المبدأ الأساسي: **"قريبة من المعالج، بعيدة عن التعقيد."**

لا تهدف اللغة إلى إخفاء الهاردوير أو تجريده، بل إلى تقديم طريقة عربية طبيعية للتعبير عن عمليات المعالج المنخفضة المستوى.

---

## 2. أهداف اللغة

### 2.1 الهدف الأساسي

- توفير لغة برمجة عربية منخفضة المستوى لا تعتمد على أي لغة أخرى
- السماح بالبرمجة المباشرة على المعالج بدون وسيط
- دعم الترجمة إلى معماريات متعددة (x86, x64, ARM64, RISC-V)
- الحفاظ على بساطة اللغة لسهولة تعلمها وتعليمها

### 2.2 الأهداف الفرعية

- تقليل حاجز اللغة للمبرمجين العرب
- إعطاء المبرمج العربي أدوات للبرمجة المنخفضة المستوى بلغته الأم
- إنشاء أساس لتطوير أنظمة تشغيل وبرامج نظام بلغة عربية
- تعليم مبادئ هندسة الحاسوب والمعالجات بطريقة عربية

---

## 3. لماذا أنشئت ض Core؟

### 3.1 المشكلة

معظم لغات البرمجة المنخفضة المستوى مكتوبة بالإنجليزية. هذا يخلق حاجزاً لغير الناطقين بالإنجليزية في مجال البرمجة المنخفضة المستوى. بينما توجد لغات عربية عالية المستوى، إلا أنه لا توجد لغة عربية صُممت خصيصاً للبرمجة على مستوى المعالج.

### 3.2 الحل

ض Core تقدم حلاً bằng:
- كلمات مفتاحية عربية بالكامل تعكس وظائف المعالج الحقيقية
- قواعد بسيطة تشبه طريقة التفكير في Assembly
- نموذج ذاكرة واضح يعكس هيكل الحاسوب الحقيقي
- قابلية للتوسع لدعم معماريات متعددة

### 3.3 الرؤية

أن تصبح ض Core اللغة المرجعية للبرمجة المنخفضة المستوى بالعربية، وأن تُستخدم في:
- تعليم هندسة الحاسوب
- تطوير أنظمة تشغيل
- كتابة برامج النظام
- ترجمة البرامج إلى أنظمة متنوعة

## 4. الفرق بين ض Core و Assembly

| الميزة | Assembly | ض Core |
|--------|----------|--------|
| **اللغة** | إنجليزية (MOV, ADD, SUB) | عربية بالكامل (حمل, اجمع, اطرح) |
| **المؤشرات** | مسجلات محددة (AX, BX) | سجلات مجردة (سجل1, سجل2) |
| **التعليقات** | تختلف حسب الم assembler | تنسيق موحد |
| **التنظيم** | سطر بسطر | بنيان أكثر تنظيماً |
| **القراءة** | صعبة للمبتدئين | مصممة للقراءة |
| **ال-portability** | مвяз بمعمارية واحدة | مستقلة عن المعماريات |
| **نهاية التعليمة** | تعتمد على ال assembler | نهاية السطر |
| **الأسماء** | مختصرات غامضة | كلمات وصفية عربية |

### مثال مقارن:

**Assembly (x86):**
```asm
section .data
    msg db 'Hello', 0

section .text
    global _start
_start:
    mov eax, 4
    mov ebx, 1
    mov ecx, msg
    mov edx, 5
    int 0x80
```

**ض Core:**
```ض
نوع_نص: رسالة = "مرحباً"

دالة: الرئيسية() :-
    حمل(سجل1، 4)
    حمل(سجل2، 1)
    حمل(سجل3، مؤشر(رسالة))
    حمل(سجل4، 5)
    استدعاء(نظام(80))
نهاية
```

## 5. الفرق بين ض Core و C

| الميزة | C | ض Core |
|--------|---|--------|
| **المستوى** | عالية-منخفضة | منخفضة جداً |
| **الذاكرة** | إدارة تلقائية (جزئية) | تحكم يدوي كامل |
| **السجلات** | غير مرئية مباشرة | مرئية وقابلة للتحكم |
| **النوعية** | نظام نوع قوي | بسيطة (أرقام/نصوص) |
| **التعقيد** | مؤشرات، هياكل، قوائم ارتباط | مباشر وبسيط |
| **الأمان** | لا يوجد حماية طبيعية | لا يوجد حماية (مثل Assembly) |
| **الاستخدام** | تطبيقات عامة | أنظمة و-low level |

### مثال مقارن:

**C:**
```c
int add(int a, int b) {
    return a + b;
}
```

**ض Core:**
```ض
دالة: اجمع(معامل1: عدد، معامل2: عدد) -> عدد :-
    حمل(سجل1، معامل1)
    اجمع(سجل1، معامل2)
    ارجع(سجل1)
نهاية
```

## 6. الفرق بين ض Core و Rust

| الميزة | Rust | ض Core |
|--------|------|--------|
| **الفلسفة** | الأمان أولاً | السيطرة أولاً |
| **نظام الملكية** | ملكية + اقتران حياة | غير موجود (تحكم يدوي) |
| **الحماية** | وقت التشغيل + وقت التجميع | لا يوجد (مثل C/Assembly) |
| **التعقيد** | منخفض-عالي | منخفض |
| **الاستخدام** | أنظمة موثوقة | أنظمة منخفضة المستوى |
| **التعلم** | منحنى تعلم حاد | بسيط نسبياً |

### مثال مقارن:

**Rust:**
```rust
fn add(a: i32, b: i32) -> i32 {
    a + b
}
```

**ض Core:**
```ض
دالة: اجمع(معامل1: عدد، معامل2: عدد) -> عدد :-
    حمل(سجل1، معامل1)
    اجمع(سجل1، معامل2)
    ارجع(سجل1)
نهاية
```

## 7. خصائص اللغة

### 7.1 الحالة (Case Sensitivity)

- اللغة حساسة لحالة الأحرف العربية
- `سجل1` و `سجل١` و `Sجل1` كلها مختلفة
- الأحرف الإنجليزية مدعومة داخل الأسماء لكن بالحالة

### 7.2 نظام الأرقام

- تدعم الأرقام العشرية (123)
- تدعم الأرقام السداسية عشرية (0x1A)
- تدعم الأرقام الثنائية (0b10101)
- تدعم الأرقام الثمانية (0o77)
- تدعم الأرقام العربية-الهندسية (١٢٣)

### 7.3 التعليقات

```ض
# هذه تعليقة من سطر واحد

#[
 هذه تعليقة
 متعددة الأسطر
]#
```

### 7.4 نهاية التعليمة

- كل سطر يمثل تعليمة واحدة ما لم يُنص خلاف ذلك
- الفاصلة المنقوطة غير مطلوبة
- يمكن استخدام الفاصلة المنقوطة العربية `؛` لفصل تعليمتين في سطر واحد (اختياري)
- الفاصلة الإنجليزية `;` غير مدعومة

### 7.5 البنيان

```ض
# تعريف متغير
ثابت: طول = 100

# تعريف مصفوفة
متغير: بيانات: رقم[10]

# تعريف دالة
دالة: اسم(معاملات) -> نوع :-
    # جسم الدالة
نهاية
```

## 8. نموذج البيانات الأساسي

### 8.1 الأنواع الأساسية

| النوع | الوصف | الحجم |
|-------|-------|-------|
| `رقم` | عدد صحيح | 64 بت |
| `رقم_عشري` | عدد عشري | 64 بت |
| `حرف` | حرف واحد | 8 بت |
| `منطق` | صحيح/خطأ | 8 بت |
| `فراغ` | لا قيمة | 0 بت |
| `نص` | سلسلة نصية | متغير |

### 8.2 الأنواع المشتقة

```ض
# مصفوفة
متغير: صفين: رقم[10]

# سلسلة نصية (مصفوفة من الحروف)
ثابت: اسم = "أحمد"

# مؤشر
متغير: مؤشر_الذاكرة: مؤشر_نوع(رقم)
```

## 9. مثال شامل

```ض
# برنامج حساب المضروب
# المؤلف: مطور ض Core
# التاريخ: 2026

# تعريف الثوابت
ثابت: النهاية = 10

# تعريف الدالة الرئيسية
دالة: الرئيسية() :-
    # تهيئة المتغيرات
    متغير: النتيجة: رقم = 1
    متغير: العداد: رقم = 1
    
    # حلقة التكرار
    طالما(العداد <= النهاية) :-
        النتيجة = النتيجة * العداد
        العداد = العداد + 1
    نهائية
    
    # طباعة النتيجة
    اطبع("المضروب =", النتيجة)
    ارجع(0)
نهاية
```

## 10. مبادئ التصميم

1. **البساطة:** كل تعليمة تفعل شيئاً واحداً
2. **الوضوح:** الأسماء وصفية وواضحة
3. **القرب من المعالج:** العمليات تعكس تعليمات المعالج
4. **الاستقلالية:** لا تعتمد على لغات أخرى
5. **التوسعية:** يمكن إضافة ميزات جديدة بدون كسر القديمة

## 11. الجمهور المستهدف

- مطورو الأنظمة العرب
- طلاب هندسة الحاسوب العرب
- المبرمجون الراغبون في فهم المستوى المنخفض
- مطورو أنظمة التشغيل العرب
- أي شخص يريد البرمجة بالعربية على مستوى المعالج

## 12. الحالة الحالية

هذه مسودة أولية مُصححة للغة ض Core. المواصفات قيد التطوير وقد تتغير. يُرحب بالمساهمات والملاحظات.

**الإصدارات القادمة:**
- الإصدار 0.2: تفصيل أكثر لنظام أنواع البيانات
- الإصدار 0.3: تعريف مكتبة النظام الأساسية
- الإصدار 0.4: تعريف نظام التعامل مع الأخطاء
- الإصدار 1.0: الإصدار الأول المستقر

## 13. التغييرات عن الإصدار 0.1

### 13.1 تغييرات في القواعد

1. استخدام `:-` لبداية جسم الدالة بدلاً من `->`
2. تحديد `:` بوضوح حسب السياق
3. تحديد `و` و `أو` بدلاً من `&&` و `||`
4. تحديد `فراغ` بدلاً من `null`
5. تحديد `خطأ` و `صحيح` كثوابت
6. تحديد `@` للعلامات
7. إضافة جدول أولوية العمليات
8. تحديد escape sequences
9. تحديد `[]` و `.` كعاملات
10. تحديد نطاق المتغيرات

### 13.2 تغييرات في الكلمات المفتاحية

1. فصل `نوع` عن `جلب_نوع`
2. استبدال `asil` بـ `و_بتية`
3. استبدال `shift_*` بـ `تحريك_*`
4. استبدال `bitwise_*` بـ عربي
5. حذف `عددي` واستبدالها بـ `رقم`
6. إضافة `نص` كنوع أساسي
7. استبدال `عدّل` بـ `غيّر_حجم`
8. استبدال `أعلن` بـ `أطلق`
9. فصل `اقرأ` إلى three أنواع
10. حذف جميع الكلمات الإنجليزية

### 13.3 تغييرات في التوثيق

1. حذف جميع الكلمات الصينية
2. استخدام أسماء عربية فقط للسجلات
3. تصحيح التقويم الزمني
4. إضافة أمثلة إضافية
