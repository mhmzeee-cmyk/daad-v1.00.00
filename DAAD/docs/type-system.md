# الفصل 1: مبادئ نظام الأنواع

## 1.1 الفلسفة

نظام الأنواع في ض Core **بسيط ومباشر**. لا يوجد تعقيد مثل الـ Generics أو الـ Type Inference المتقدم. الهدف هو提供 تحكم مباشر بالبيانات على مستوى المعالج.

## 1.2 المبادئ الأساسية

1. **البساطة:** الأنواع قليلة وواضحة
2. **المباشرة:** حجم كل نوع معروف مسبقاً
3. **التحكم:** المبرمج يتحكم في التحويلات
4. **الشفافية:** لا يوجد إخفاء للأنواع

## 1.3 تصنيف الأنواع

```
الأنواع في ض Core
├── الأنواع الأساسية
│   ├── رقم (صحيح)
│   ├── رقم_عشري (عشري)
│   ├── حرف
│   └── منطق
├── الأنواع المركبة
│   ├── مصفوفة
│   ├── هيكل
│   └── مؤشر
└── الأنواع الخاصة
    ├── فراغ (void)
    └── نص (مصفوفة حروف)
```

# الفصل 2: الأنواع الأساسية

## 2.1 الأعداد الصحيحة

### 2.1.1 النوع الأساسي: `رقم`

| الخاصية | القيمة |
|---------|--------|
| **الاسم** | `رقم` |
| **الحجم** | 8 بايت (64 بت) |
| **النطاق (موقّع)** | -9,223,372,036,854,775,808 إلى 9,223,372,036,854,775,807 |
| **النطاق (غير موقّع)** | 0 إلى 18,446,744,073,709,551,615 |
| **المحاذاة** | 8 بايت |
| **القيمة الافتراضية** | `0` |

### 2.1.2 الأنواع الفرعية للمعادلة

**ملاحظة:** في الإصدار الحالي، `رقم` هو النوع الوحيد للمعادلة. الأنواع الفرعية ستُضاف مستقبلاً.

| النوع المستقبلي | الحجم | النطاق (موقّع) |
|----------------|-------|----------------|
| `رقم_8` | 1 بايت | -128 إلى 127 |
| `رقم_16` | 2 بايت | -32,768 إلى 32,767 |
| `رقم_32` | 4 بايت | -2,147,483,648 إلى 2,147,483,647 |
| `رقم_64` | 8 بايت | كما في `رقم` |

### 2.1.3 الأنواع غير الموقّعة

**ملاحظة:** غير مدعومة حالياً. ستُضاف مستقبلاً.

| النوع المستقبلي | الحجم | النطاق |
|----------------|-------|--------|
| `رقم_8_بدون_علامة` | 1 بايت | 0 إلى 255 |
| `رقم_16_بدون_علامة` | 2 بايت | 0 إلى 65,535 |
| `رقم_32_بدون_علامة` | 4 بايت | 0 إلى 4,294,967,295 |
| `رقم_64_بدون_علامة` | 8 بايت | 0 إلى 18,446,744,073,709,551,615 |

### 2.1.4 أمثلة

```ض
# تعريف أعداد صحيحة
متغير: عدد1: رقم = 10
متغير: عدد2: رقم = -255
متغير: عدد3: رقم = 0xFF       # hexadecimal
متغير: عدد4: رقم = 0b10101010  # binary
متغير: عدد5: رقم = 0o77        # octal
```

## 2.2 الأعداد العشرية

### 2.2.1 النوع الأساسي: `رقم_عشري`

| الخاصية | القيمة |
|---------|--------|
| **الاسم** | `رقم_عشري` |
| **الحجم** | 8 بايت (64 بت) |
| **النوع** | Double Precision (IEEE 754) |
| **الدقة** | 15-17 رقم عشري |
| **المحاذاة** | 8 بايت |
| **القيمة الافتراضية** | `0.0` |

### 2.2.2 أمثلة

```ض
# تعريف أعداد عشرية
متغير: نسبة1: رقم_عشري = 3.14
متغير: نسبة2: رقم_عشري = -0.5
متغير: نسبة3: رقم_عشري = 1.0e10    # scientific notation
متغير: نسبة4: رقم_عشري = 0x1.8p+1   # hex float
```

### 2.2.3 القيم الخاصة

```ض
ثابت: اللانهاية = رقم_عشري.لانهاية
ثابت: اللانهاية_السالبة = -رقم_عشري.لانهاية
ثابت: ليس_رقم = رقم_عشري.ليس_رقم
```

## 2.3 الحروف

### 2.3.1 النوع الأساسي: `حرف`

| الخاصية | القيمة |
|---------|--------|
| **الاسم** | `حرف` |
| **الحجم** | 1 بايت (8 بت) |
| **الترميز** | ASCII موسّع |
| **المحاذاة** | 1 بايت |
| **القيمة الافتراضية** | `'\0'` |

### 2.3.2 أمثلة

```ض
# تعريف حروف
متغير: حرف1: حرف = 'أ'
متغير: حرف2: حرف = 'A'
متغير: حرف3: حرف = '0'
متغير: حرف4: حرف = '\n'    # سطر جديد
```

### 2.3.3 Escape Sequences

| التسلسل | الوصف |
|---------|-------|
| `\n` | سطر جديد |
| `\t` | تبويب |
| `\\` | علامة ح backslash |
| `\"` | علامة اقتباس |
| `\'` | علامة اقتباس مفردة |
| `\0` | بايت صفر |

## 2.4 المنطق

### 2.4.1 النوع الأساسي: `منطق`

| الخاصية | القيمة |
|---------|--------|
| **الاسم** | `منطق` |
| **الحجم** | 1 بايت (8 بت) |
| **القيم** | `صحيح` أو `خطأ` |
| **المحاذاة** | 1 بايت |
| **القيمة الافتراضية** | `خطأ` |

### 2.4.2 الثوابت المنطقية

```ض
ثابت: صحيح = 1
ثابت: خطأ = 0
```

### 2.4.3 أمثلة

```ض
# تعريف قيم منطقية
متغير: حالة1: منطق = صحيح
متغير: حالة2: منطق = خطأ
متغير: حالة3 = (أ > ب)    # نتيجة المقارنة منطقية
```

# الفصل 3: الأنواع المركبة

## 3.1 المصفوفات

### 3.1.1 التعريف

```ض
# مصفوفة ذات حجم ثابت
متغير: بيانات: رقم[10]

# مصفوفة بقيمة افتراضية
متغير: بيانات2: رقم[5] = {1، 2، 3، 4، 5}

# مصفوفة حروف (نص)
ثابت: اسم = "أحمد"
```

### 3.1.2 خصائص المصفوفات

| الخاصية | القيمة |
|---------|--------|
| **النوع** | مصفوفة من نوع معين |
| **الحجم** | عدد العناصر × حجم النوع |
| **الفهرسة** | تبدأ من 0 |
| **المحاذاة** | حجم النوع الأساسي |

### 3.1.3 الوصول

```ض
# الوصول لعنصر
المصفوفة[0]       # العنصر الأول
المصفوفة[العداد]  # العنصر عند الفهرس
```

### 3.1.4 المصفوفات متعددة الأبعاد

```ض
# مصفوفة ثنائية البعد
متغير: مصفوفة2D: رقم[3][4]

# الوصول
المصفوفة2D[0][0]    # الصف الأول، العمود الأول
```

## 3.2 الهياكل (Structures)

### 3.2.1 التعريف

```ض
نوع: نقطة = {
    x: رقم，
    y: رقم
}

نوع: طالب = {
    الاسم: حرف[50]，    # اسم ثابت الطول
    العمر: رقم،
    المعدل: رقم_عشري
}
```

### 3.2.2 خصائص الهياكل

| الخاصية | القيمة |
|---------|--------|
| **النوع** | هيكل بيانات |
| **الحجم** | مجموع أحجام الأعضاء + المحاذاة |
| **المحاذاة** | حسب أكبر عضو |
| **الأعضاء** | م publicly متاحة |

### 3.2.3 الوصول للأعضاء

```ض
# تعريف هيكل
نوع: نقطة = { x: رقم، y: رقم }
متغير: ص1: نقطة = { 10، 20 }

# الوصول لعضو
ص1.x    # 10
ص1.y    # 20

# تغيير عضو
ص1.x = 30
```

### 3.2.4 الهياكل المتداخلة

```ض
نوع: عنوان = {
    شارع: حرف[100]，
    مدينة: حرف[50]
}

نوع: طالب = {
    اسم: حرف[50]，
    عنوان_السكن: عنوان
}

# الوصول
طالب1.عنوان_السكن.المدينة
```

## 3.3 المؤشرات

### 3.3.1 التعريف

```ض
# مؤشر إلى نوع معين
متغير: مؤشر: مؤشر_نوع(رقم)

# مؤشر إلى هيكل
متغير: مؤشر_نقطة: مؤشر_نوع(نقطة)

# مؤشر حر (void pointer)
متغير: مؤشر_حر: مؤشر_نوع(فراغ)
```

### 3.3.2 خصائص المؤشرات

| الخاصية | القيمة |
|---------|--------|
| **النوع** | مؤشر إلى نوع معين |
| **الحجم** | 8 بايت (64 بت) |
| **المحاذاة** | 8 بايت |
| **القيمة الافتراضية** | `فراغ` |

### 3.3.3 عمليات المؤشرات

```ض
# تحميل عنوان
حمل(المؤشر، مؤشر(المتغير))

# الوصول للقيمة
اقرأ_ذاكرة(سجل1، [المؤشر])

# كتابة عبر المؤشر
خزن([المؤشر]، القيمة)

# حساب الإزاحة
المؤشر = المؤشر + حجم_النوع(رقم) * العداد
```

### 3.3.4 المؤشرات الفارغة

```ض
# التحقق من فراغ المؤشر
إذا(المؤشر == فراغ) :-
    اطبع("المؤشر فارغ")
نهاية
```

## 3.4 النصوص

### 3.4.1 التعريف

**النص في ض Core هو مصفوفة حروف.**

```ض
# تعريف نص
ثابت: اسم = "أحمد"

# تعريف نص متغير
متغير: رسالة: حرف[100] = "مرحباً بالعالم"
```

### 3.4.2 خصائص النصوص

| الخاصية | القيمة |
|---------|--------|
| **النوع** | مصفوفة حروف |
| **النهاية** | `\0` (بايت صفر) |
| **الطول** | عدد الحروف + 1 (لـ `\0`) |

### 3.4.3 الوصول للأحرف

```ض
ثابت: اسم = "أحمد"
متغير: حرف1: حرف = اسم[0]    # 'أ'
```

# الفصل 4: التحويلات بين الأنواع

## 4.1 التحويل الصريح (Explicit Cast)

```ض
حوّل(قيمة، نوع_جديد)
```

## 4.2 التحويلات المدعومة

### 4.2.1 التحويلات بين الأعداد الصحيحة

| من | إلى | الحالة |
|----|-----|--------|
| `رقم` | `رقم_عشري` |  مدعوم |
| `رقم_عشري` | `رقم` |  مدعوم ( فقدان الكسور) |
| `رقم` | `حرف` |  مدعوم |
| `حرف` | `رقم` |  مدعوم |

### 4.2.2 التحويلات بين الأعداد العشرية

| من | إلى | الحالة |
|----|-----|--------|
| `رقم_عشري` | `رقم` |  مدعوم |
| `رقم` | `رقم_عشري` |  مدعوم |

### 4.2.3 التحويلات مع المنطق

| من | إلى | الحالة |
|----|-----|--------|
| `منطق` | `رقم` |  مدعوم (0 أو 1) |
| `رقم` | `منطق` |  مدعوم (0 = خطأ، غير 0 = صحيح) |

### 4.2.4 التحويلات مع المؤشرات

| من | إلى | الحالة |
|----|-----|--------|
| `مؤشر_نوع(*)` | `رقم` |  مدعوم |
| `رقم` | `مؤشر_نوع(*)` |  مدعوم |
| `مؤشر_نوع(*)` | `مؤشر_نوع(فراغ)` |  مدعوم |
| `مؤشر_نوع(فراغ)` | `مؤشر_نوع(*)` |  مدعوم |

## 4.3 التحويل الضمني (Implicit Cast)

**ض Core لا تدعم التحويل الضمني.** جميع التحويلات يجب أن تكون صريحة باستخدام `حوّل`.

```ض
# خطأ: تحويل ضمني
متغير: عدد: رقم = 10
متغير: كسر: رقم_عشري = عدد    # خطأ!

# صحيح: تحويل صريح
متغير: كسر: رقم_عشري = حوّل(عدد، رقم_عشري)
```

## 4.4 التحويلات غير المدعومة

| من | إلى | الحالة |
|----|-----|--------|
| `رقم` | `نص` |  غير مدعوم |
| `نص` | `رقم` |  غير مدعوم |
| `هيكل` | `رقم` |  غير مدعوم |
| `مصفوفة` | `مؤشر` |  غير مدعوم |

# الفصل 5: قواعد التوافق

## 5.1 التوافق في العمليات

### 5.1.1 العمليات الحسابية

**قاعدة:** يجب أن يكون كلا النوعين متماثلين.

```ض
# صحيح
متغير: أ: رقم = 10
متغير: ب: رقم = 5
متغير: ج: رقم = أ + ب

# خطأ
متغير: أ: رقم = 10
متغير: ب: رقم_عشري = 5.0
متغير: ج = أ + ب    # خطأ! نوعان مختلفان
```

### 5.1.2 حل الاستثناء

**يمكن استخدام `حوّل` للتوافق:**

```ض
متغير: أ: رقم = 10
متغير: ب: رقم_عشري = 5.0
متغير: ج: رقم_عشري = حوّل(أ، رقم_عشري) + ب
```

## 5.2 التوافق في المقارنات

**قاعدة:** يجب أن يكون كلا النوعين متماثلين.

```ض
# صحيح
إذا(أ == ب) :-    # كلاهما رقم
    ...
نهاية

# خطأ
إذا(أ == نص) :-    # خطأ! رقم ونص
    ...
نهاية
```

## 5.3 التوافق في التعيين

**قاعدة:** يجب أن يكون النوع متطابقاً.

```ض
# صحيح
متغير: أ: رقم = 10

# خطأ
متغير: أ: رقم = "أحمد"    # خطأ! رقم ونص
```

## 5.4 التوافق في الدوال

### 5.4.1 المعاملات

**قاعدة:** يجب أن تتطابق الأنواع.

```ض
دالة: اجمع(أ: رقم، ب: رقم) -> رقم :-
    ارجع(أ + ب)
نهاية

# صحيح
اجمع(10، 20)

# خطأ
اجمع(10، "20")    # خطأ! رقم ونص
```

### 5.4.2 الإرجاع

**قاعدة:** يجب أن يتطابق نوع الإرجاع.

```ض
دالة: مثال() -> رقم :-
    ارجع(10)       # صحيح
    ارجع("أحمد")   # خطأ! النوع غير متطابق
نهاية
```

## 5.5 التوافق في المصفوفات

**قاعدة:** يجب أن تتطابق أنواع العناصر.

```ض
# صحيح
متغير: بيانات: رقم[3] = {1، 2، 3}

# خطأ
متغير: بيانات: رقم[3] = {1، "اثنين"، 3}    # خطأ!
```

## 5.6 التوافق في الهياكل

**قاعدة:** يجب أن تتطابق الهياكل بالكامل.

```ض
نوع: نقطة1 = { x: رقم، y: رقم }
نوع: نقطة2 = { x: رقم، y: رقم }

# صحيح (نفس البنية)
متغير: ص1: نقطة1 = { 10، 20 }
متغير: ص2: نقطة2 = ص1    # صحيح
```

# الفصل 6: حجم الأنواع والمحاذاة

## 6.1 جدول الأحجام

| النوع | الحجم (بايت) | الحجم (بت) | المحاذاة |
|-------|-------------|-----------|----------|
| `رقم` | 8 | 64 | 8 |
| `رقم_عشري` | 8 | 64 | 8 |
| `حرف` | 1 | 8 | 1 |
| `منطق` | 1 | 8 | 1 |
| `مؤشر` | 8 | 64 | 8 |
| `فراغ` | 0 | 0 | - |

## 6.2 حجم المصفوفات

```ض
# حجم المصفوفة = عدد العناصر × حجم النوع
ثابت: حجم_مصفوفة = حجم_النوع(رقم) * 10    # 80 بايت
```

## 6.3 حجم الهياكل

```ض
نوع: نقطة = {
    x: رقم،    # 8 بايت
    y: رقم     # 8 بايت
}

# الحجم الكلي = 16 بايت (بدون ملء)
```

## 6.4 الملء (Padding)

**الهياكل قد تحتوي على ملء للمحافظة على المحاذاة.**

```ض
نوع: مثال = {
    أ: حرف،    # 1 بايت + 7 بايت ملء
    ب: رقم     # 8 بايت
}

# الحجم الكلي = 16 بايت (وليس 9)
```

## 6.5 حساب الحجم

```ض
# حجم_النوع: يُرجع حجم أي نوع
حجم_النوع(رقم)        # 8
حجم_النوع(رقم_عشري)   # 8
حجم_النوع(حرف)         # 1
حجم_النوع(منطق)        # 1
حجم_النوع(مؤشر)        # 8

# حجم_القيمة: يُرجع حجم قيمة معينة
متغير: عدد: رقم = 10
حجم_القيمة(العدد)     # 8
```

# الفصل 7: القيم الافتراضية

## 7.1 جدول القيم الافتراضية

| النوع | القيمة الافتراضية | الوصف |
|-------|-------------------|-------|
| `رقم` | `0` | العدد الصفر |
| `رقم_عشري` | `0.0` | العدد العشري الصفر |
| `حرف` | `'\0'` | حرف فارغ |
| `منطق` | `خطأ` | القيمة المنطقية الخاطئة |
| `مؤشر` | `فراغ` | مؤشر فارغ |
| `نص` | `""` | نص فارغ |

## 7.2 التعريف بدون قيمة

```ض
# عند التعريف بدون قيمة، تحصل على القيمة الافتراضية
متغير: عدد: رقم           # عدد = 0
متغير: نسبة: رقم_عشري    # نسبة = 0.0
متغير: حالة: منطق         # حالة = خطأ
```

## 7.3 الثوابت

**الثوابت يجب أن تُعرّف بقيمة.**
