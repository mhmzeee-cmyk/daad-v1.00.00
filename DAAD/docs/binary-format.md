# الفصل 2: صيغة الملفات

## 2.1 مخطط عام

```
ملف .dad (مصدر)
    ↓
المترجم (Compiler)
    ↓
ملف .o (كائني)
    ↓
الرابط (Linker)
    ↓
ملف تنفيذي
```

## 2.2 أنواع الإنتاج

### 1. ملف كائني (Object File)

```
المحتوى:
├── رأس الملف (Header)
├── قسم الكود (Code Section)
├── قسم البيانات (Data Section)
├── جدول الرموز (Symbol Table)
├── جدول إعادة التوطين (Relocation Table)
└── معلومات التصحيح (Debug Info)
```

### 2. ملف تنفيذي (Executable)

```
المحتوى:
├── رأس الملف (ELF Header / PE Header)
├── خريطة البرامج (Program Header Table)
├── قسم الكود (Text Section)
├── قسم البيانات (Data Section)
├── قسم BSS (بيانات غير مُهيأة)
├── جدول الرموز (Symbol Table)
└── معلومات التصحيح (Debug Info)
```

# الفصل 3: بنية الملف الكائني

## 3.1 رأس الملف (ELF Header)

```c
typedef struct {
    unsigned char e_ident[16];    # معرف ELF
    uint16_t e_type;              # نوع الملف
    uint16_t e_machine;           # المعمارية
    uint32_t e_version;           # الإصدار
    uint64_t e_entry;             # نقطة الدخول
    uint64_t e_phoff;             # إزاحة Program Header
    uint64_t e_shoff;             # إزاحة Section Header
    uint32_t e_flags;             # العلامات
    uint16_t e_ehsize;            # حجم الرأس
    uint16_t e_phentsize;         # حجم Program Header Entry
    uint16_t e_phnum;             # عدد Program Headers
    uint16_t e_shentsize;         # حجم Section Header Entry
    uint16_t e_shnum;             # عدد Section Headers
    uint16_t e_shstrndx;         # فهرس اسم القسم
} Elf64_Ehdr;
```

## 3.2 الأقسام (Sections)

### قسم الكود (.text)

```
- يحتوي على تعليمات المترجم
- غير قابل للكتابة
- قابل للتنفيذ
```

### قسم البيانات (.data)

```
- يحتوي على البيانات المُهيأة
- قابل للقراءة والكتابة
- متغيرات عامة وثوابت
```

### قسم BSS (.bss)

```
- بيانات غير مُهيأة
- يحتوي فقط على الحجم
- يُهيأ تلقائياً عند التشغيل
```

### قسم الثوابت (.rodata)

```
- بيانات للقراءة فقط
- النصوص والثوابت
```

## 3.3 جدول الرموز (Symbol Table)

```c
typedef struct {
    uint32_t st_name;     # اسم الرمز
    uint8_t st_info;      # النوع والأولوية
    uint8_t st_other;     # الرؤية
    uint16_t st_shndx;    # فهرس القسم
    uint64_t st_value;    # القيمة
    uint64_t st_size;     # الحجم
} Elf64_Sym;
```

## 3.4 جدول إعادة التوطين (Relocation Table)

```c
typedef struct {
    uint64_t r_offset;    # الموقع المتأثر
    uint64_t r_info;      # معلومات الرمز والنوع
    int64_t r_addend;     # الإضافة
} Elf64_Rela;
```

# الفصل 4: بنية الملف التنفيذي

## 4.1 رأس Program Header

```c
typedef struct {
    uint32_t p_type;      # نوع العنصر
    uint32_t p_flags;     # العلامات
    uint64_t p_offset;    # إزاحة في الملف
    uint64_t p_vaddr;     # العنوان الافتراضي
    uint64_t p_paddr;     # العنوان الفعلي
    uint64_t p_filesz;    # حجم الملف
    uint64_t p_memsz;     # حجم الذاكرة
    uint64_t p_align;     # المحاذاة
} Elf64_Phdr;
```

## 4.2 أنواع العناصر (Program Header Types)

| النوع | الوصف |
|-------|-------|
| PT_NULL | عنصر غير مستخدم |
| PT_LOAD | قسم قابل للتحميل |
| PT_DYNAMIC | معلومات ديناميكية |
| PT_INTERP | مسار المحمل |
| PT_NOTE | معلومات إضافية |

## 4.3 العلامات (Flags)

| العلامة | الوصف |
|---------|--------|
| PF_X | قابل للتنفيذ |
| PF_W | قابل للكتابة |
| PF_R | قابل للقراءة |

## 4.4 مثال على تخطيط الملف التنفيذي

```
العنوان الافتراضي
0x00400000    ┌────────────────────────────┐
              │  ELF Header                │
0x00400040    ├────────────────────────────┤
              │  Program Header Table      │
0x00400100    ├────────────────────────────┤
              │  .text (الكود)             │
              │  ...                       │
0x00500000    ├────────────────────────────┤
              │  .rodata (الثوابت)         │
              │  ...                       │
0x00600000    ├────────────────────────────┤
              │  .data (البيانات)          │
              │  ...                       │
0x00700000    ├────────────────────────────┤
              │  .bss (بيانات غير مُهيأة)  │
              │  ...                       │
0x7FFFFFF0    └────────────────────────────┘
```

# الفصل 5: معلومات التصحيح

## 5.1 صيغة معلومات التصحيح

### DWARF (المدعوم)

```c
typedef struct {
    uint32_t length;
    uint16_t version;
    uint8_t address_size;
    uint8_t segment_selector;
} DWARF_Compilation_Unit_Header;
```

## 5.2 المعلومات المُخزنة

| المعلومات | الوصف |
|-----------|-------|
| أسماء المتغيرات | أسماء المتغيرات الأصلية |

| أرقام الأسطر | الربط بالسطر في الملف الأصلي |
| العلامات | أماكن العلامات في الكود |
