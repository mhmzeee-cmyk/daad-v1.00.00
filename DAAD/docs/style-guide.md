## 1. فلسفة الأسلوب

### 1.1 المبدأ الأساسي

**"الكود الذي يُقرأ أولاً يُكتب ثانياً."**

صُمم دليل الأسلوب ليحقق:
1. **القراءة:** سهولة قراءة الكود
2. **الفهم:** وضوح النية
3. **الصيانة:** سهولة التعديل
4. **التناسق:** نمط موحد لجميع المبرمجين

## 2. تسمية المتغيرات (Variable Naming)

### 2.1 القواعد الأساسية

```ض
# القاعدة: اسم وصري يبدأ بحرف عربي أو إنجليزي أو _

# صحيح
متغير
عدد
المتغير
_عدد
أحمد
myVar

# خاطئ
2متغير    # تبدأ برقم
مسافة بين  # تحتوي على مسافة
```

### 2.2 أنماط التسمية

#### المتغيرات

```ض
# متغيرات عامة: اسم وصري بحروف صغيرة
متغير: عدد = 10
متغير: اسم = "أحمد"
متغير: نسبة = 3.14

# لا تستخدم حروف كبيرة في بداية المتغيرات العامة
# خطأ: متغير: العدد = 10
```

#### الثوابت

```ض
# الثوابت: حروف كبيرة أو سفلية مع شرطة سفلية
ثابت: النهاية = 100
ثابت: المصف = 3.14159
ثابت: الناتج = "مرحباً"

# أو
ثابت: نهاية_البرنامج = 100
ثابت: قيمة_ال.pi = 3.14159
```

#### الدوال

```ض
# الدوال: فعل + اسم وصري
دالة: اجمع() :-
دالة: اطبع_تحية() :-
دالة: احسب_المجموع() :-
دالة: أضف_طالب() :-

# لا تستخدم
دالة: دالة1() :-
دالة: عمل() :-  # غير واصف
```

#### الأنواع

```ض
# الأنواع: اسم بحروف كبيرة في البداية
نوع: طالب
نوع: مصفوفة
نوع: مؤشر_نوع

# أو
نوع: نوع_طالب
نوع: نوع_مصفوفة
```

#### السجلات

```ض
# السجلات: تبدأ بـ "سجل" أو "سجل_"
سجل1
سجل2
سجل_النتيجة
سجل_المؤقت

# السجلات الخاصة
المؤشر_المكدس
المؤشر_الإطار
```

### 2.3 أسماء المعاملات

```ض
# المعاملات: أسماء وصفية
دالة: اجمع(أ: رقم، ب: رقم) -> رقم :-

# أو
دالة: اجمع(الرقم1: رقم، الرقم2: رقم) -> رقم :-

# تجنب
دالة: اجمع(أ: رقم، ب: رقم) -> رقم :-  # أسماء قصيرة جداً
```

### 2.4 أسماء المتغيرات المحلية

```ض
دالة: معقدة() :-
    # متغيرات محلية: أسماء قصيرة وواضحة
    محلي: نتيجة = 0
    محلي: عداد = 0
    محلي: مؤقت = 0
    
    # أو
    محلي: النتيجة = 0
    محلي: العداد = 0
نهاية
```

## 4. تسمية الدوال (Function Naming)

### 4.1 القواعد

```ض
# الدوال: فعل + اسم وصري

# أمثلة صحيحة
دالة: اجمع() :-
دالة: اطبع_تحية() :-
دالة: احسب_المجموع() :-
دالة: أضف_طالب() :-
دالة: ابحث_عن() :-
دالة: احذف() :-

# أمثلة خاطئة
دالة: دالة1() :-
دالة: عمل() :-  # غير واصف
دالة: something() :-  # بالإنجليزية فقط
```

### 4.2 الدوال الخاصة

```ض
# الدوال الخاصة: تبدأ بـ "_" أو "نظام_"
دالة: _تهيئة() :-
دالة: نظام_استدعاء() :-
دالة: _تنظيف() :-
```

### 4.3 الدوال المدة

```ض
# الدوال المدة: تعريف مسبق
أمامية: اجمع(أ: رقم، ب: رقم) -> رقم

# التنفيذ لاحقاً
دالة: اجمع(أ: رقم، ب: رقم) -> رقم :-
    ارجع(أ + ب)
نهاية
```

## 6. كتابة التعليمات (Statement Writing)

### 6.1 الأسطر الواحدة

```ض
# كل تعليمة في سطر واحد
متغير: عدد = 10
اجمع(أ، ب)
اطبع("مرحباً")
```

### 6.2 الأسطر المتعددة

```ض
# تعليمة طويلة يمكن تقسيمها
نتيجة = (
    أ + ب + ج +
    د + هـ + و
)

# أو
نتيجة = أ + ب + ج +
    د + هـ + و
```

### 6.3 الفاصلة المنقوطة

```ض
# الفاصلة المنقوطة اختيارية且 عربية فقط
أ = 10
ب = 20

# أو
أ = 10؛ ب = 20

# الفاصلة الإنجليزية غير مدعومة
أ = 10; ب = 20   # خطأ
```

## 7. المسافات (Spacing)

### 7.1 المسافات العامة

```ض
# مسافة واحدة بعد الفاصلة
دالة: اجمع(أ: رقم، ب: رقم) -> رقم :-

# لا مسافة قبل الفاصلة
دالة: اجمع(أ: رقم، ب: رقم) -> رقم :-

# مسافة بعد النقطتين
متغير: عدد: رقم = 10

# لا مسافة قبل النقطتين
متغير: عدد: رقم = 10
```

### 7.2 المسافات في البنيان

```ض
# مسافة واحدة بعد السهم
إذا(أ > ب) :-
    اطبع("أكبر")
نهاية

# لا مسافة قبل السهم
إذا(أ > ب) :-
    اطبع("أكبر")
نهاية
```

### 7.3 المسافات في العمليات

```ض
# مسافة حول العامل
نتيجة = أ + ب
نتيجة = أ * ب

# لا مسافة داخل الأقواس
نتيجة = (أ + ب) * ج
```

### 7.4 المسافات في التعليقات

```ض
# مسافة واحدة بعد علامة التعليق
# هذا تعليق

# مسافة واحدة بعد علامة البداية
#[
هذا تعليق متعدد
]#
```

## 9. التعليقات (Comments)

### 9.1 التعليقات من سطر واحد

```ض
# هذا تعليق من سطر واحد
متغير: عدد = 10  # تعليق بعد الكود
```

### 9.2 التعليقات متعددة الأسطر

```ض
#[
هذا تعليق
متعدد الأسطر
يستخدم للكتابة المطولة
]#
```

### 9.3 التعليقات الوثائقية (مستقبلاً)

```ض
#[
@ الدالة: اجمع
@ الوصف: تجمع رقمين
@ المعامل1: الرقم الأول
@ المعامل2: الرقم الثاني
@ النتيجة: مجموع الرقمين
]#
دالة: اجمع(أ: رقم، ب: رقم) -> رقم :-
    ارجع(أ + ب)
نهاية
```

### 9.4 تعليقات الكود

```ض
# تعليقات توضيحية للكود المعقد
حمل(سجل1، 10)  # تحميل العدد 10 في السجل1
اجمع(سجل1، 20)  # إضافة 20 للسجل1
خزن(المتغير، سجل1)  # حفظ النتيجة
```

### 9.5 التعليقات المعطلة

```ض
# لتعطيل كود، استخدم التعليق المتعدد
#[
هذا الكود معطل ولن يُنفذ
المتغير = 10
اجمع(المتغير، 20)
]#
```

## 10. البنيان (Formatting)

### 10.1 البنيان الأساسي

```ض
# كل بنيان ينتهي بكلمة "نهاية"

دالة: اجمع(أ: رقم، ب: رقم) -> رقم :-
    ارجع(أ + ب)
نهاية

إذا(أ > ب) :-
    اطبع("أكبر")
نهاية
```

### 10.2 البنيان المتداخل

```ض
# المحاذاة حسب العمق
إذا(أ > ب) :-
    إذا(أ > ج) :-
        اطبع("الأكبر")
    نهاية
نهاية
```

### 10.3 البنيان الطويل

```ض
# يمكن تقسيم البنيان الطويل
دالة: معقدة() :-
    # الخطوة 1
    حمل(سجل1، 10)
    
    # الخطوة 2
    اجمع(سجل1، 20)
    
    # الخطوة 3
    خزن(المتغير، سجل1)
نهاية
```

## 11. نمط الكود (Code Patterns)

### 11.1 نمط التعريف

```ض
# تعريف المتغيرات
متغير: عدد1 = 10
متغير: عدد2 = 20

# تعريف الثوابت
ثابت: النهاية = 100

# تعريف الدوال
دالة: اجمع(أ: رقم، ب: رقم) -> رقم :-
    ارجع(أ + ب)
نهاية
```

### 11.2 نمط الشرط

```ض
# شرط بسيط
إذا(أ > ب) :-
    اطبع("أكبر")
نهاية

# شرط معقد
إذا(أ > ب و ج == 5) :-
    اطبع("الشرط محقق")
نهاية

# شرط متعدد
إذا(أ > ب) :-
    اطبع("أكبر")
وإلا إذا(أ == ب) :-
    اطبع("متساويان")
وإلا :-
    اطبع("أصغر")
نهاية
```

### 11.3 نمط الحلقة

```ض
# حلقة طالما
طالما(أ < 10) :-
    اطبع(أ)
    أ = أ + 1
نهاية

# حلقة لكل
لكل(متغير: عداد = 0؛ العداد < 10؛ العداد = العداد + 1) :-
    اطبع(العداد)
نهاية
```

### 11.4 نمط الدالة

```ض
# دالة بسيطة
دالة: اجمع(أ: رقم، ب: رقم) -> رقم :-
    ارجع(أ + ب)
نهاية

# دالة معقدة
دالة: معقدة() :-
    # تعريف المتغيرات المحلية
    محلي: نتيجة = 0
    محلي: عداد = 0
    
    # الحلقة
    طالما(العداد < 10) :-
        النتيجة = النتيجة + العداد
        العداد = العداد + 1
    نهائية
    
    # الإرجاع
    ارجع(النتيجة)
نهاية
```

## 12. الأخطاء الشائعة

### 12.1 عدم استخدام نهاية

```ض
# خطأ
دالة: اجمع(أ: رقم، ب: رقم) -> رقم :-
    ارجع(أ + ب)
# لا توجد كلمة نهاية

# صحيح
دالة: اجمع(أ: رقم، ب: رقم) -> رقم :-
    ارجع(أ + ب)
نهاية
```

### 12.2 عدم مطابقة الأقواس

```ض
# خطأ
إذا(أ > ب :-
    اطبع("أكبر")
نهاية

# صحيح
إذا(أ > ب) :-
    اطبع("أكبر")
نهاية
```

### 12.3 استخدام كلمات خاطئة

```ض
# خطأ
إذا(أ > ب) {
    اطبع("أكبر")
}

# صحيح
إذا(أ > ب) :-
    اطبع("أكبر")
نهاية
```

### 12.4 عدم استخدام مسافات

```ض
# سيء
أ=10؛ب=20؛اجمع(أ،ب)

# جيد
أ = 10
ب = 20
اجمع(أ، ب)
```

### 12.5 استخدام سهم خاطئ

```ض
# خطأ: استخدام -> للجسد
دالة: اجمع(أ: رقم، ب: رقم) -> رقم ->
    ارجع(أ + ب)
نهاية

# صحيح: استخدام :- للجسد
دالة: اجمع(أ: رقم، ب: رقم) -> رقم :-
    ارجع(أ + ب)
نهاية
```

## 13. أمثلة شاملة

### 13.1 برنامج بسيط

```ض
# برنامج حسابي بسيط
# المؤلف: مطور ض Core
# التاريخ: 2026

# تعريف الثوابت
ثابت: النهاية = 10

# الدالة الرئيسية
دالة: الرئيسية() :-
    # تعريف المتغيرات
    متغير: النتيجة: رقم = 1
    متغير: العداد: رقم = 1
    
    # حلقة التكرار
    طالما(العداد <= النهاية) :-
        النتيجة = النتيجة * العداد
        العداد = العداد + 1
    نهائية
    
    # طباعة النتيجة
    اطبع("المضروب =", النتيجة)
    ارجع(0)
نهاية
```

### 13.2 برنامج معقد

```ض
# برنامج إدارة بيانات
# المؤلف: مطور ض Core
# التاريخ: 2026

# تعريف الهياكل
نوع: طالب = {
    الاسم: نص，
    العمر: رقم،
    المعدل: رقم_عشري
}

# تعريف المصفوفة
متغير: الطلاب: طالب[100]
متغير: العدد: رقم = 0

# دالة إضافة طالب
دالة: أضف_طالب(اسم: نص، عمر: رقم، معدل: رقم_عشري) :-
    # حفظ البيانات
    الطلاب[العدد].الاسم = الاسم
    الطلاب[العدد].العمر = العمر
    الطلاب[العدد].المعدل = المعدل
    العدد = العدد + 1
نهاية

# دالة بحث
دالة: ابحث_طالب(اسم: نص) -> رقم :-
    متغير: عداد: رقم = 0
    طالما(العداد < العدد) :-
        إذا(الطلاب[العداد].الاسم == الاسم) :-
            ارجع(العداد)
        نهاية
        العداد = العداد + 1
    نهائية
    ارجع(-1)  # لم يُوجد
نهاية

# الدالة الرئيسية
دالة: الرئيسية() :-
    # إضافة طلاب
    أضف_طالب("أحمد"، 20، 3.5)
    أضف_طالب("محمد"، 21، 3.8)
    أضف_طالب("علي"، 19، 3.2)
    
    # بحث عن طالب
    متغير: النتيجة: رقم = ابحث_طالب("محمد")
    إذا(النتيجة != -1) :-
        اطبع("تم العثور على:", الطلاب[النتيجة].الاسم)
    وإلا :-
        اطبع("لم يُوجد الطالب")
    نهاية
    
    ارجع(0)
نهاية
```

## 14. ملخص

### 14.1 القواعد الأساسية

1. **أسماء وصفية:** وضوح النية
2. **مسافات متناسقة:** سهولة القراءة
3. **تعليقات واضحة:** توضيح الكود
4. **بنايات منتهية:** كلمة "نهاية"
5. **نمط موحد:** تعاون أفضل

### 14.2 المبادئ التوجيهية

1. **القراءة أولاً:** الكود يُقرأ أكثر مما يُكتب
2. **الوضوح:** المبرمج الآخر يجب أن يفهم الكود
3. **البساطة:** تجنب التعقيد غير الضروري
4. **التناسق:** اتبع النمط الموجود
5. **التوثيق:** وثّق الكود المعقد

## 16. التغييرات عن الإصدار 0.1

1. استخدام `:-` لبداية الجسد بدلاً من `->`
2. استخدام `و` و `أو` بدلاً من `&&` و `||`
3. استخدام `فراغ` بدلاً من `null`
4. استخدام `خطأ` و `صحيح` بدلاً من `خطا` و `ص`
5. استخدام `؛` عربية بدلاً من `;` إنجليزية
6. استخدام `أطلق` بدلاً من `أعلن`
7. استخدام `اقرأ_ذاكرة` و `اقرأ_مكدس`
8. استخدام `انسخ_ذاكرة` و `امسح_ذاكرة`
9. استخدام `غيّر_حجم` بدلاً من `عدّل`
10. استخدام `حجم_النوع` و `حجم_القيمة`
11. استخدام `المؤشر_المكدس` و `المؤشر_الإطار`
12. استخدام `@` للعلامات
