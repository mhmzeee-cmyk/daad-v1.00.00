## 1. فلسفة التعامل مع الذاكرة

### 1.1 المبدأ الأساسي

في ض Core، الذاكرة **مكشوفة بالكامل**. لا يوجد إخفاء ولا إدارة تلقائية. المبرمج يتحكم في كل بايت في الذاكرة.

### 1.2 لماذا هذا النهج؟

1. **التحكم الكامل:** المبرمج يعرف ما يحدث
2. **الأداء:** لا رسوم إضافية لإدارة الذاكرة
3. **التعلم:** فهم كيف يعمل الحاسو فعلياً
4. **البرمجة المنخفضة:** ضروري لبرمجة الأنظمة

## 2. هيكل الذاكرة

### 2.1 التخطيط العام

```ض
# تخطيط الذاكرة العام
# ===================
# العناوين           | المنطقة
# ------------------|----------
# 0x00000000        | منطقة نظام التشغيل (محظورة)
# ...               |
# 0x00400000        | منطقة البرنامج (الكود)
# ...               |
# 0x00600000        | منطقة البيانات الثابتة (RO Data)
# ...               |
# 0x00800000        | منطقة البيانات المتغيرة (Data)
# ...               |
# 0x00A00000        | منطقة الكومة (Heap)
# ...               |
# 0x7FFFFFF0        | منطقة المكدس (Stack)
# ...               |
# 0xFFFFFFFF        | نهاية الذاكرة (kernel space)
```

### 2.2 مناطق الذاكرة

#### منطقة الكود (Code Segment)

```ض
# منطقة الكود: تحتوي على تعليمات البرنامج
# غير قابلة للكتابة أثناء التنفيذ

ثابت: بداية_الكود = 0x00400000
ثابت: نهاية_الكود = 0x005FFFFF
```

#### منطقة البيانات الثابتة (Read-Only Data)

```ض
# منطقة البيانات الثابتة: النصوص والثوابت
# غير قابلة للكتابة

ثابت: بداية_الثوابت = 0x00600000
ثابت: نهاية_الثوابت = 0x007FFFFF

# مثال
ثابت: رسالة = "مرحباً بالعالم"
```

#### منطقة البيانات المتغيرة (Data Segment)

```ض
# منطقة البيانات المتغيرة: المتغيرات العامة
# قابلة للقراءة والكتابة

ثابت: بداية_البيانات = 0x00800000
ثابت: نهاية_البيانات = 0x009FFFFF

# مثال
متغير: عداد = 0
ثابت: طول = 100
```

#### منطقة الكومة (Heap)

```ض
# منطقة الكومة: الذاكرة الديناميكية
# تنمو من الأسفل إلى الأعلى

ثابت: بداية_الكومة = 0x00A00000
ثابت: نهاية_الكومة = 0x7FEFFFFF

# مثال: حجز ذاكرة ديناميكية
متغير: مؤشر: مؤشر_نوع(رقم) = حجز(100 * حجم_النوع(رقم))
```

#### منطقة المكدس (Stack)

```ض
# منطقة المكدس: المتغيرات المحلية ومعاملات الدوال
# تنمو من الأعلى إلى الأسفل

ثابت: بداية_المكدس = 0x7FFFFFF0
ثابت: نهاية_المكدس = 0x70000000

# مثال: دفع على المكدس
ادفع(سجل1)
اسحب(سجل2)
```

## 3. العناوين (Addresses)

### 3.1 نظام العناوين

```ض
# العناوين: أرقام من 64 بت تمثل مواقع في الذاكرة

# أمثلة على العناوين
0x0000000000000000    # العنوان الأول
0x0000000000400000    # بداية الكود
0x7FFFFFFFFFFFFFFF    # أعلى عنوان

# حجم الذاكرة المدعومة: 2^64 بايت
```

### 3.2 الوصول للعناوين

```ض
# تحميل عنوان متغير
حمل(سجل1، مؤشر(المتغير))

# تحميل عنوان مصفوفة
حمل(سجل1، مؤشر(المصفوفة[0]))

# حساب عنوان
حمل(جل1، مؤشر(المصفوفة))
اجمع(جل1، حجم_النوع(رقم) * العداد)
```

### 3.3 التحقق من صحة العناوين

```ض
# التحقق من أن العنوان في نطاق آمن
إذا(العنوان < بداية_الكومة أو العنوان > نهاية_المكدس) :-
    أطلق("خطأ: عنوان غير صالح")
نهاية
```

## 4. المكدس (Stack)

### 4.1 خصائص المكدس

- **الاتجاه:** ينمو من الأعلى إلى الأسفل
- **الحجم:** 8 ميجابايت افتراضياً
- **الوصول:** LIFO (آخر واحد يدخل أول واحد يخرج)
- **السرعة:** أسرع من الكومة

### 4.2 عمليات المكدس

```ض
# دفع قيمة على المكدس
ادفع(سجل1)           # حفظ سجل1
ادفع(المتغير)        # حفظ المتغير
ادفع(العنوان)        # حفظ عنوان

# سحب قيمة من المكدس
اسحب(جل1)           # استعادة إلى سجل1
اسحب(المتغير)        # استعادة إلى المتغير

# قراءة دون إزالة
اقرأ_مكدس(سجل1)      # قراءة القيمة العلوية بدون إزالتها
```

### 4.3 هيكل الإطار (Stack Frame)

```ض
# هيكل إطار الدالة على المكدس
# ==================================
# المحتوى              | الإزاحة
# ----------------------|----------
# المعاملات (من اليمين) | [المؤشر_الإطار+16]
# المعامل 2             | [المؤشر_الإطار+12]
# المعامل 1             | [المؤشر_الإطار+8]
# عنوان العودة           | [المؤشر_الإطار+4]
# مؤشر الإطار القديم     | [المؤشر_الإطار]
# المتغيرات المحلية 1    | [المؤشر_الإطار-4]
# المتغيرات المحلية 2    | [المؤشر_الإطار-8]
# ...                   |
# ========================

دالة: مثال(أ: رقم، ب: رقم) -> رقم :-
    محلي: محل1 = 10
    محلي: محل2 = 20
    
    # الكود هنا
نهاية
```

### 4.4 إدارة الإطارات

```ض
# عند استدعاء دالة:
1. دفع المعاملات على المكدس
2. دفع عنوان العودة
3. نسخ مؤشر الإطار إلى مؤشر الإطار القديم
4. تحريك مؤشر الإطار إلى当前位置
5. تحريك مؤشر المكدس لتوفير مساحة للمتغيرات المحلية

# عند العودة من الدالة:
1. استعادة مؤشر المكدس من مؤشر الإطار
2. استعادة مؤشر الإطار القديم
3. القفز لعنوان العودة
```

## 5. الكومة (Heap)

### 5.1 خصائص الكومة

- **الاتجاه:** تنمو من الأسفل إلى الأعلى
- **الحجم:** متغير (يصل لنهاية الذاكرة المتاحة)
- **الوصول:** عشوائي
- **السرعة:** أبطأ من المكدس

### 5.2 عمليات الكومة

```ض
# حجز ذاكرة
متغير: مؤشر: مؤشر_نوع(رقم) = حجز(100 * حجم_النوع(رقم))

# تغيير حجم الذاكرة المحجوزة
المؤشر = غيّر_حجم(المؤشر، 200 * حجم_النوع(رقم))

# تحرير الذاكرة
حرر(المؤشر)

# التحقق من نجاح الحجز
إذا(المؤشر == فراغ) :-
    أطلق("خطأ: فشل الحجز")
نهاية
```

### 5.3 إدارة الكومة

```ض
# مخطط الكومة البسيط
# ===================
# المنطقة              | الحالة
# ---------------------|----------
# 0x00A00000-0x00AFFFFF | حرة
# 0x00B00000-0x00BFFFFF | محجوزة (100 بايت)
# 0x00C00000-0x00CFFFFF | حرة
# ...                  |
# =====================

# ملاحظة: هذا مخطط مبسط. الإصدار الحقيقي سيكون أكثر تعقيداً.
```

### 5.4 تجميع الكومة (Garbage Collection)

**لا يوجد جمع قمامة تلقائي في ض Core.** يجب على المبرمج تحرير الذاكرة يدوياً.

```ض
# سيئة: تسريب ذاكرة
دالة: سيئة() :-
    متغير: مؤشر = حجز(100)
    # ... استخدام المؤشر
    # نسيان تحرير الذاكرة!
نهاية

# جيدة: إدارة صحيحة
دالة: جيدة() :-
    متغير: مؤشر = حجز(100)
    # ... استخدام المؤشر
    حرر(المؤشر)  # تحرير واضح
نهاية
```

## 6. المؤشرات (Pointers)

### 6.1 تعريف المؤشرات

```ض
# مؤشر عادي
متغير: مؤشر: مؤشر_نوع(رقم)

# مؤشر إلى مؤشر
متغير: مؤشر_عميق: مؤشر_نوع(مؤشر_نوع(رقم))

# مؤشر حر (void pointer)
متغير: مؤشر_حر: مؤشر_نوع(فراغ)
```

### 6.2 عمليات المؤشرات

```ض
# تحميل عنوان
حمل(المؤشر، مؤشر(المتغير))

# الوصول للقيمة
اقرأ_ذاكرة(سجل1، [المؤشر])

# كتابة عبر المؤشر
خزن([المؤشر]، القيمة)

# حساب الإزاحة
اجمع(المؤشر، حجم_النوع(رقم) * العداد)
```

### 6.3 مؤشرات المصفوفات

```ض
# مصفوفة
متغير: مصفوفة: رقم[10]

# مؤشر للعنصر الأول
متغير: مؤشر: مؤشر_نوع(رقم) = مؤشر(المصفوفة[0])

# الوصول للعنصر
اقرأ_ذاكرة(سجل1، [المؤشر + العداد * حجم_النوع(رقم)])
```

## 7. التعامل مع البيانات

### 7.1 أنواع البيانات في الذاكرة

```ض
# حجم الأنواع الأساسية
ثابت: حجم_رقم = 8        # 64 بت
ثابت: حجم_رقم_عشري = 8   # 64 بت
ثابت: حجم_حرف = 1        # 8 بت
ثابت: حجم_منطق = 1       # 8 بت
ثابت: حجم_مؤشر = 8       # 64 بت
```

### 7.2 ترتيب البايتات (Endianness)

```ض
# ض Core تستخدم Little Endian (مثل x86)
# البايت الأقل أهمية يُخزن أولاً

# مثال: الرقم 0x12345678
# العنوان 0: 0x78
# العنوان 1: 0x56
# العنوان 2: 0x34
# العنوان 3: 0x12
```

### 7.3 المحاذاة (Alignment)

```ض
# البيانات يجب أن تكون محاذاة لحدودها الطبيعية
# هذا يحسن الأداء ويمنع أخطاء المحاذاة

# مثال: رقم 64 بت يجب أن يكون على عنوان مقسوم على 8
0x0000: صحيح (0 % 8 == 0)
0x0001: خاطئ (1 % 8 != 0)
0x0008: صحيح (8 % 8 == 0)
```

## 8. حماية الذاكرة

### 8.1 لا حماية تلقائية

**ض Core لا توفر حماية تلقائية للذاكرة.** هذا يعني:

```ض
# يمكن الكتابة في أي عنوان
خزن([0x00000000]، 100)  # قد يسبب crash!

# يمكن قراءة أي عنوان
اقرأ_ذاكرة(سجل1، [0xFFFFFFFF])  # قد يسبب crash!

# يمكن تنفيذ كود من منطقة بيانات
اقفز(0x00800000)  # خطر أمني!
```

### 8.2 الحماية اليدوية

**يجب على المبرمج الحفاظ على سلامة الذاكرة يدوياً.**

```ض
# التحقق من صحة المؤشر قبل الاستخدام
إذا(المؤشر == فراغ أو المؤشر < بداية_الكومة أو المؤشر > نهاية_الكومة) :-
    أطلق("خطأ: مؤشر غير صالح")
    ارجع()
نهاية

# استخدام المؤشر
اقرأ_ذاكرة(سجل1، [المؤشر])
```

### 8.3 أدوات مساعدة (مستقبلاً)

```ض
# أدوات مساعدة للتحقق (ستكون متاحة مستقبلاً)
دالة: تحقق_العنوان(عنوان: مؤشر_نوع(فراغ)) -> منطق :-
    إذا(العنوان == فراغ) :-
        ارجع(خطأ)
    نهاية
    إذا(العنوان < بداية_الذاكرة أو العنوان > نهاية_الذاكرة) :-
        ارجع(خطأ)
    نهاية
    ارجع(صحيح)
نهاية
```

## 9. إدارة الذاكرة اليدوية

### 9.1 بسيط (Bump Allocator)

```ض
# موزع بسيط: يخصم من مؤشر الكومة فقط

ثابت: بداية_الكومة = 0x00A00000
متغير: مؤشر_الحالي = بداية_الكومة

دالة: حجز(حجم: رقم) -> مؤشر_نوع(فراغ) :-
    متغير: العنوان = مؤشر_الحالي
    مؤشر_الحالي = مؤشر_الحالي + حجم
    ارجع(العنوان)
نهاية

دالة: تحرير(العنوان: مؤشر_نوع(فراغ)) :-
    # لا يفعل شيئاً في الموزع البسيط
نهاية
```

### 9.2 حلول محددة (Free List Allocator)

```ض
# موزع بسيط مع قائمة حرة

نوع: كتلة_ذاكرة = {
    الحجم: رقم،
    التالية: مؤشر_نوع(كتلة_ذاكرة)，
    حرة: منطق
}

دالة: حجز_محدد(حجم: رقم) -> مؤشر_نوع(فراغ) :-
    # البحث عن كتلة حرة مناسبة
    متغير: الحالي = بداية_الكتل
    طالما(الحالي != فراغ) :-
        إذا(الحالي.حرة و الحالي.الحجم >= حجم) :-
            # وجدنا كتلة مناسبة
            الحالي.حرة = خطأ
            ارجع(الحالي + حجم_النوع(كتلة_ذاكرة))
        نهاية
        الحالي = الحالي.التالية
    نهائية
    ارجع(فراغ)  # لم نجد
نهاية
```

## 10. مثال شامل

```ض
# برنامج يدير ذاكرة يدوياً

# تعريف أنواع البيانات
نوع: طالب = {
    الاسم: حرف[50]，
    العمر: رقم،
    المعدل: رقم_عشري
}

# دالة إنشاء طالب
دالة: إنشاء_طالب(اسم: مؤشر_نوع(حرف)، عمر: رقم، معدل: رقم_عشري) -> مؤشر_نوع(طالب) :-
    # حجز ذاكرة للطالب
    متغير: المؤشر = حجز(حجم_النوع(طالب))
    
    # التحقق من نجاح الحجز
    إذا(المؤشر == فراغ) :-
        أطلق("خطأ: فشل الحجز")
        ارجع(فراغ)
    نهاية
    
    # نسخ البيانات
    انسخ_ذاكرة(المؤشر + إزاحة(طالب.الاسم)， الاسم، 50)
    خزن([المؤشر + إزاحة(طالب.العمر)]، العمر)
    خزن([المؤشر + إزاحة(طالب.المعدل)]، المعدل)
    
    ارجع(المؤشر)
نهاية

# دالة حذف طالب
دالة: حذف_طالب(مؤشر: مؤشر_نوع(طالب)) :-
    إذا(المؤشر != فراغ) :-
        حرر(المؤشر)
    نهاية
نهاية

# دالة رئيسية
دالة: الرئيسية() :-
    # إنشاء طلاب
    متغير: طالب1 = إنشاء_طالب("أحمد"، 20، 3.5)
    متغير: طالب2 = إنشاء_طالب("محمد"، 21، 3.8)
    
    # استخدام الطلاب
    اطبع("الطالب 1:", [طالب1 + إزاحة(طالب.الاسم)])
    اطبع("الطالب 2:", [طالب2 + إزاحة(طالب.الاسم)])
    
    # حذف الطلاب
    حذف_طالب(طالب1)
    حذف_طالب(طالب2)
    
    ارجع(0)
نهاية
```

## 11. ملخص

### 11.1 المبادئ الأساسية

1. **التحكم الكامل:** المبرمج يتحكم في كل بايت
2. **لا حماية تلقائية:** يدوية فقط
3. **لا جمع قمامة:** تحرير يدوي
4. **المباشرة:** لا طبقات إضافية

### 11.2 المناطق الأساسية

1. **الكود:** غير قابل للكتابة
2. **الثوابت:** غير قابلة للكتابة
3. **البيانات:** قابلة للقراءة والكتابة
4. **الكومة:** ديناميكية
5. **المكدس:** سريعة ومحدودة (8 ميجابايت)

### 11.3 العمليات الأساسية

1. **التحميل:** حمل من الذاكرة إلى السجل
2. **التخزين:** حفظ من السجل إلى الذاكرة
3. **الدفع:** حفظ على المكدس
4. **السحب:** استعادة من المكدس
5. **الحجز:** تخصيص من الكومة
6. **التحرير:** تحرير من الكومة

### 11.4 التوسع المستقبلي

- دعم الذاكرة الافتراضية (Virtual Memory)
- حماية الذاكرة على مستوى نظام التشغيل
- موزعين متقدمين (Slab, Pool)
- دعم متعدد الخيوط (Thread Safety)

## 12. التغييرات عن الإصدار 0.1

1. استخدام `فراغ` بدلاً من `null`
2. استخدام `أطلق` بدلاً من `أعلن`
3. استخدام `خطأ` و `صحيح` بدلاً من `خطا` و `ص`
4. استخدام `:-` لبداية جسم الدالة
5. استخدام `اقرأ_ذاكرة` و `اقرأ_مكدس` بدلاً من `اقرأ`
6. استخدام `انسخ_ذاكرة` و `امسح_ذاكرة`
7. استخدام `غيّر_حجم` بدلاً من `عدّل`
8. استخدام `حجم_النوع` بدلاً من `حجم`
9. استخدام `المؤشر_المكدس` و `المؤشر_الإطار`
10. تحديد حجم المكدس بـ 8 ميجابايت
