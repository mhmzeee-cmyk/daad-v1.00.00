## الاختبارات الأساسية (1-20)

### 1. تعريف متغير أساسي
```ض
متغير: عدد: رقم = 10
اطبع(العدد)
```

### 2. تعريف ثابت
```ض
ثابت: النهاية: رقم = 100
اطبع(النهاية)
```

### 3. عمليات حسابية
```ض
متغير: أ: رقم = 10
متغير: ب: رقم = 5
اطبع(اجمع(أ، ب))
اطبع(اطرح(أ، ب))
اطبع(اضرب(أ، ب))
اطبع(اقسم(أ، ب))
اطبع(باقي(أ، ب))
```

### 4. شرط إذا
```ض
إذا(عدد > 10) :-
    اطبع("العدد كبير")
نهاية
```

### 5. شرط إذا وإلا
```ض
إذا(عدد > 10) :-
    اطبع("كبير")
وإلا :-
    اطبع("صغير")
نهاية
```

### 6. حلقة طالما
```ض
متغير: عداد: رقم = 0
طالما(العداد < 10) :-
    اطبع(العداد)
    العداد = العداد + 1
نهاية
```

### 7. حلقة لكل
```ض

```

```

### 9. دالة بدون إرجاع

```
