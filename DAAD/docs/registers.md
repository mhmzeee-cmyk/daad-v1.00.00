# ض Core - السجلات (Registers) - الإصدار المُصحح

**الإصدار:** 0.1.1 (بعد المراجعة)
**تاريخ الإصدار:** 2026-08-03
**الحالة:** مُعتمد

---

## 1. فلسفة التعامل مع السجلات

### 1.1 المبدأ الأساسي

في ض Core، لا نستخدم أسماء السجلات الحقيقية للمعالج (مثل AX, RAX, X0). بدلاً من ذلك، نستخدم **أسماء مجردة** تعكس الوظيفة.

### 1.2 لماذا أسماء مجردة؟

1. **الاستقلالية:** اللغة لا تвяз بمعمارية معينة
2. **الوضوح:** الأسماء وصفية وواضحة
3. **البساطة:** لا حاجة لحفظ أسماء السجلات لكل معمارية
4. **المرونة:** يمكن ربطها بأي معمارية لاحقاً

### 1.3 المقارنة

| المنهج | Assembly | ض Core |
|--------|----------|--------|
| **الاسم** | AX, BX, CX | سجل1، سجل2، سجل3 |
| **الوظيفة** | محددة مسبقاً | حسب الاستخدام |
| **عدد** | محدود بعدد المعالج | عدد غير محدود نظرياً |
| **الاسم** | إنجليزي | عربي بالكامل |

## 2. السجلات المجردة

### 2.1 السجلات الأساسية

```ض
# السجلات الأساسية (64 بت)
سجل1    # السجل الرئيسي للعمليات الحسابية
سجل2    # سجل ثانوي للعمليات
سجل3    # سجل مؤقت للنتائج
سجل4    # سجل للمؤشرات
سجل5    # سجل للعناوين
سجل6    # سجل للعمليات الخاصة
سجل7    # سجل للإدخال/الإخراج
سجل8    # سجل عام
```

### 2.2 السجلات الخاصة

```ض
# سجل المؤشرات
المؤشر_المكدس    # مؤشر المكدس (Stack Pointer)
المؤشر_الإطار    # مؤشر الإطار (Frame Pointer)
المؤشر_البرنامج  # مؤشر البرنامج (Program Counter)

# سجل الحالة
سجل_الحالة       # سجل مسجل الحالة (Flags Register)
```

### 2.3 السجلات الافتراضية

```ض
# عند بدء تنفيذ البرنامج:
سجل1 = 0            # مسجل نشط
سجل2 = 0            # مسجل ثانوي
المؤشر_المكدس = أعلى عنوان في الذاكرة
المؤشر_الإطار = أعلى عنوان في الذاكرة
```

## 3. العمليات على السجلات

### 3.1 التحميل والتخزين

```ض
# تحميل قيمة ثابتة إلى سجل
حمل(سجل1، 10)           # سجل1 = 10
حمل(سجل2، 0xFF)         # سجل2 = 255

# تحميل من متغير
حمل(سجل1، المتغير)      # سجل1 = قيمة المتغير

# حفظ قيمة من سجل إلى متغير
خزن(المتغير، سجل1)      # المتغير = سجل1
```

### 3.2 النسخ بين السجلات

```ض
# نسخ من سجل إلى آخر
انقل(سجل1، سجل2)        # سجل2 = سجل1
```

### 3.3 العمليات الحسابية

```ض
# جمع
اجمع(سجل1، سجل2)        # سجل1 = سجل1 + سجل2
اجمع(سجل1، 10)          # سجل1 = سجل1 + 10

# طرح
اطرح(سجل1، سجل2)        # سجل1 = سجل1 - سجل2

# ضرب
اضرب(سجل1، سجل2)        # سجل1 = سجل1 * سجل2

# قسمة
اقسم(سجل1، سجل2)        # سجل1 = سجل1 / سجل2

# باقي
باقي(سجل1، سجل2)        # سجل1 = سجل1 % سجل2
```

### 3.4 العمليات المنطقية

```ض
# AND
و_بتية(سجل1، سجل2)      # سجل1 = سجل1 & سجل2

# OR
أو_بتية(سجل1، سجل2)     # سجل1 = سجل1 | سجل2

# XOR
تبادل_بتية(سجل1، سجل2)  # سجل1 = سجل1 ^ سجل2

# NOT
ليس_بتية(سجل1)           # سجل1 = ~سجل1

# تحريك يسار
تحريك_يسار(سجل1، 2)     # سجل1 = سجل1 << 2

# تحريك يمين
تحريك_يمين(سجل1، 2)     # سجل1 = سجل1 >> 2
```

### 3.5 المقارنات

```ض
# مقارنة وتحديث سجل الحالة
قارن(سجل1، سجل2)        # تحديث سجل الحالة بناءً على الفرق

# استخدام سجل الحالة في الشرط
إذا(يساوي) ->           # إذا كان سجل1 == سجل2
إذا(أكبر) ->            # إذا كان سجل1 > سجل2
إذا(أصغر) ->            # إذا كان سجل1 < سجل2
```

## 4. السجلات والدوال

### 4.1 اتفاقية استدعاء الدوال

```ض
# عند استدعاء دالة:
# - سجل1 إلى سجل4: معاملات الدالة
# - سجل5 إلى سجل8: متغيرات عودة الدالة
# - سجلات أخرى: حرة

دالة: اجمع(أ: رقم، ب: رقم) -> رقم :-
    # الأعلى في سجل1 والثاني في سجل2
    اجمع(سجل1، سجل2)    # النتيجة في سجل1
    ارجع(سجل1)          # القيمة في سجل1
نهاية
```

### 4.2 اتفاقية الاحتفاظ بالسجلات

```ض
# يجب الحفاظ على سجل1 إلى سجل4 عبر استدعاءات الدوال
# السجلات من سجل5 فما فوق يمكن تغييرها حريةاً

دالة: معقدة() :-
    # حفظ السجلات المطلوب الحفاظ عليها
    ادفع(سجل1)
    ادفع(سجل2)
    
    # تنفيذ عمليات
    حمل(سجل1، 10)
    حمل(سجل2، 20)
    اجمع(سجل1، سجل2)
    
    # استعادة السجلات
    اسحب(سجل2)
    اسحب(سجل1)
    
    ارجع(سجل1)
نهاية
```

## 6. تعريف سجلات مخصصة

### 6.1 تعريف سجل جديد

**يمكن تعريف سجلات إضافية للاستخدام المحلي.**

```ض
# تعريف سجل مخصص
سجل: النتيجة: رقم
سجل: المؤقت: رقم

# استخدامه
حمل(النتيجة، 10)
اجمع(النتيجة، 20)
```

### 6.2 حدود السجلات المخصصة

- **الحد الأقصى:** 32 سجل مخصصاً
- **الأولوية:** سجلات النظام أولاً
- **الاسم:** يجب أن يبدأ بـ "سجل" أو "سجل_"

## 7. سجل الحالة (Flags Register)

### 7.1 بتات سجل الحالة

```ض
# بت الصفر (Zero Flag)
# يُضبط عندما تكون النتيجة صفر

# بت الحمل (Carry Flag)
# يُضبط عند حدوث حمل في الجمع

# بت الفيض (Overflow Flag)
# يُضبط عند حدوث فيض

# بت الإشارة (Sign Flag)
# يُضبط عندما تكون النتيجة سالبة
```

### 7.2 استخدام سجل الحالة

```ض
# عند المقارنة
قارن(سجل1، سجل2)

# استخدام البتات
إذا(يساوي) ->        # Zero Flag = 1
إذا(لا_يساوي) ->    # Zero Flag = 0
إذا(أكبر) ->         # Sign Flag = 0 AND Zero Flag = 0
إذا(أصغر) ->         # Sign Flag = 1
```

## 8. المكدس (Stack)

### 8.1 تعريف المكدس

```ض
# المكدس: منطقة ذاكرة آخرها الأولوية
# ينمو من الأعلى إلى الأسفل في الذاكرة

ثابت: حجم_المكدس = 8 * 1024 * 1024  # 8 ميجابايت
```

### 8.2 عمليات المكدس

```ض
# دفع قيمة على المكدس
ادفع(سجل1)           # حفظ سجل1
ادفع(المتغير)        # حفظ المتغير

# سحب قيمة من المكدس
اسحب(سجل1)           # استعادة إلى سجل1
اسحب(المتغير)        # استعادة إلى المتغير

# قراءة دون إزالة
اقرأ_مكدس(سجل1)      # قراءة القيمة العلوية بدون إزالتها
```

دالة: مثال(أ: رقم، ب: رقم) -> رقم :-

## 9. التعامل مع المؤشرات

### 9.1 تعريف المؤشر

```ض
# تعريف مؤشر إلى رقم
متغير: مؤشر: مؤشر_نوع(رقم)

# تعريف مؤشر إلى حرف
متغير: مؤشر_نص: مؤشر_نوع(حرف)
```

### 9.2 تحميل العنوان

```ض
# تحميل عنوان متغير
حمل(سجل1، مؤشر(المتغير))

# تحميل عنوان مصفوفة
حمل(سجل1، مؤشر(المصفوفة[0]))
```

### 9.3 الوصول عبر المؤشر

```ض
# الوصول للقيمة عبر المؤشر
اقرأ_ذاكرة(سجل1، [سجل1])    # قراءة من العنوان في سجل1

# كتابة عبر المؤشر
خزن([المؤشر]، سجل2)    # كتابة سجل2 إلى العنوان في المؤشر
```

## 10. مثال شامل

```ض
# برنامج يحسب مجموع مصفوفة باستخدام السجلات

# تعريف المصفوفة
ثابت: البيانات = {1، 2، 3، 4، 5}
ثابت: الحجم = 5

دالة: الرئيسية() :-
    # تهيئة السجلات
    حمل(سجل1، 0)          # المجموع = 0
    حمل(سجل2، 0)          # العداد = 0
    حمل(سجل3، الحجم)      # حجم المصفوفة
    
    # حلقة التكرار
    طالما(سجل2 < سجل3) :-
        # حساب العنوان
        حمل(سجل4، مؤشر(البيانات))
        اجمع(سجل4، سجل2)
        اجمع(سجل4، سجل2)  # عنوان = البيانات + العداد * 8
        
        # قراءة القيمة
        اقرأ_ذاكرة(سجل5، [سجل4])
        
        # إضافة للمجموع
        اجمع(سجل1، سجل5)
        
        # زيادة العداد
        اجمع(سجل2، 1)
    نهائية
    
    # طباعة النتيجة
    اطبع("المجموع =", سجل1)
    
    # إرجاع النتيجة
    ارجع(سجل1)
نهاية
```

## 12. ملخص

### 12.1 القواعد الأساسية

1. **الأسماء مجردة:** لا نستخدم أسماء المعالج الحقيقية
2. **الوصفية:** الأسماء تعكس الوظيفة
3. **المرونة:** يمكن ربطها بأي معمارية
4. **البساطة:** عدد محدود من السجلات

### 12.2 الاتفاقيات

1. **سجل1 إلى سجل4:** محفوظة عبر الاستدعاءات
2. **سجل5 إلى سجل8:** ح自由
3. **المؤشرات:** خاصة ومحددة

### 12.3 التوسع المستقبلي

- إضافة سجلات متعددة الدقة (32/64 بت)
- دعم السجلات المتنائية (Vector Registers)
- دعم السجلات العشرية (Floating Point Registers)
- دعم السجلات المميزة (SIMD Registers)

## 13. التغييرات عن الإصدار 0.1

1. استبدال `المؤشر_ال.stack` بـ `المؤشر_المكدس`
2. استبدال `المؤشر_ال框` بـ `المؤشر_الإطار`
3. استبدال `المؤشر_ال programme` بـ `المؤشر_البرنامج`
4. استبدال `asil` بـ `و_بتية`
5. استبدال ` xor` بـ `تبادل_بتية`
6. استبدال `shift_يسار` بـ `تحريك_يسار`
7. استبدال `shift_يمين` بـ `تحريك_يمين`
8. استخدام `:-` لبداية جسم الدالة
9. استخدام `اقرأ_ذاكرة` بدلاً من `اقرأ`
10. استخدام `اقرأ_مكدس` بدلاً من `اقرأ_المكدس`
