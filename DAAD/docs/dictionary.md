## أ

### إذا

| الحقل | القيمة |
|-------|--------|
| **الكلمة** | `إذا` |
| **النوع** | تحكم شرطي |
| **المقارنة في C** | `if` |
| **مرجع قرار** | D-042 |
| **حالة الاستخدام** | نشط |

**التعريف:** تبدأ كتلة شرطية. إذا تحقق الشرط يتم تنفيذ الكود بداخلها.

**الاستخدام:**
```ض
إذا(شرط) :-
    # كود
نهاية
```

**أمثلة:**
```ض
إذا(عدد > 10) :-
    اطبع("العدد كبير")
نهاية

إذا(اسم == "أحمد") :-
    اطبع("مرحباً أحمد")
نهاية
```

**قواعد:**
- الشرط يجب أن يكون بين قوسين `()`
- تنتهي بكلمة `نهاية`
- يمكن دمجها مع `وإلا`

### ارجع

| الحقل | القيمة |
|-------|--------|
| **الكلمة** | `ارجع` |
| **النوع** | تحكم تدفق |
| **المقارنة في C** | `return` |
| **مرجع قرار** | - |
| **حالة الاستخدام** | نشط |

**التعريف:** تُرجع قيمة من الدالة وتوقف التنفيذ.

**الاستخدام:**
```ض
ارجع(قيمة)      # إرجاع قيمة
ارجع()           # إرجاع بدون قيمة
```

**أمثلة:**
```ض
دالة: اجمع(أ: رقم، ب: رقم) -> رقم :-
    ارجع(أ + ب)
نهاية

دالة: اطبع_تحية() :-
    اطبع("مرحباً")
    ارجع()
نهاية
```

**قواعد:**
- القيمة يجب أن تتوافق مع نوع الإرجاع
- يمكن إرجاع تعبيرات
- إرجاع بدون قيمة فقط للدوال بدون نوع إرجاع

### اطرح

| الحقل | القيمة |
|-------|--------|
| **الكلمة** | `اطرح` |
| **النوع** | عملية حسابية |
| **المقارنة في C** | `-` |
| **مرجع قرار** | - |
| **حالة الاستخدام** | نشط |

**التعريف:** طرح رقمين.

**الاستخدام:**
```ض
اطرح(سجل1، سجل2)    # سجل1 = سجل1 - سجل2
اطرح(سجل1، قيمة)     # سجل1 = سجل1 - قيمة
```

**أمثلة:**
```ض
اطرح(سجل1، سجل2)    # إذا كان سجل1=10 وسجل2=3، النتيجة=7
اطرح(سجل1، 5)        # إذا كان سجل1=10، النتيجة=5
```

**قواعد:**
- العملية تُ修改 المعدل الأول
- النتيجة تُخزن في المعدل الأول

**أمثلة:**
```ض
قارن(سجل1، سجل2)
إذا(يساوي) :-
    اطبع("متساويان")
نهاية
```

**التأثير على سجل الحالة:**
- إذا كان سجل1 == سجل2: Zero Flag = 1
- إذا كان سجل1 > سجل2: Sign Flag = 0
- إذا كان سجل1 < سجل2: Sign Flag = 1

### لكل

| الحقل | القيمة |
|-------|--------|
| **الكلمة** | `لكل` |
| **النوع** | حلقة تكرار |

| **حالة الاستخدام** | نشط |

**الاستخدام:**

- الشرط يُقيم قبل كل تكرار
- التكرار يُنفذ بعد كل دورة
