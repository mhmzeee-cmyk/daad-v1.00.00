## 1.2 وصف المراحل

| المرحلة | المدخل | المخرج | الوصف |
|---------|--------|--------|-------|
| Lexer | نص المصدر | رموز (Tokens) | تحويل النص لرموز |
| Parser | رموز | AST | بناء شجرة الإعراب |
| Semantic | AST | AST مُدقّق | فحص الأخطاء الدلالية |
| IR | AST | IR | تحويل لتمثيل داخلي |
| Optimizer | IR | IR مُحسّن | تحسين الكود |
| Backend | IR | تعليمات | توليد الكود للمعادية |
| Encoder | تعليمات | ثنائي | ترميز التعليمات |

# الفصل 2: مراحل الترجمة

## 2.1 مرحلة التحليل (Frontend)

```
النص → [Lexer] → [Parser] → [Semantic Analyzer] → AST
```

### الهدف
- تحويل النص إلى شجرة إعراب
- فحص الأخطاء النحوية والدلالية

## 2.2 مرحلة التحويل (Middleend)

```
AST → [IR Generator] → [Optimizer] → IR مُحسّن
```

### الهدف
- تحويل AST لتمثيل داخلي سهل التعديل
- تحسين الكود

## 2.3 مرحلة التوليد (Backend)

```
IR → [Code Generator] → [Instruction Encoder] → ثنائي
```

### الهدف
- توليد كود لكل معمارية مدعومة

# الفصل 3: المحلل البصري (Lexer)

## 3.1 المدخل والمخرج

```
المدخل: "متغير: عدد: رقم = 10"

المخرج: [
    { نوع: "متغير", قيمة: "متغير", سطر: 1, عمود: 1 },
    { نوع: "نقطتين", قيمة: ":", سطر: 1, عمود: 8 },
    { نوع: "معرف", قيمة: "عدد", سطر: 1, عمود: 10 },
    { نوع: "نقطتين", قيمة: ":", سطر: 1, عمود: 13 },
    { نوع: "نوع", قيمة: "رقم", سطر: 1, عمود: 15 },
    { نوع: "تعيين",_value: "=", سطر: 1, عمود: 19 },
    { نوع: "عدد", قيمة: "10", سطر: 1, عمود: 21 }
]
```

## 3.2 أنواع الرموز (Token Types)

### كلمات مفتاحية
```
متغير, ثابت, نوع, دالة, إذا, وإلا, طالما, لكل, ارجع, نهاية, ...
```

### أنواع بيانات
```
رقم, رقم_عشري, حرف, منطق, نص, مؤشر_نوع, هيكل, مصفوفة
```

### عمليات
```
اجمع, اطرح, اضرب, اقسم, باقي, و, أو, ليس
```

### رموز
```
: :- -> ( ) { } [ ] , .
```

### معرفات
```
أسماء المتغيرات والدوال
```

### قيم
```
أعداد صحيحة, أعداد عشرية, حروف, نصوص
```

## 3.3 هيكل الرمز (Token Struct)

```c
typedef struct {
    TokenType type;      // نوع الرمز
    const char* value;   // قيمة النص الأصلي
    int line;            // رقم السطر
    int column;          // رقم العمود
} Token;
```

# الفصل 4: المحلل النحوي (Parser)

## 4.1 المدخل والمخرج

```
المدخل: [array of tokens]

المخرج: AST (Abstract Syntax Tree)
```

## 4.2 قواعد النحو (Grammar Rules)

### تعريف متغير
```
VariableDecl ::= 'متغير' ':' IDENTIFIER ':' TYPE '=' Expression
```

### تعريف ثابت
```
ConstantDecl ::= 'ثابت' ':' IDENTIFIER '=' Expression
```

### تعريف دالة
```
FunctionDecl ::= 'دالة' ':' IDENTIFIER '(' ParamList ')' '->' TYPE ':-' Block 'نهاية'
```

### جملة شرطية
```
IfStmt ::= 'إذا' '(' Expression ')' ':-' Block ('وإلا' ':-' Block)? 'نهاية'
```

### حلقة تكرارية
```
WhileStmt ::= 'طالما' '(' Expression ')' ':-' Block 'نهاية'
ForStmt ::= 'لكل' '(' ForInit ';' Expression ';' ForUpdate ')' ':-' Block 'نهاية'
```

## 4.3 هيكل الشجرة (AST Nodes)

```c
typedef enum {
    NODE_VARIABLE_DECL,
    NODE_CONSTANT_DECL,
    NODE_FUNCTION_DECL,
    NODE_IF_STMT,
    NODE_WHILE_STMT,
    NODE_FOR_STMT,
    NODE_RETURN_STMT,
    NODE_BINARY_EXPR,
    NODE_UNARY_EXPR,
    NODE_IDENTIFIER,
    NODE_NUMBER,
    NODE_STRING,
    NODE_CALL,
    NODE_BLOCK
} NodeType;

typedef struct ASTNode {
    NodeType type;
    union {
        struct { char* name; ASTNode* value; } variable;
        struct { char* name; ASTNode* params; ASTNode* body; } function;
        struct { ASTNode* condition; ASTNode* then_block; ASTNode* else_block; } if_stmt;
        struct { ASTNode* left; Operator op; ASTNode* right; } binary;
        // ... المزيد من العناصر
    } data;
    int line;
    int column;
} ASTNode;
```

# الفصل 5: شجرة الإعراب (AST)

## 5.1 أمثلة على الشجر

### مثال 1: تعريف متغير

```
المصدر: متغير: عدد: رقم = 10

الشجرة:
    VariableDecl
    ├── name: "عدد"
    ├── type: "رقم"
    └── value: Number(10)
```

### مثال 2: جملة شرطية

```
المصدر:
إذا(أ > ب) :-
    اطبع("أكبر")
نهاية

الشجرة:
    IfStmt
    ├── condition: BinaryExpr(>, Identifier("أ"), Identifier("ب"))
    └── then_block: Block
        └── Call("اططبع", [String("أكبر")])
```

### مثال 3: دالة

```
المصدر:
دالة: اجمع(أ: رقم، ب: رقم) -> رقم :-
    ارجع(أ + ب)
نهاية

الشجرة:
    FunctionDecl
    ├── name: "اجمع"
    ├── params:
    │   ├── Param("أ", "رقم")
    │   └── Param("ب", "رقم")
    ├── return_type: "رقم"
    └── body: Block
        └── Return
            └── BinaryExpr(+, Identifier("أ"), Identifier("ب"))
```

# الفصل 6: المحلل الدلالي (Semantic Analyzer)

## 6.1 المهام

### 6.1.1 فحص النطاق (Scope Checking)

```ض
# صحيح
متغير: أ = 10
إذا(أ > 5) :-
    متغير: ب = 20    # ب محلية للشرط
نهاية

# خطأ
إذا(أ > 5) :-
    متغير: ب = 20
نهاية
اططبع(ب)    # خطأ! ب خارج النطاق
```

### 6.1.2 فحص الأنواع (Type Checking)

```ض
# صحيح
متغير: أ: رقم = 10
متغير: ب: رقم = 5
متغير: ج: رقم = أ + ب

# خطأ
متغير: أ: رقم = 10
متغير: ب: نص = "أحمد"
متغير: ج = أ + ب    # خطأ! رقم + نص
```

### 6.1.3 فحص الدوال (Function Checking)

```ض
# صحيح
دالة: اجمع(أ: رقم، ب: رقم) -> رقم :-
    ارجع(أ + ب)
نهاية
اجمع(10، 20)

# خطأ
اجمع(10)    # خطأ! نقص معامل
```

## 6.2 جدول الرموز (Symbol Table)

```c
typedef struct Symbol {
    char* name;
    Type* type;
    Scope* scope;
    int offset;
    bool is_function;
} Symbol;

typedef struct SymbolTable {
    Symbol** symbols;
    int count;
    struct SymbolTable* parent;
} SymbolTable;
```

## 6.3 الأخطاء الدلالية

| الخطأ | الوصف | الكود |
|-------|-------|-------|
| متغير غير معروف | استخدام متغير لم يُعرّف | S001 |
| عدم تطابق الأنواع | عملية على نوعين مختلفين | S002 |
| دالة غير معروفة | استدعاء دالة غير مُعرّفة | S003 |
| عدد أخطاء المعاملات | عدد المعاملات غير صحيح | S004 |
| متغير مُعرّف مرتين | تعريف نفس المتغير مرتين | S005 |
| نوع غير معروف | استخدام نوع غير مُعرّف | S006 |

# الفصل 7: التمثيل الداخلي (IR)

## 7.1 لماذا IR؟

- تسهيل التحسين
- فصل الـ Frontend عن الـ Backend
- إمكانية دعم عدة معماريات

## 7.2 نوع IR: Three-Address Code

```
# المصدر:_result = أ + ب * ج

# IR:
t1 = ب * ج
t2 = أ + t1
نتيجة = t2
```

## 7.3 هيكل IR

```c
typedef enum {
    IR_ASSIGN,
    IR_ADD,
    IR_SUB,
    IR_MUL,
    IR_DIV,
    IR_MOD,
    IR_AND,
    IR_OR,
    IR_NOT,
    IR_LOAD,
    IR_STORE,
    IR_JUMP,
    IR_BRANCH,
    IR_CALL,
    IR_RETURN,
    IR_LABEL
} IRInstructionType;

typedef struct IRInstruction {
    IRInstructionType type;
    char* dest;
    char* src1;
    char* src2;
    int line;
} IRInstruction;

typedef struct IRFunction {
    char* name;
    IRInstruction** instructions;
    int count;
    int capacity;
} IRFunction;
```

## 7.4 أمثلة على IR

### مثال 1: عملية حسابية

```
المصدر: نتيجة = أ + ب * ج

IR:
t1 = ب * ج
t2 = أ + t1
نتيجة = t2
```

### مثال 2: شرط

```
المصدر:
إذا(أ > ب) :-
    النتيجة = 1
وإلا :-
    النتيجة = 0
نهاية

IR:
if أ > ب goto L1
النتيجة = 0
goto L2
L1:
النتيجة = 1
L2:
```

### مثال 3: حلقة

```
المصدر:
لكل(عداد = 0؛ العداد < 10؛ العداد = العداد + 1) :-
    اطبع(العداد)
نهاية

IR:
عداد = 0
L1:
if العداد >= 10 goto L2
call اطبع, العداد
عداد = العداد + 1
goto L1
L2:
```

# الفصل 8: المُحسّن (Optimizer)

## 8.1 أنواع التحسين

### 8.1.1 تحسين على مستوى IR

| التحسين | الوصف |
|---------|-------|
| نشر الثوابت | استبدال الثابت بقيمته |
| إزالة الكود الميت | حذف الكود غير المستخدم |
| دمج الأكواد المتشابهة | إزالة التكرار |
| تبسيط التعبيرات | تبسيط الحسابات |

### 8.1.2 تحسين على مستوى الكود

| التحسين | الوصف |
|---------|--------|
| استخدام السجلات | تقليل الوصول للذاكرة |
| ترتيب التعليمات | تحسين التدفق |
| تقليل الحركة | تقليل نسخ البيانات |

## 8.2 مثال على التحسين

```
# قبل التحسين
ت1 = 2 + 3
ت2 = ت1 * 4

# بعد التحسين (نشر الثوابت)
ت1 = 5
ت2 = 5 * 4

# بعد التحسين (تبسيط)
ت2 = 20
```

# الفصل 9: الخلفية (Backend)

## 9.1 المهام

1. تحويل IR لكود لكل معمارية
2. إدارة السجلات
3. توزيع المتغيرات على المكدس
4. توليد كود الدوال

## 9.2 المعماريات المدعومة

| المعمارية | الحالة |
|-----------|--------|
| x86-64 | ✅ مدعوم |
| ARM64 | ✅ مدعوم |
| RISC-V | ✅ مدعوم |

## 9.3 مثال على توليد الكود

### IR

```
نتيجة = أ + ب
```

### x86-64

```asm
mov rax, [rbp-8]    # تحميل أ
add rax, [rbp-16]   # إضافة ب
mov [rbp-24], rax   # حفظ النتيجة
```

### ARM64

```asm
ldr x0, [fp, #-8]    # تحميل أ
ldr x1, [fp, #-16]   # تحميل ب
add x0, x0, x1       # الجمع
str x0, [fp, #-24]   # حفظ النتيجة
```
