|-------|--------|

| الحقل | القيمة |
|-------|--------|
| **الرقم** | D-012 |
| **الحالة** | ثابت |
| **الأولوية** | عالية |
| **تاريخ الاعتماد** | 2026-08-03 |

**المشكلة:** `:` تُستخدم لأغراض مختلفة.

**القرار:** `:` تأتي بعد الكلمة المفتاحية دائماً.

```ض
متغير: عدد: رقم = 10    # فصل الاسم عن النوع
ثابت: النهاية = 100      # فصل الاسم عن القيمة
دالة: اجمع(...)          # فصل الكلمة عن الاسم
نوع: نقطة = { ... }      # فصل الكلمة عن الاسم
@ نهاية_الحلقة:          # تعريف علامة
```
