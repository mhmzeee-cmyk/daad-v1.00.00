# الفصل 1: مقدمة

## 1.1 ما هو ABI؟

واجهة التطبيق الثنائية (Application Binary Interface) تحدد كيف تتفاعل الدوال على المستوى الثنائي. تشمل:

- كيفية تمرير المعاملات
- أين توضع قيمة الإرجاع
- من يحفظ السجلات
- محاذاة المكدس
- ترتيب المتغيرات في الذاكرة

## 1.2 لماذا نحتاج ABI؟

1. **التوافق:** السماح بالاستدعاء بين وحدات مختلفة
2. **الأداء:** تحسين استخدام السجلات والمكدس
3. **الثبات:** ضمان سلوك متسق عبر المنصات

# الفصل 2: اتفاقية الاستدعاء

## 2.1 المبدأ الأساسي

ض Core تستخدم اتفاقية استدعاء مبنية على السجلات أولاً، ثم المكدس.

## 2.2 تمرير المعاملات

### المعمارية x86-64

| ترتيب المعامل | السجل المستخدم |
|---------------|----------------|
| المعامل 1 | `سجل1` (RDI) |
| المعامل 2 | `سجل2` (RSI) |
| المعامل 3 | `سجل3` (RDX) |
| المعامل 4 | `سجل4` (RCX) |
| المعامل 5 | `سجل5` (R8) |
| المعامل 6 | `سجل6` (R9) |
| المعامل 7+ | المكدس |

### المعمارية ARM64

| ترتيب المعامل | السجل المستخدم |
|---------------|----------------|
| المعامل 1 | `سجل1` (X0) |
| المعامل 2 | `سجل2` (X1) |
| المعامل 3 | `سجل3` (X2) |
| المعامل 4 | `سجل4` (X3) |
| المعامل 5 | `سجل5` (X4) |
| المعامل 6 | `سجل6` (X5) |
| المعامل 7+ | المكدس |

### المعمارية RISC-V

| ترتيب المعامل | السجل المستخدم |
|---------------|----------------|
| المعامل 1 | `سجل1` (a0) |
| المعامل 2 | `سجل2` (a1) |
| المعامل 3 | `سجل3` (a2) |
| المعامل 4 | `سجل4` (a3) |
| المعامل 5 | `سجل5` (a4) |
| المعامل 6 | `سجل6` (a5) |
| المعامل 7+ | المكدس |

## 2.3 أمثلة

```ض
# دالة بمعاملين
دالة: اجمع(أ: رقم، ب: رقم) -> رقم :-
    # أ في سجل1، ب في سجل2
    اجمع(سجل1، سجل2)
    # النتيجة في سجل1 (تُرجع تلقائياً)
نهاية
```

```ض
# دالة بعدة معاملات
دالة: معقدة(أ: رقم، ب: رقم، ج: رقم، د: رقم) -> رقم :-
    # أ في سجل1، ب في سجل2
    # ج في سجل3، د في سجل4
نهاية
```

# الفصل 3: إدارة السجلات

## 3.1 تصنيف السجلات

### سجلات محفوظة (Callee-saved)

يجب الحفاظ عليها عبر استدعاءات الدوال:

| ض Core | x86-64 | ARM64 | RISC-V |
|--------|--------|-------|--------|
| `سجل7` | RBX | X19 | s0 |
| `المؤشر_الإطار` | RBP | FP | fp |
| `المؤشر_المكدس` | RSP | SP | sp |

### سجلات مؤقتة (Caller-saved)

يمكن تغييرها حريةاً:

| ض Core | x86-64 | ARM64 | RISC-V |
|--------|--------|-------|--------|
| `سجل1` | RAX | X0 | a0 |
| `سجل2` | RDI | X1 | a1 |
| `سجل3` | RSI | X2 | a2 |
| `سجل4` | RDX | X3 | a3 |
| `سجل5` | RCX | X4 | a4 |
| `سجل6` | R8 | X5 | a5 |

## 3.2 حفظ السجلات

### في بداية الدالة

```ض
دالة: معقدة() :-
    # حفظ السجلات المحفوظة
    ادفع(سجل7)
    ادفع(المؤشر_الإطار)
    
    # الكود هنا
نهاية
```

### في نهاية الدالة

```ض
    # استعادة السجلات
    اسحب(المؤشر_الإطار)
    اسحب(سجل7)
    
    ارجع()
نهاية
```

# الفصل 4: المكدس

## 4.1 هيكل الإطار (Stack Frame)

```
العالي (العناوين الأعلى)
┌─────────────────────────┐
│   المعاملات الإضافية    │ [المؤشر_الإطار+32]
├─────────────────────────┤
│   المعامل 6             │ [المؤشر_الإطار+24]
├─────────────────────────┤
│   المعامل 5             │ [المؤشر_الإطار+16]
├─────────────────────────┤
│   عنوان العودة           │ [المؤشر_الإطار+8]
├─────────────────────────┤
│   مؤشر الإطار القديم     │ [المؤشر_الإطار]
├─────────────────────────┤
│   المتغيرات المحلية 1    │ [المؤشر_الإطار-8]
├─────────────────────────┤
│   المتغيرات المحلية 2    │ [المؤشر_الإطار-16]
├─────────────────────────┤
│         ...              │
└─────────────────────────┘
المنخفض (العناوين الأدنى)
```

## 4.2 محاذاة المكدس

- **الحد الأدنى للمحاذاة:** 8 بايت (x86-64, ARM64, RISC-V)
- **يجب أن يكون مؤشر المكدس دائماً مقسوماً على 8**

```ض
# عند الدفع
ادفع(سجل1)    # ينقص مؤشر المكدس بـ 8 بايت

# عند السحب
اسحب(سجل1)    # يزداد مؤشر المكدس بـ 8 بايت
```

## 4.3 دفع المعاملات على المكدس

**عند وجود أكثر من 6 معاملات:**

```ض
دالة: كثيرة(أ، ب، ج، د، هـ، و، ز) :-
    # المعاملات 1-6 في السجلات
    # المعامل 7 (ز) على المكدس
نهاية
```

# الفصل 5: ترتيب الذاكرة

## 5.1 ترتيب البايتات (Endianness)

**ض Core تستخدم Little Endian** (مثل x86-64 و ARM64 و RISC-V).

```
الرقم 0x12345678:
العنوان 0: 0x78 (أقل بايت)
العنوان 1: 0x56
العنوان 2: 0x34
العنوان 3: 0x12 (أكثر بايت)
```

## 5.2 المحاذاة (Alignment)

| النوع | الحجم | المحاذاة |
|-------|-------|----------|
| `رقم` | 8 بايت | 8 |
| `رقم_عشري` | 8 بايت | 8 |
| `حرف` | 1 بايت | 1 |
| `منطق` | 1 بايت | 1 |
| `مؤشر` | 8 بايت | 8 |

## 5.3 ملء الهياكل (Padding)

```ض
نوع: مثال = {
    أ: حرف،    # 1 بايت + 7 بايت ملء
    ب: رقم     # 8 بايت
}

# الحجم الكلي = 16 بايت
```

# الفصل 6: القيم الإرجاعية

## 6.1 قيمة الإرجاع في السجل

### للأنواع الأساسية (8 بايت فأقل)

| النوع | سجل الإرجاع |
|-------|-------------|
| `رقم` | `سجل1` (RAX/X0/a0) |
| `رقم_عشري` | `سجل1` (RAX/X0/a0) |
| `حرف` | `سجل1` (RAX/X0/a0) |
| `منطق` | `سجل1` (RAX/X0/a0) |
| `مؤشر` | `selectAll1` (RAX/X0/a0) |

### للأنواع الكبيرة (> 8 بايت)

```
- النوع يُخزن في الذاكرة
- المؤشر إلى الموقع يُرجع في سجل1
```

## 6.2 أمثلة

```ض
# إرجاع رقم
دالة: اجمع(أ: رقم، ب: رقم) -> رقم :-
    ارجع(أ + ب)    # القيمة في سجل1
نهاية

# إرجاع هيكل كبير
نوع: نقطة = { x: رقم، y: رقم }
دالة: إنشاء_نقطة() -> نقطة :-
    متغير: ص: نقطة = { 10، 20 }
    ارجع(ص)    # مؤشر إلى الذاكرة في سجل1
نهاية
```
