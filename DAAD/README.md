# ض Core

**لغة برمجة منخفضة المستوى عربية**

---

## نظرة عامة

ض Core هي لغة برمجة منخفضة المستوى صُممت لتكون الجسر بين لغة التجميع (Assembly) واللغات عالية المستوى. تقدم واجهة عربية كاملة للبرمجة على مستوى المعالج.
