# ض Core - اختبارات التوافق (Language Conformance Tests)

**الإصدار:** 0.1.0
**تاريخ الإصدار:** 2026-08-03
**الحالة:** مُعتمد

---

## المقدمة

هذه اختبارات رسمية للتأكد من توافق المترجم مع مواصفات اللغة. كل ملف يختبر ميزة محددة.

## بنية الاختبارات

```
tests/
├── valid/           # برامج صحيحة يجب أن تترجم بنجاح
├── invalid/         # برامج خاطئة يجب أن تسبب أخطاء
├── runtime/         # اختبارات سلوك التنفيذ
├── types/           # اختبارات نظام الأنواع
├── memory/          # اختبارات الذاكرة
├── abi/             # اختبارات واجهة التطبيق الثنائية
├── lexer/           # اختبارات المحلل البصري
├── parser/          # اختبارات المحلل النحوي
└── conformance/     # اختبارات التوافق الشاملة
```

## كيفية التشغيل

```bash
# تشغيل جميع الاختبارات
./daad test --all

# تشغيل اختبارات محددة
./daad test --valid
./daad test --invalid
./daad test --runtime
```

## معايير النجاح

- **valid/**: يجب أن تترجم وتُنفذ بنجاح
- **invalid/**: يجب أن تسبب خطأ في التحليل
- **runtime/**: يجب أن تُنفذ وتحقق النتيجة المتوقعة

## الفئات

### valid/ - برامج صحيحة

| الملف | الميزة المختبرة |
|-------|-----------------|
| `001-variable.deff` | تعريف متغير |
| `002-constant.deff` | تعريف ثابت |
| `003-function.deff` | تعريف دالة |
| `004-if.deff` | جملة شرطية |
| `005-while.deff` | حلقة while |
| `006-for.deff` | حلقة for |
| `007-struct.deff` | تعريف هيكل |
| `008-pointer.deff` | مؤشرات |
| `009-array.deff` | مصفوفة |
| `010-string.deff` | نص |

### invalid/ - برامج خاطئة

| الملف | الخطأ المتوقع |
|-------|---------------|
| `001-reserved-word.deff` | استخدام كلمة محجوزة كاسم |
| `002-undefined-type.deff` | نوع غير معروف |
| `003-undefined-var.deff` | متغير غير معروف |
| `004-type-mismatch.deff` | عدم تطابق الأنواع |
| `005-missing-end.deff` | نهاية مفقودة |

### runtime/ - اختبارات التنفيذ

| الملف | الميزة المختبرة |
|-------|-----------------|
| `001-arithmetic.deff` | العمليات الحسابية |
| `002-comparison.deff` | المقارنات |
| `003-logical.deff` | العمليات المنطقية |
| `004-function-call.deff` | استدعاء دوال |
| `005-recursion.deff` | التكرار |

### types/ - اختبارات الأنواع

| الملف | الميزة المختبرة |
|-------|-----------------|
| `001-int.deff` | النوع رقم |
| `002-float.deff` | النوع رقم_عشري |
| `003-char.deff` | النوع حرف |
| `004-bool.deff` | النوع منطق |
| `005-cast.deff` | التحويل بين الأنواع |

### memory/ - اختبارات الذاكرة

| الملف | الميزة المختبرة |
|-------|-----------------|
| `001-stack.deff` | المكدس |
| `002-heap.deff` | الكومة |
| `003-pointer-arith.deff` | حساب المؤشرات |
| `004-dynamic.deff` | الذاكرة الديناميكية |

---

## ملاحظات

1. كل ملف اختبار يجب أن يكون **صغيراً ومركّزاً** على ميزة واحدة
2. اختبارات **valid/** يجب أن تحتوي على تعليق يوضح النتيجة المتوقعة
3. اختبارات **invalid/** يجب أن تحتوي على تعليق يوضح نوع الخطأ المتوقع
4. اختبارات **runtime/** يجب أن تحتوي على تعليق يوضح المخرجات المتوقعة
