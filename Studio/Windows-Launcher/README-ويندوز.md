# دليل التشغيل على ويندوز — ض ستوديو

## التشغيل السريع (3 خطوات)

### الخطوة 1: تثبيت Node.js (مرة واحدة فقط)
1. افتح المتصفح
2. اذهب إلى: https://nodejs.org
3. حمّل الإصدار **LTS** (الموصى به)
4. شغّل الملف المحمّل واضغط "Next" حتى يكتمل
5. أعد تشغيل الكمبيوتر

### الخطوة 2: الإعداد التلقائي
1. اضغط نقراً مزدوجاً على: **`Windows-Launcher\إعداد-تلقائي.bat`**
2. انتظر حتى يكتمل (يأخذ حوالي دقيقة)

### الخطوة 3: التشغيل
1. اضغط نقراً مزدوجاً على: **`تشغيل-سريع.bat`**
2. أو اضغط على اختصار **"ض ستوديو"** على سطح المكتب

---

## قائمة التشغيل

عند فتح `Windows-Launcher\ض-ستوديو.bat` ستظهر قائمة:

```
1)  تشغيل المنصة الكاملة (سيرفر + واجهة ويب)
2)  تشغيل تطبيق سطح المكتب (Electron)
3)  تشغيل مترجم ض (C++ Compiler)
4)  تشغيل معالج ض (CPU Assembler + Simulator)
5)  تشغيل واجهة التيرمنال
6)  تشغيل واجهة Qt الرسومية
7)  تثبيت إضافة VS Code
8)  فتح محرر الكود على الويب
9)  عرض وثائق المشروع
0)  خروج
```

---

## شرح كل خيار

### 1. المنصة الكاملة (موصى بها)
- تشغّل السيرفر على المنفذ 3000
- يفتح المتصفح تلقائياً على http://localhost:3000
- يحتوي على: لوحة تحكم، تحديات، امتحانات، إدارة فصول
- **بيانات الدخول:**
  - المدير: `admin_1@test.com` / `Test1234!`
  - الطالب: `sara@test.com` / `Test1234!`

### 2. تطبيق سطح المكتب
- تطبيق مستقل عبر Electron
- لا يحتاج متصفح
- نفس ميزات المنصة الكاملة

### 3. مترجم ض
- يترجم ملفات `.ض` إلى كود C++20
- الملفات المترجمة يمكن تشغيلها بأي مترجم C++
- **مثال:** `daad-compiler.exe ملف.ض -o output.cpp`

### 4. معالج ض
- مجمّع ومحاكي معالج 8-بت
- الملفات: `.ضasm`
- **خيارات التشغيل:**
  - `--state` : عرض حالة المعالج الكاملة
  - `--hex` : عرض الكود السداسي عشري
  - `--debug` : تتبع تعليمة بتعليقمة
  - `--bin` : حفظ كملف binary
- **سحب وإفلات:** اسحب ملف `.ضasm` على الملف مباشرة

### 5. واجهة التيرمنال
- محاكي تيرمنال حي
- يعمل بدون رسوميات

### 6. واجهة Qt الرسومية
- IDE كامل مع محرر كود
- تلوين صيغة الكود
- تشغيل مباشر

### 7. إضافة VS Code
- تلوين صيغة الكود العربي
- 6 قصاصات كود جاهزة
- اختصار F9 للترجمة

### 8. محرر الويب
- محرر كود على المتصفح
- تشغيل مباشر بدون سيرفر

## استكشاف الأخطاء

### "Node.js غير مثبّت"
- حمّله من https://nodejs.org
- تأكد من إضافة "Add to PATH" أثناء التثبيت
- أعد تشغيل الكمبيوتر

### "Port 3000 already in use"
- افتح Task Manager (Ctrl+Shift+Esc)
- ابحث عن "node" في Processes
- أنهِ العملية (End Task)
- أعد تشغيل السيرفر

### "الملف غير موجود"
- تأكد أنك في المجلد الصحيح
- اضغط Shift+كليك يمين → Open PowerShell here
- اكتب: `dir` لرؤية الملفات

### المترجم لا يعمل
- تأكد من تثبيت C++ compiler (GCC أو MSVC)
- أو استخدم النسخة المجمّعة المسبقاً
