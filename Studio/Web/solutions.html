دورة التشفير

الدرس الأول: مقدمة في علم التشفير

في هذا الدرس تعلمنا كيف نستخدم دالة الهاش() من مكتبة الأمان لتحويل النص إلى بصمة رقمية لا يمكن عكسها.

// استيراد مكتبة الأمان استورد "الأمان"; // تحويل نص إلى بصمة SHA-256 نص النص = "مرحباً بالعالم"; نص البصمة = الهاش(النص); طباعة("النص الأصلي: " + النص); طباعة("البصمة: " + البصمة); // مقارنة نصين نص نص2 = "مرحباً بالعالم"; صحيح مطابق = (الهاش(النص) == الهاش(نص2)); طباعة("هل هما متساويان؟ " + مطابق);
البصمة: 7d793037a0760186574b0282f2f435e7...
ملاحظة: الهاش أحادي الاتجاه - لا يمكن استرجاع النص الأصلي من البصمة. هذا يجعله آمناً لتخزين كلمات المرور.
جرّب تغيير النص وشاهد كيف تتغير البصمة بالكامل حتى لو تغير حرف واحد فقط.

دورة الأمن السيبراني

الدرس الأول: مقدمة في الأمن السيبراني

في هذا الدرس تعلمنا كيف نجمع المعلومات عن أي موقع ويب باستخدام دوال مكتبة الأدوات.

// استيراد مكتبة الأدوات الأمنية استورد "الأدوات"; // جمع معلومات عن موقع نص المعلومات = جمع_معلومات("example.com"); طباعة(المعلومات); // فحص المنافذ المفتوحة نص المنافذ = فحص_منافذ("example.com", "1-100"); طباعة(المنافذ); // تحليل رؤوس HTTP نص الرؤوس = حلل_رؤوس("https://example.com"); طباعة(الرؤوس); // تقرير أمان شامل نص التقرير = تقرير_أمان("example.com"); طباعة(التقرير);
تقرير أمان example.com: تم فحص 100 منفذ - 3 مفتوحة (80, 443, 22)
ملاحظة: جمع المعلومات هو الخطوة الأولى في أي اختبار اختراق. كلما حصلت على معلومات أكثر، كان تحليلك أدق.
جرّب فحص موقعك الخاص وشاهد النتائج. هل توجد منافذ غير متوقعة مفتوحة؟

دورة برمجة صفحات الويب

الدرس الأول: مقدمة في HTML

في هذا الدرس تعلمنا كيف ننشئ صفحة ويب كاملة باستخدام دوال مكتبة الويب في لغة ض.

// استيراد مكتبة الويب استورد "الويب"; // إنشاء صفحة HTML كاملة صفحة_كاملة("موقعي الأول", [ ترويسة("مرحباً بكم في موقعي", "هذا موقع تعليمي بلغة ض"), عنوان2("من نحن"), فقرة("نحن طلاب يتعلمون البرمجة بلغة الض"), عنوان2("خدماتنا"), قائمة([ "تعلم البرمجة", "بناء المواقع", "تطوير التطبيقات" ]), رابط("https://example.com", "زيارة موقعنا"), تذييل("© 2024 جميع الحقوق محفوظة") ]);
تم إنشاء صفحة HTML كاملة بعنوان وفقرات وقائمة ورابط وتذييل
ملاحظة: دالة صفحة_كاملة() تنشئ لك HTML كامل جاهز للعرض. يمكنك تعديل المحتوى بسهولة.
جرّب إضافة صورة باستخدام صورة() وعنوان رئيسي باستخدام عنوان1().
