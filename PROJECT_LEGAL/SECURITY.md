|-----------|--------------------|
| 1.00.00   | ✅ Active          |

## Reporting a Vulnerability

We take the security of **ض (Daad)** seriously.

### How to Report

1. **DO NOT** open a public GitHub issue for security vulnerabilities.
2. Send a detailed report to: **[أضف بريدك الإلكتروني هنا]**
3. Include the following information:
   - Description of the vulnerability
   - Steps to reproduce
   - Affected version(s)
   - Potential impact
   - Suggested fix (if any)

### What to Expect

- **Acknowledgment**: Within 48 hours of receiving your report.
- **Assessment**: We will evaluate the severity within 7 days.
- **Resolution**: We aim to release a patch within 30 days for critical issues.
- **Disclosure**: We follow responsible disclosure practices. You will be
  credited (unless you prefer to remain anonymous) after the fix is released.

### Scope

The following are in scope:
- The Daad compiler/interpreter source code
- The standard library
- The package manager (if applicable)
- Build system and toolchain

The following are out of scope:
- Third-party dependencies (report to their respective maintainers)
- Documentation-only issues
- Social engineering attacks
